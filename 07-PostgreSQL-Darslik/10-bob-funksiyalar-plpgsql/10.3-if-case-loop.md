# 10.3. `IF`, `CASE` va `LOOP` — boshqaruv strukturalari

## Bu darsda nimalarni o'rganasiz

- Oddiy SQL'ning o'zida (funksiyasiz) `CASE` ifodasi bilan shartli mantiq yozishni bilasiz
- `CASE`ning ikkita shakli — "qidiruvchi" va "oddiy" — orasidagi farqni tushunasiz
- PL/pgSQL funksiyalari ichida `IF`/`ELSIF`/`ELSE`ni mustahkamlaysiz
- `FOR` va `WHILE` tsikllari bilan takrorlanuvchi mantiqni yozishni bilasiz

## Nazariy qism

### `CASE` — oddiy SQL ichidagi shartli ifoda (funksiyasiz)

10.2-darsda PL/pgSQL funksiyasi ichidagi `IF`ni ko'rdik. Lekin ko'pincha sizga **funksiya yaratmasdan**, to'g'ridan-to'g'ri oddiy `SELECT` ichida shartli mantiq kerak bo'ladi — buning uchun standart SQL'ning o'zida mavjud bo'lgan `CASE` ifodasi ishlatiladi:

```sql
SELECT nomi, narxi,
    CASE
        WHEN narxi > 3000000 THEN 'Qimmat'
        WHEN narxi > 1000000 THEN 'O''rtacha'
        ELSE 'Arzon'
    END AS narx_toifasi
FROM mahsulotlar
ORDER BY narxi DESC;
```

```
          nomi          |   narxi    | narx_toifasi 
------------------------+------------+--------------
 Noutbuk Lenovo IdeaPad | 8500000.00 | Qimmat
 Muzlatgich             | 6800000.00 | Qimmat
 Kofe mashinasi         | 3500000.00 | Qimmat
 Ish stoli              | 2500000.00 | O'rtacha
 Monitor Samsung 24"    | 2200000.00 | O'rtacha
 Bosma printer          | 1800000.00 | O'rtacha
 Ofis stuli             | 1200000.00 | O'rtacha
 Kitob tokchasi         |  900000.00 | Arzon
 Klaviatura mexanik     |  450000.00 | Arzon
 Sichqoncha Logitech    |  150000.00 | Arzon
(10 rows)
```

`CASE WHEN shart1 THEN natija1 WHEN shart2 THEN natija2 ... ELSE standart_natija END` — shartlar **yuqoridan pastga** ketma-ket tekshiriladi, birinchi `TRUE` bo'lgan shartning natijasi qaytariladi (xuddi dasturlash tilidagi `if/elif/elif/else` kabi). `ELSE` — ixtiyoriy; agar u bo'lmasa va hech qanday shart to'g'ri kelmasa, natija `NULL` bo'ladi.

### `CASE`ning ikkinchi shakli — "oddiy" (simple) `CASE`

Agar barcha shartlar **bitta ustunni turli qiymatlar bilan** solishtirsa, qisqaroq shakl ham mavjud:

```sql
SELECT holati,
    CASE holati
        WHEN 'yetkazildi' THEN 'Yakunlangan'
        WHEN 'bekor qilindi' THEN 'Bekor qilingan'
        ELSE 'Jarayonda'
    END AS holat_uz
FROM buyurtmalar
ORDER BY id;
```

```
    holati     |    holat_uz    
---------------+----------------
 yetkazildi    | Yakunlangan
 yetkazildi    | Yakunlangan
 jonatildi     | Jarayonda
 yetkazildi    | Yakunlangan
 kutilmoqda    | Jarayonda
 bekor qilindi | Bekor qilingan
 yetkazildi    | Yakunlangan
 jonatildi     | Jarayonda
 kutilmoqda    | Jarayonda
(9 rows)
```

Bu — `CASE WHEN holati = 'yetkazildi' THEN ... WHEN holati = 'bekor qilindi' THEN ... END`ning qisqartmasi. Ikkala shakl ham keng qo'llaniladi — "qidiruvchi" (birinchi, `WHEN shart`) shakli ko'proq moslashuvchan (turli ustun/murakkab shartlar), "oddiy" (`CASE ustun WHEN qiymat`) shakli esa faqat bitta ustunni solishtirishda qisqaroq va tozaroq.

`CASE` — SQL'ning **istalgan** joyida (`SELECT` ro'yxatida, `WHERE`da, `ORDER BY`da, hattoki `GROUP BY`da) ishlatilishi mumkin bo'lgan **ifoda**, funksiya emas.

### PL/pgSQL ichidagi `IF`/`ELSIF`/`ELSE` (mustahkamlash)

10.2-darsda ko'rganimizdek, PL/pgSQL funksiyalari ichida to'liq protsedurali `IF` mavjud:

```sql
IF shart1 THEN
    ...
ELSIF shart2 THEN
    ...
ELSE
    ...
END IF;
```

`CASE` bilan solishtirganda, `IF` — bir necha SQL bayonotini (masalan, bir nechta `INSERT`, o'zgaruvchi tayinlash) ichiga olishi mumkin, `CASE` esa faqat **bitta qiymat** qaytaradi — shuning uchun `IF` PL/pgSQL funksiyasi/protsedura ichida, `CASE` esa oddiy SQL so'rovlarida ishlatiladi.

### `FOR` tsikli — sonlar oralig'i bo'yicha

PL/pgSQL'da eng ko'p ishlatiladigan tsikl turi — `FOR ... IN oraliq LOOP`:

```sql
CREATE FUNCTION faktorial(n INTEGER) RETURNS BIGINT AS $$
DECLARE
    natija BIGINT := 1;
    i INTEGER;
BEGIN
    FOR i IN 1..n LOOP
        natija := natija * i;
    END LOOP;
    RETURN natija;
END;
$$ LANGUAGE plpgsql;
```

```sql
SELECT faktorial(5), faktorial(10);
```

```
 faktorial | faktorial 
-----------+-----------
       120 |   3628800
```

`FOR i IN 1..n LOOP ... END LOOP;` — `i`ni `1`dan `n`gacha (ikkalasi ham kiritilgan holda, 2.1-darsdagi `BETWEEN`ga o'xshab) ketma-ket oshirib, har bir qiymat uchun tsikl tanasini bajaradi. `:=` — PL/pgSQL'da o'zgaruvchiga qiymat tayinlash operatori (`=` emas — bu SQL'dagi taqqoslash bilan chalkashmasligi uchun).

### `WHILE` tsikli — shart to'g'ri bo'lguncha

Agar takrorlanish soni oldindan aniq bo'lmasa, `WHILE` ishlatiladi:

```sql
CREATE FUNCTION birinchi_n_juft(n INTEGER) RETURNS TEXT AS $$
DECLARE
    natija TEXT := '';
    son INTEGER := 0;
    hisoblagich INTEGER := 0;
BEGIN
    WHILE hisoblagich < n LOOP
        son := son + 2;
        natija := natija || son || ' ';
        hisoblagich := hisoblagich + 1;
    END LOOP;
    RETURN natija;
END;
$$ LANGUAGE plpgsql;
```

```sql
SELECT birinchi_n_juft(5);
```

```
 birinchi_n_juft 
-----------------
 2 4 6 8 10 
```

`WHILE shart LOOP ... END LOOP;` — shart `TRUE` bo'lgan ekan, tsikl tanasi takrorlanadi. **Diqqat:** `WHILE`da tsikl ichida shartga ta'sir qiluvchi o'zgaruvchini (bu misolda `hisoblagich`) yangilashni unutmaslik juda muhim — aks holda tsikl **cheksiz** aylanib qoladi (bu — 9.2-darsdagi rekursiv CTE'dagi "aylanma bog'lanish" xavfiga konseptual jihatdan o'xshash muammo).

### Amaliyotda tsikllardan qachon foydalanish kerak — muhim eslatma

SQL — **to'plamlar bilan ishlash** (set-based) tiliga mo'ljallangan, ya'ni ko'pchilik vazifalar (masalan, "har bir mahsulot narxini 10% oshirish") alohida-alohida tsikl bilan emas, balki **bitta** `UPDATE mahsulotlar SET narxi = narxi * 1.1`buyrug'i bilan, barcha qatorlarga **bir vaqtda** qo'llanadi — bu deyarli har doim tsikl bilan yozilgan versiyadan sezilarli tezroq. PL/pgSQL'dagi tsikllar asosan quyidagi holatlarda haqiqatan zarur: (1) har bir qadam oldingisiga bog'liq bo'lgan hisob-kitob (masalan, faktorial); (2) alohida qatorlar ustida turli, bir-biriga bog'liq bo'lmagan amallarni ketma-ket bajarish kerak bo'lganda (masalan, har biri turlicha xato bilan tugashi mumkin bo'lgan tashqi tizimga so'rov yuborish); (3) ma'lumotlar to'plamiga oid emas, balki sof matematik/algoritmik hisob-kitoblar. **Amaliy qoida:** agar vazifani oddiy `UPDATE`/`SELECT` bilan (tsiklsiz) yechish mumkin bo'lsa, deyarli har doim shu yo'l afzalroq.

## Amaliy misol

**Vazifa:** Har bir buyurtmaning holatini, uning "bosqichi" raqami bilan birga ko'rsatuvchi so'rov yozing (`CASE` yordamida): "kutilmoqda" = 1, "jonatildi" = 2, "yetkazildi" = 3, "bekor qilindi" = 0.

```sql
SELECT id, holati,
    CASE holati
        WHEN 'kutilmoqda' THEN 1
        WHEN 'jonatildi' THEN 2
        WHEN 'yetkazildi' THEN 3
        WHEN 'bekor qilindi' THEN 0
    END AS bosqich
FROM buyurtmalar
ORDER BY bosqich DESC, id;
```

Bu — `CASE`ning natijasini `ORDER BY`da ham ishlatib, "mantiqiy" (alfavit tartibida emas, biznes jarayoni bosqichi bo'yicha) saralashni ko'rsatadi.

## Keng tarqalgan xatolar

**Xato 1:** Oddiy shartli formatlash uchun keraksiz ravishda butun PL/pgSQL funksiya yozish, `CASE` yetarli bo'lgan holatda.
✅ Agar vazifa faqat "shartga qarab qiymat tanlash" bo'lsa, oddiy `CASE` — funksiyadan qisqaroq va tezroq.

**Xato 2:** `WHILE` tsiklida shart o'zgaruvchisini yangilashni unutib, cheksiz tsiklga tushib qolish.
✅ Har doim tsikl tanasida shartga ta'sir qiluvchi o'zgaruvchi albatta o'zgarishini tekshiring.

**Xato 3:** To'plamlar bilan yechilishi mumkin bo'lgan vazifani keraksiz ravishda tsikl bilan, qator-qator qayta ishlash.
✅ Avval "buni oddiy `UPDATE`/`SELECT` bilan bitta amalda yechib bo'lmaydimi" deb o'ylab ko'ring — SQL to'plamlar bilan ishlashda juda samarali.

## Qisqacha xulosa

`CASE` — oddiy SQL ichida (funksiyasiz) shartli qiymat tanlash uchun ishlatiladigan ifoda, ikkita shaklda ("qidiruvchi" va "oddiy") mavjud. PL/pgSQL funksiyalari ichida esa to'liq `IF`/`ELSIF`/`ELSE`, `FOR` (sonlar oralig'i bo'yicha) va `WHILE` (shart asosida) tsikllari mavjud — lekin ko'pchilik ma'lumotlar bazasi vazifalari tsiklsiz, to'plamlar darajasidagi `UPDATE`/`SELECT` bilan tezroq va tabiiyroq yechiladi. Bu bilan 10-bob (Funksiyalar va PL/pgSQL) yakunlanadi — keyingi, 11-bobda esa VIEW va Window funksiyalarni o'rganamiz.
