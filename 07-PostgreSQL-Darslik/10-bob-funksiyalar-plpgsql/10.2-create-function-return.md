# 10.2. `CREATE FUNCTION` va `RETURN` — o'z funksiyalaringizni yaratish

## Bu darsda nimalarni o'rganasiz

- PostgreSQL'da o'z funksiyangizni yaratishni bilasiz
- `LANGUAGE sql` va `LANGUAGE plpgsql` orasidagi farqni tushunasiz
- `RETURN` bilan qiymat qaytarishni bilasiz
- Funksiya ichida `DECLARE` bilan lokal o'zgaruvchi e'lon qilish va `SELECT ... INTO` bilan qiymat olishni o'rganasiz
- Funksiyani so'rovlarda oddiy ustundek ishlatishni ko'rasiz

## Nazariy qism

### Nega o'z funksiyangizni yaratish kerak

10.1-darsda PostgreSQL'ning boy o'rnatilgan funksiyalar to'plamini ko'rdik. Lekin ba'zan sizga **o'zingizning biznes mantig'ingizga xos** hisob-kitob kerak bo'ladi — masalan, "mahsulot holatini matn sifatida aniqlash" yoki "bo'limdagi xodimlar sonini hisoblash" kabi, bir necha joyda takroran ishlatiladigan mantiq. Bunday mantiqni har safar qo'lda yozish (yoki nusxalash) o'rniga, uni **bir marta** funksiya sifatida yozib, keyin istalgan so'rovda oddiy funksiya kabi chaqirish mumkin.

### `LANGUAGE sql` — eng sodda funksiya turi

Eng sodda funksiya — ichida bitta SQL ifodasi bo'lgan funksiya:

```sql
CREATE FUNCTION ikkilantirish(x INTEGER) RETURNS INTEGER AS $$
    SELECT x * 2;
$$ LANGUAGE sql;
```

```sql
SELECT ikkilantirish(21);
```

```
 ikkilantirish 
---------------
            42
```

Bu yerda: `ikkilantirish(x INTEGER)` — funksiya nomi va parametr(lar)i; `RETURNS INTEGER` — funksiya qaytaradigan qiymat turi; `$$ ... $$` — funksiya "tanasi" (body)ni belgilaydigan maxsus chegara (dollar-tirnoq, oddiy tirnoqlar bilan chalkashmasligi uchun); `LANGUAGE sql` — funksiya tanasi oddiy SQL bilan yozilganini bildiradi. `LANGUAGE sql` funksiyalari — juda sodda, faqat bitta `SELECT` ifodasini "o'rab" nomlashning qulay usuli.

### `LANGUAGE plpgsql` — protsedurali mantiq bilan

Agar sizga shartli mantiq (`IF`/`ELSE`), tsikllar, yoki bir nechta qadamli hisob-kitob kerak bo'lsa, **PL/pgSQL** — PostgreSQL'ning o'z protsedurali dasturlash tili — kerak bo'ladi (bu tilni 10.3-darsda chuqurroq o'rganamiz):

```sql
CREATE FUNCTION mahsulot_holati(soni INTEGER) RETURNS TEXT AS $$
BEGIN
    IF soni = 0 THEN
        RETURN 'Tugagan';
    ELSIF soni < 10 THEN
        RETURN 'Kam qoldi';
    ELSE
        RETURN 'Yetarli';
    END IF;
END;
$$ LANGUAGE plpgsql;
```

Endi bu funksiyani oddiy ustundek, `SELECT` ro'yxatida ishlatish mumkin:

```sql
SELECT nomi, ombordagi_soni, mahsulot_holati(ombordagi_soni)
FROM mahsulotlar
ORDER BY id;
```

```
          nomi          | ombordagi_soni | mahsulot_holati 
------------------------+----------------+-----------------

 Sichqoncha Logitech    |             87 | Yetarli
 Klaviatura mexanik     |             34 | Yetarli
 Monitor Samsung 24"    |             20 | Yetarli
 Ofis stuli             |             15 | Yetarli
 Ish stoli              |              8 | Kam qoldi
 Kofe mashinasi         |              5 | Kam qoldi
 Muzlatgich             |              3 | Kam qoldi

```

Diqqat qiling — funksiya `mahsulotlar.ombordagi_soni`ni **har bir qator uchun** alohida qabul qilib, o'zining shartli mantig'ini qo'llaydi. Bu — ma'lumotlar bazasidagi ma'lumot bilan "muzlatilgan holda birga yashaydigan" biznes qoidasi yaratishning kuchli usuli: endi "Kam qoldi" chegarasi (10) faqat **bitta joyda** — funksiya ichida — belgilangan, va uni istalgan so'rovda, istalgan ilova tomonidan izchil qo'llash mumkin.

### `DECLARE` va `SELECT ... INTO` — lokal o'zgaruvchi va so'rov natijasini olish

Murakkabroq funksiyalarga odatda **lokal o'zgaruvchilar** kerak bo'ladi — ular `DECLARE` bandida e'lon qilinadi:

```sql
CREATE FUNCTION bolim_xodimlar_soni(p_bolim_id INTEGER) RETURNS INTEGER AS $$
DECLARE
    natija INTEGER;
BEGIN
    SELECT count(*) INTO natija FROM xodimlar WHERE bolim_id = p_bolim_id;
    RETURN natija;
END;
$$ LANGUAGE plpgsql;
```

```sql
SELECT nomi, bolim_xodimlar_soni(id)
FROM bolimlar
ORDER BY id;
```

```
   nomi    | bolim_xodimlar_soni 
-----------+---------------------
 Sotuv     |                   3
 IT        |                   3
 Marketing |                   2
 Moliya    |                   1
 Kadrlar   |                   1
```

Bu yerda `SELECT count(*) INTO natija FROM ...` — PL/pgSQL'ning maxsus sintaksisi: oddiy `SELECT` natijasini (agar u bitta qator, bitta ustun bo'lsa) to'g'ridan-to'g'ri lokal o'zgaruvchiga yozib oladi. Bu — 9.1-darsdagi skalyar subquery bilan **konseptual jihatdan o'xshash** (bitta qiymat kutiladi), lekin bu holda funksiya ichida, alohida bosqich sifatida bajariladi.

> **Diqqat:** parametr nomi (`p_bolim_id`) atayin `bolim_id` emas, `p_bolim_id` (`p_` — "parameter" prefiksi) deb tanlangan — bu keng tarqalgan konventsiya, chunki agar parametr nomi jadval ustuni nomi bilan **aynan bir xil** bo'lsa, funksiya ichidagi SQL ifodalarida noaniqlik (7.2-darsdagi `UPDATE ... FROM`da ko'rgan "ambiguous column" xatosiga o'xshash) yuzaga kelishi mumkin.

### Funksiyani o'chirish

```sql
DROP FUNCTION ikkilantirish(INTEGER);
```

Diqqat qiling — `DROP FUNCTION`da parametr turlarini ham ko'rsatish kerak (`ikkilantirish(INTEGER)`, shunchaki `ikkilantirish` emas), chunki PostgreSQL bir xil nomli, lekin turli parametrlar bilan bir nechta funksiyaga ruxsat beradi (bu — "funksiya ortiqcha yuklanishi", function overloading, deyiladi — masalan, `ikkilantirish(INTEGER)` va `ikkilantirish(NUMERIC)` alohida, mustaqil funksiyalar sifatida birga mavjud bo'lishi mumkin).

## Amaliy misol

**Vazifa:** Xodimning bonus miqdorini, uning maoshi va staj (shartli, oddiy misol sifatida "5 yildan ko'p ishlagan bo'lsa 10%, aks holda 5%") asosida hisoblovchi funksiya yarating.

```sql
CREATE FUNCTION bonus_hisobla(maosh NUMERIC, stajli BOOLEAN) RETURNS NUMERIC AS $$
BEGIN
    IF stajli THEN
        RETURN maosh * 0.10;
    ELSE
        RETURN maosh * 0.05;
    END IF;
END;
$$ LANGUAGE plpgsql;

SELECT ism, ish_haqi, bonus_hisobla(ish_haqi, ish_haqi > 15000000) AS bonus
FROM xodimlar
ORDER BY id;
```

## Keng tarqalgan xatolar

**Xato 1:** Funksiya parametri nomini jadval ustuni nomi bilan bir xil qilib, keyin "ambiguous" xatosiga duch kelish.
✅ Parametr nomlariga izchil prefiks (`p_`) qo'shish — bu muammoni butunlay oldini oladi.

**Xato 2:** `RETURNS`da e'lon qilingan tur bilan haqiqiy qaytarilayotgan qiymat turi mos kelmasligi.
❌ `RETURNS INTEGER AS $$ SELECT 'matn'; $$` — tur mos kelmasa xato (yoki, agar avtomatik aylantirish mumkin bo'lsa, kutilmagan natija).
✅ Har doim `RETURNS`dagi tur bilan real qaytariladigan qiymat turini mos qiling.

**Xato 3:** `DROP FUNCTION`da parametr turlarini ko'rsatmaslik, funksiya ortiqcha yuklangan (overload qilingan) bo'lsa xatoga duch kelish.
✅ Har doim to'liq imzo (`funksiya_nomi(parametr_turlari)`) bilan `DROP FUNCTION` chaqiring.

## Mashq/topshiriq

**(Oson)** `narxni_som_bilan_korsat(narx NUMERIC) RETURNS TEXT` funksiyasini yarating, u sonni `"X so'm"` formatidagi matnga aylantirsin (`LANGUAGE sql`, `CONCAT` ishlatib).

**(O'rtacha)** `mijoz_toifasi(jami_xarid NUMERIC) RETURNS TEXT` funksiyasini yarating: agar `jami_xarid > 5000000` bo'lsa `'VIP'`, `> 1000000` bo'lsa `'Doimiy'`, aks holda `'Oddiy'` qaytarsin (`LANGUAGE plpgsql`, `IF/ELSIF/ELSE`).

**(Qiyin)** `mahsulot_soni_kategoriyada(p_kategoriya TEXT) RETURNS INTEGER` funksiyasini yarating — u berilgan kategoriyadagi mahsulotlar sonini qaytarsin (`DECLARE`/`SELECT ... INTO` ishlatib), so'ng uni `mahsulotlar`dagi har bir noyob kategoriya uchun chaqirib natijalarni solishtiring.

```sql
CREATE FUNCTION narxni_som_bilan_korsat(narx NUMERIC) RETURNS TEXT AS $$
```

```sql
CREATE FUNCTION mijoz_toifasi(jami_xarid NUMERIC) RETURNS TEXT AS $$

    IF jami_xarid > 5000000 THEN
        RETURN 'VIP';

        RETURN 'Doimiy';
    ELSE
        RETURN 'Oddiy';
```

```sql
CREATE FUNCTION mahsulot_soni_kategoriyada(p_kategoriya TEXT) RETURNS INTEGER AS $$
DECLARE
    natija INTEGER;
BEGIN
    SELECT count(*) INTO natija FROM mahsulotlar WHERE kategoriya = p_kategoriya;
    RETURN natija;

$$ LANGUAGE plpgsql;

SELECT DISTINCT kategoriya, mahsulot_soni_kategoriyada(kategoriya) FROM mahsulotlar;
```

## Qisqacha xulosa

`CREATE FUNCTION` — o'zingizning, qayta ishlatiladigan mantiqingizni bazaning o'ziga "joylashtirish" imkonini beradi: `LANGUAGE sql` sodda, bitta ifodali funksiyalar uchun, `LANGUAGE plpgsql` esa shartli mantiq, tsikllar va lokal o'zgaruvchilar kerak bo'lganda ishlatiladi. Funksiyalar, bir marta yaratilgach, oddiy ustundek istalgan `SELECT`da ishlatilishi mumkin. Keyingi darsda PL/pgSQL'ning boshqaruv strukturalarini — `IF`/`CASE`/`LOOP`ni — chuqurroq o'rganamiz.
