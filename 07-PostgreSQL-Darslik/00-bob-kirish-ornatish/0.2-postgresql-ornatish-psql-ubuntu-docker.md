# 0.2. O'rnatish va `psql` buyruq qatori mijozi

## Bu darsda nimalarni o'rganasiz

- PostgreSQL'ni Ubuntu'ga to'g'ridan-to'g'ri va Docker orqali o'rnata olasiz
- `psql` buyruq qatori mijozidan foydalanishni bilasiz
- Baza yaratish va unga ulanishni amalga oshira olasiz
- `psql`ning eng muhim maxsus buyruqlarini (`\l`, `\c`, `\dt`, `\d`, `\q`) qo'llay olasiz

## Nazariy qism

### O'rnatish usullari — qaysi birini tanlash

PostgreSQL'ni o'rnatishning uchta asosiy yo'li bor:

1. **Tizim paket menejeri orqali** (Ubuntu'da `apt`) — eng oddiy, doimiy ishlaydigan server sifatida.
2. **Docker konteynerida** — izolyatsiya qilingan, tez o'chirib-yoqiladigan, versiyani osongina almashtirish mumkin bo'lgan usul; zamonaviy development muhitlarida eng ko'p tavsiya etiladi.
3. **Manba kodidan qurish (build from source)** — faqat maxsus konfiguratsiya yoki eng so'nggi (hatto beta) versiya kerak bo'lganda ishlatiladi, bu darslikda ko'rilmaydi.

### 1-usul: Ubuntu'ga to'g'ridan-to'g'ri o'rnatish

Ubuntu'ning standart repozitoriyasida ko'pincha biroz eskiroq versiya bo'ladi, shuning uchun PostgreSQL'ning **rasmiy** APT repozitoriyasini qo'shish tavsiya etiladi — bu doimo eng so'nggi barqaror versiyani (hozircha **18**) taqdim etadi:

```bash
# Kerakli vositalarni o'rnatish
sudo apt update
sudo apt install -y curl ca-certificates gnupg

# PostgreSQL'ning rasmiy GPG kalitini qo'shish
curl -fsSL https://www.postgresql.org/media/keys/ACCC4CF8.asc | sudo gpg --dearmor -o /usr/share/keyrings/postgresql.gpg

# Rasmiy repozitoriyani qo'shish (Ubuntu kodli nomini avtomatik aniqlash bilan)
echo "deb [signed-by=/usr/share/keyrings/postgresql.gpg] http://apt.postgresql.org/pub/repos/apt $(lsb_release -cs)-pgdg main" | \
  sudo tee /etc/apt/sources.list.d/pgdg.list

# O'rnatish
sudo apt update
sudo apt install -y postgresql-18 postgresql-client-18
```

O'rnatish tugagach, PostgreSQL xizmati (service) avtomatik ishga tushadi. Holatini tekshirish:

```bash
sudo systemctl status postgresql
```

O'rnatish jarayonida avtomatik ravishda **`postgres`** nomli maxsus operatsion tizim foydalanuvchisi va shu nomdagi superuser (bazadagi eng yuqori huquqli foydalanuvchi) yaratiladi.

### `postgres` foydalanuvchisi bilan birinchi ulanish

```bash
sudo -i -u postgres     # postgres OS foydalanuvchisiga o'tish
psql                     # psql'ni ishga tushirish (standart holatda "postgres" bazasiga ulanadi)
```

Yoki bitta qatorda:

```bash
sudo -u postgres psql
```

### 2-usul: Docker orqali o'rnatish

Docker — PostgreSQL'ni tizimga "iflos" o'rnatmasdan, tezda ishga tushirish va kerak bo'lganda butunlay o'chirib tashlashning eng qulay yo'li (ayniqsa development va o'rganish uchun):

```bash
docker run --name mening-postgresim \
  -e POSTGRES_PASSWORD=maxfiy_parol \
  -e POSTGRES_DB=dokon_bazasi \
  -p 5432:5432 \
  -d postgres:18
```

Bu buyruq:
- `--name mening-postgresim` — konteynerga nom beradi
- `-e POSTGRES_PASSWORD=...` — superuser (`postgres`) paroli
- `-e POSTGRES_DB=dokon_bazasi` — ishga tushishda avtomatik `dokon_bazasi` nomli baza yaratadi
- `-p 5432:5432` — konteyner ichidagi 5432-portni kompyuterning 5432-portiga bog'laydi
- `-d postgres:18` — fonda (detached), rasmiy `postgres` image'ining 18-versiyasi bilan ishga tushiradi

Konteyner ichidagi `psql`ga ulanish:

```bash
docker exec -it mening-postgresim psql -U postgres -d dokon_bazasi
```

Konteynerni to'xtatish/qayta ishga tushirish:

```bash
docker stop mening-postgresim
docker start mening-postgresim
```

> 📌 **Nega Docker ko'pincha afzal ko'riladi:** turli loyihalar turli PostgreSQL versiyasini talab qilishi mumkin — Docker bilan har bir loyiha uchun alohida, bir-biriga aralashmaydigan konteyner ishlatish oson. Bu tushuncha Python darsligidagi virtual muhit (venv) g'oyasiga juda o'xshaydi — faqat butun ma'lumotlar bazasi darajasida.

### `psql` — PostgreSQL'ning rasmiy buyruq qatori mijozi

`psql` — PostgreSQL bilan ishlashning eng asosiy, hamma joyda mavjud vositasi. U ikki turdagi buyruqni qabul qiladi:

1. **Oddiy SQL buyruqlari** — `;` (nuqtali vergul) bilan tugaydi: `SELECT * FROM mijozlar;`
2. **`psql`ning maxsus (meta) buyruqlari** — teskari qiya chiziq `\` bilan boshlanadi, `;` talab qilmaydi: `\dt`, `\l`, `\q`

### Eng muhim `psql` meta-buyruqlari

| Buyruq | Vazifasi |
|---|---|
| `\l` | Barcha bazalar ro'yxatini ko'rsatadi |
| `\c baza_nomi` | Boshqa bazaga ulanish (connect) |
| `\dt` | Joriy bazadagi jadvallar ro'yxati |
| `\d jadval_nomi` | Jadval strukturasi (ustunlar, turlar, indekslar, cheklovlar) |
| `\du` | Foydalanuvchilar/rollar ro'yxati |
| `\dn` | Sxemalar ro'yxati |
| `\x` | Kengaytirilgan (vertical) chiqish rejimini yoqish/o'chirish — keng jadvallarni o'qish uchun qulay |
| `\timing` | Har bir so'rovning bajarilish vaqtini ko'rsatishni yoqish/o'chirish |
| `\?` | Barcha meta-buyruqlar ro'yxati (yordam) |
| `\h BUYRUQ` | Ma'lum bir SQL buyrug'i (masalan `\h SELECT`) haqida qisqacha yordam |
| `\q` | `psql`dan chiqish |

### Yangi baza yaratish va ulanish

```sql
-- postgres bazasiga ulangan holda:
CREATE DATABASE dokon_bazasi;
```

```bash
\c dokon_bazasi
```

```
Siz endi "dokon_bazasi" bazasiga "postgres" foydalanuvchisi sifatida ulangansiz.
```

## Amaliy misol

To'liq, boshidan oxirigacha ketma-ketlik — o'rnatishdan birinchi bazani yaratish va tekshirishgacha:

```bash
# 1. postgres foydalanuvchisi sifatida ulanish
sudo -u postgres psql
```

```sql
-- 2. Yangi baza yaratish
CREATE DATABASE dokon_bazasi;

-- 3. Bazalar ro'yxatini ko'rish
\l

-- 4. Yangi bazaga ulanish
\c dokon_bazasi

-- 5. Sinov uchun oddiy jadval va qator yaratish
CREATE TABLE sinov (xabar TEXT);
INSERT INTO sinov VALUES ('Salom, PostgreSQL!');
SELECT * FROM sinov;
```

Kutilgan natija:

```
      xabar
--------------------
 Salom, PostgreSQL!
(1 row)
```

```sql
-- 6. Jadvallar ro'yxatini tekshirish
\dt

-- 7. Chiqish
\q
```

## Keng tarqalgan xatolar

**Xato 1:** `psql`ga kirgandan keyin SQL buyrug'ining oxiriga `;` qo'yishni unutish.
❌ `SELECT * FROM sinov` (nuqta-vergulsiz) yozib Enter bosilsa, `psql` buyruq hali "tugamagan" deb hisoblaydi va yangi qatorda `dokon_bazasi=# ` o'rniga `dokon_bazasi-# ` (chiziqcha bilan) ko'rsatadi, kutib turadi.
✅ To'g'ri: har bir SQL buyrug'ini albatta `;` bilan yakunlang. Agar "osilib qolgan" bo'lsangiz, shunchaki `;` yozib Enter bosing.

**Xato 2:** meta-buyruqlarga (`\dt`, `\l` va h.k.) nuqta-vergul qo'shish.
❌ `\dt;` — bu xato beradi yoki kutilmagan natija ko'rsatadi, chunki meta-buyruqlar `;`ni SQL sintaksisi qismi sifatida talqin qilishga urinishi mumkin.
✅ To'g'ri: meta-buyruqlar `;`siz, faqat `\dt` shaklida yoziladi.

**Xato 3:** Docker konteynerini `-p 5432:5432` siz ishga tushirib, keyin tashqaridan (masalan boshqa GUI dastur bilan) ulanolmaslik.
❌ Port bog'lanishi (`-p`) ko'rsatilmasa, konteyner ichidagi PostgreSQL faqat konteyner ichidan (yoki Docker tarmog'idagi boshqa konteynerlardan) ko'rinadi, kompyuterning o'zidan emas.
✅ To'g'ri: agar kompyuterdan (masalan pgAdmin yoki `psql` orqali) ulanish kerak bo'lsa, `-p 5432:5432` (yoki boshqa bo'sh port) albatta ko'rsatilishi kerak.

## Mashq/topshiriq

**(Oson)** PostgreSQL'ni (Ubuntu'ga to'g'ridan-to'g'ri yoki Docker orqali, xohishingizga ko'ra) o'rnating va `psql -U postgres` (yoki Docker orqali) bilan ulaning, `SELECT version();` buyrug'ini bajarib natijani ko'ring.

**(O'rtacha)** `mashq_bazasi` nomli yangi baza yarating, unga ulaning, ichida `talabalar` nomli jadval yarating (bitta `ism TEXT` ustuni bilan), ikkita qator qo'shing va `SELECT * FROM talabalar;` bilan natijani ko'ring.

**(Qiyin)** `\timing`ni yoqing va `SELECT 1;` kabi oddiy so'rovni bir necha marta bajarib, bajarilish vaqtini kuzating. So'ng `\x` (kengaytirilgan chiqish) rejimini yoqib, `\d talabalar` buyrug'ini ikkala rejimda (yoqilgan va o'chirilgan holatda) solishtirib, farqni tushuntiring.

1. `psql -U postgres` (parol so'ralishi mumkin, standart o'rnatishda mahalliy ulanish uchun ko'pincha parol so'ralmaydi — `peer` autentifikatsiyasi), so'ng `SELECT version();` — natija PostgreSQL versiyasi va operatsion tizim ma'lumotlarini ko'rsatadi.

2.
```sql
CREATE DATABASE mashq_bazasi;
\c mashq_bazasi

```

3. `\timing` yoqilgandan keyin har bir so'rovdan so'ng `Time: 0.421 ms` kabi qator qo'shimcha chiqadi — bu ishlash unumdorligini tekshirishda foydali (13-19-boblarda buni ko'p ishlatamiz). `\x` o'chirilgan holatda `\d talabalar` natijasi **gorizontal jadval** ko'rinishida (ustunlar yonma-yon), `\x` yoqilgan holatda esa **vertikal** ko'rinishda (har bir ustun alohida qatorda, `-[ RECORD 1 ]-` kabi sarlavha bilan) chiqadi — bu ayniqsa ko'p ustunli, keng jadvallarni terminalda o'qish qiyin bo'lganda foydali.

## Qisqacha xulosa

PostgreSQL'ni Ubuntu'ga rasmiy APT repozitoriyasi orqali to'g'ridan-to'g'ri, yoki Docker konteynerida izolyatsiya qilingan holda o'rnatish mumkin — ikkalasi ham keng qo'llaniladi, Docker esa ayniqsa ko'p versiyani sinash yoki tezda o'chirib-yoqish kerak bo'lganda qulay. `psql` — PostgreSQL bilan ishlashning asosiy buyruq qatori vositasi bo'lib, oddiy SQL buyruqlari (`;` bilan tugaydigan) va maxsus meta-buyruqlar (`\` bilan boshlanadigan, `\l`, `\c`, `\dt`, `\d`, `\q` kabi) orqali boshqariladi — bu vositalar butun darslik davomida doimiy ishlatiladi. Keyingi darsda grafik interfeys vositalari (pgAdmin, DBeaver) bilan tanishamiz.
