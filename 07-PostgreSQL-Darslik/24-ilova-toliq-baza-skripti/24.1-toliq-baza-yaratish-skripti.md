# Ilova. `dokon_bazasi` — to'liq yaratish skripti

Ushbu ilova — darslik davomida (1-bobdan boshlab) barcha misollarda ishlatilgan `dokon_bazasi` ma'lumotlar bazasining **to'liq, boshidan oxirigacha ishlaydigan** skripti. 1.1-darsda va'da qilinganidek, bu yerda oltita jadval (`bolimlar`, `mijozlar`, `mahsulotlar`, `xodimlar`, `buyurtmalar`, `buyurtma_elementlari`) — ularning tuzilishi (`CREATE TABLE`) va namuna ma'lumotlari (`INSERT`) bilan birga keltirilgan. Skriptni istalgan yangi, bo'sh PostgreSQL bazasida, yuqoridan pastga qarab, to'liq bajarsangiz — darslikdagi barcha misol va mashqlarni o'zingizning kompyuteringizda qayta ishga tushira olasiz.

## Baza yaratish

```sql
CREATE DATABASE dokon_bazasi;
```

Keyingi barcha buyruqlar `dokon_bazasi` bazasiga ulangan holda bajariladi (`\c dokon_bazasi` — `psql`da, yoki grafik vositangizda mos bazani tanlang).

## 1. Jadvallarni yaratish (`CREATE TABLE`)

Jadvallar, tashqi kalit (`FOREIGN KEY`) bog'liqliklariga ko'ra, quyidagi tartibda yaratiladi: avval bog'liqligi yo'q jadvallar (`bolimlar`, `mijozlar`, `mahsulotlar`), so'ng ularga bog'liq jadvallar (`xodimlar`, `buyurtmalar`), va nihoyat ikkalasiga ham bog'liq jadval (`buyurtma_elementlari`).

```sql
-- Bolimlar (kompaniya bo'limlari)
CREATE TABLE bolimlar (
    id SERIAL PRIMARY KEY,
    nomi VARCHAR(50) NOT NULL,
    joylashuv VARCHAR(50)
);

-- Mijozlar
CREATE TABLE mijozlar (
    id SERIAL PRIMARY KEY,
    ism VARCHAR(50) NOT NULL,
    email VARCHAR(100),
    shahar VARCHAR(50),
    royxatdan_otgan_sana DATE
);

-- Mahsulotlar
CREATE TABLE mahsulotlar (
    id SERIAL PRIMARY KEY,
    nomi VARCHAR(100) NOT NULL,
    narxi NUMERIC(10,2),
    kategoriya VARCHAR(50),
    ombordagi_soni INTEGER
);

-- Xodimlar (bolimlar'ga va o'ziga — boshliq_id orqali — bog'liq)
CREATE TABLE xodimlar (
    id SERIAL PRIMARY KEY,
    ism VARCHAR(50) NOT NULL,
    familiya VARCHAR(50) NOT NULL,
    email VARCHAR(100) UNIQUE,
    lavozim VARCHAR(50),
    bolim_id INTEGER REFERENCES bolimlar(id),
    boshliq_id INTEGER REFERENCES xodimlar(id),
    ish_haqi NUMERIC(10,2),
    ishga_kirgan_sana DATE
);

-- Buyurtmalar (mijozlar'ga bog'liq)
CREATE TABLE buyurtmalar (
    id SERIAL PRIMARY KEY,
    mijoz_id INTEGER REFERENCES mijozlar(id),
    sana DATE,
    holati VARCHAR(20)
);

-- Buyurtma elementlari (buyurtmalar'ga va mahsulotlar'ga bog'liq)
CREATE TABLE buyurtma_elementlari (
    id SERIAL PRIMARY KEY,
    buyurtma_id INTEGER REFERENCES buyurtmalar(id),
    mahsulot_id INTEGER REFERENCES mahsulotlar(id),
    soni INTEGER,
    narx NUMERIC(10,2)
);
```

`xodimlar.boshliq_id` — o'z-o'ziga bog'liq tashqi kalit (**self-referencing foreign key**, 3-bobdagi self-join va 9-bobdagi rekursiv CTE misollarida ishlatiladi): u xodimning bevosita rahbari, ya'ni xuddi shu `xodimlar` jadvalidagi boshqa qatorni ko'rsatadi.

## 3. Ketma-ketliklarni (sequence) to'g'rilash

`id` ustunlariga qiymatlarni **qo'lda** (`SERIAL`ning o'zi avtomatik bermasin deb) kiritganimiz sababli, har bir jadvalning ichki ketma-ketligi (sequence) hali ham `1`da turibdi. Agar shu holatda yangi `INSERT ... (ism, ...) VALUES (...)` (`id`siz) bajarsak, PostgreSQL `id = 1`ni qayta berishga urinib, `UNIQUE`/`PRIMARY KEY` xatosiga uchraydi. Shuning uchun, ma'lumot yuklangandan so'ng, har bir ketma-ketlikni jadvaldagi **eng katta** `id`ga moslab qo'yish shart:

```sql
SELECT setval('bolimlar_id_seq', (SELECT max(id) FROM bolimlar));
SELECT setval('mijozlar_id_seq', (SELECT max(id) FROM mijozlar));
SELECT setval('mahsulotlar_id_seq', (SELECT max(id) FROM mahsulotlar));
SELECT setval('xodimlar_id_seq', (SELECT max(id) FROM xodimlar));
SELECT setval('buyurtmalar_id_seq', (SELECT max(id) FROM buyurtmalar));
SELECT setval('buyurtma_elementlari_id_seq', (SELECT max(id) FROM buyurtma_elementlari));
```

Shundan so'ng, `INSERT INTO mijozlar (ism, ...) VALUES (...)` kabi, `id`ni ko'rsatmasdan yozadigan har qanday yangi qator, avtomatik ravishda `9`, `10`, `11`... tarzida to'g'ri, band qilinmagan `id` oladi.

## Tekshirish

Barcha jadvallar to'g'ri yuklanganini tekshirish uchun:

```sql
SELECT
    (SELECT count(*) FROM bolimlar) AS bolimlar,
    (SELECT count(*) FROM mijozlar) AS mijozlar,
    (SELECT count(*) FROM mahsulotlar) AS mahsulotlar,
    (SELECT count(*) FROM xodimlar) AS xodimlar,
    (SELECT count(*) FROM buyurtmalar) AS buyurtmalar,
    (SELECT count(*) FROM buyurtma_elementlari) AS buyurtma_elementlari;
```

Natija quyidagicha bo'lishi kerak:

```
 bolimlar | mijozlar | mahsulotlar | xodimlar | buyurtmalar | buyurtma_elementlari 
----------+----------+-------------+----------+-------------+----------------------
        5 |        8 |          10 |       10 |           9 |                   12
```

Agar bu qiymatlar mos kelsa — baza, darslikning istalgan darsidagi (1-bobdan 15-bobgacha) misollarni qayta ishga tushirish uchun to'liq tayyor.

**Eslatma:** 16-bobdan boshlab (ICH-ICHIGA qismi — xotira tuzilishi, MVCC, indekslash, WAL, concurrency, replikatsiya, partitioning), ko'plab misollar maxsus, alohida yaratiladigan **vaqtinchalik test jadvallari** (`test_...` prefiksli) ustida ishlaydi — ular har bir darsning "Nazariy qism" bo'limida, kerakli joyda, to'liq `CREATE TABLE` buyrug'i bilan birga keltirilgan, shu sababli ular uchun alohida oldindan tayyorgarlik kerak emas.
