# `__slots__` va zaif havolalar (weak references)

## Bu darsda nimalarni o'rganasiz

- Har bir oddiy Python obyektining nega o'z ichida yashirin `__dict__` olib yurishini va bu qanday xotira narxiga ega ekanini bilib olasiz
- `__slots__` yordamida bu narxni qanday kamaytirishni va qanday cheklovlar paydo bo'lishini o'rganasiz
- **Zaif havola (weak reference)** nima ekanini va u nega reference counting (7.1-dars) muammosini boshqacha, ammo foydali tarzda hal qilishini tushunasiz
- Kesh (cache) va observer naqshlarida `weakref`ning amaliy qo'llanilishini ko'rasiz

## Nazariy qism

### Har bir obyektning "yashirin" xotira narxi

4.1-darsda oddiy klass yaratganingizda, har bir instance o'zining atributlarini qayerda saqlaydi, deb o'ylab ko'rganmisiz? Javob: standart holatda, har bir instance o'zining **shaxsiy `__dict__`** (lug'at)ga ega, va `self.x = 5` yozganingizda, bu aslida `self.__dict__['x'] = 5`ga teng:

```python
class Nuqta:
    def __init__(self, x, y):
        self.x = x
        self.y = y

n = Nuqta(3, 4)
print(n.__dict__)   # {'x': 3, 'y': 4}
```

Bu — juda **moslashuvchan**: istalgan paytda `n.rang = "qizil"` deb, yangi atribut qo'shish mumkin. Lekin bu moslashuvchanlikning narxi bor: **har bir instance** o'z lug'atini olib yuradi, va 10.2-darsda ko'radigan dict — hattoki bo'sh bo'lsa ham — sezilarli xotira egallaydi (odatda kamida bir necha o'nlab bayt, real ma'lumot bo'lmasa ham).

**Manba:** Ushbu dars Python rasmiy hujjatlari (`__slots__` va `weakref` moduli bo'yicha docs.python.org) asosida tuzilgan.

### `__slots__` — dict'siz obyektlar

Agar sizga **millionlab** kichik obyekt yaratish kerak bo'lsa (masalan, katta grafada tugunlar, yoki katta ma'lumotlar to'plamidagi yozuvlar), va siz ularning atributlari **oldindan aniq va qat'iy** ekanini bilsangiz — `__slots__` orqali har bir instance uchun `__dict__`ni butunlay **yo'q qilish** va o'rniga qat'iy, samarali xotira joylashuvidan foydalanish mumkin:

```python
import sys


class NuqtaOddiy:
    def __init__(self, x, y):
        self.x = x
        self.y = y


class NuqtaSlots:
    __slots__ = ('x', 'y')   # FAQAT shu ikkita atribut ruxsat etiladi

    def __init__(self, x, y):
        self.x = x
        self.y = y


oddiy = NuqtaOddiy(3, 4)
slots = NuqtaSlots(3, 4)

print("Oddiy (dict bilan):", sys.getsizeof(oddiy) + sys.getsizeof(oddiy.__dict__))
print("Slots bilan:", sys.getsizeof(slots))
# Slots versiyasi SEZILARLI kamroq xotira oladi — ayniqsa millionlab
# instance yaratilganda, bu farq JAMI xotirada juda katta bo'ladi

try:
    slots.rang = "qizil"   # AttributeError! __dict__ yo'q, yangi atribut qo'shib bo'lmaydi
except AttributeError as e:
    print("Xatolik:", e)
```

### `__slots__` qanday ishlaydi — descriptor orqali

9.1-darsda ko'rgan bilimimiz asosida, `__slots__`ning "sehri" endi tushunarli: Python `__slots__` ro'yxatidagi har bir nom uchun avtomatik ravishda **data descriptor** yaratadi (C darajasida, "member descriptor" deb ataladi), bu descriptor qiymatni to'g'ridan-to'g'ri obyektning **qattiq belgilangan xotira joyida** (`__dict__` lug'atisiz) saqlaydi:

```python
print(NuqtaSlots.x)   # <member 'x' of 'NuqtaSlots' objects> — bu DESCRIPTOR, oddiy qiymat emas!
print(type(NuqtaSlots.x))   # <class 'member_descriptor'>
```

### `__slots__`ning cheklovlari — nega u har doim ishlatilmaydi

`__slots__` kuchli optimallashtirish, lekin bir qancha muhim cheklovlar bilan keladi:

1. **Meros bilan murakkablik:** agar ota-klassda `__slots__` bo'lmasa (yoki bo'sh bo'lmasa), bola klassda ham baribir `__dict__` paydo bo'lishi mumkin — bu optimallashtirish samarasini yo'qqa chiqaradi. To'liq foyda olish uchun **butun meros zanjiri** bo'ylab `__slots__` izchil ishlatilishi kerak.
2. **Klass atributlari bilan ziddiyat:** `__slots__`da ko'rsatilgan nom bilan bir xil nomdagi klass atributini (masalan standart qiymat) belgilash mumkin emas (descriptor va klass atributi bir xil nomga ega bo'lolmaydi).
3. **Ko'p vorislik (multiple inheritance) qiyinlashadi:** ikkita `__slots__`li klassdan bir vaqtning o'zida meros olish, agar ikkalasida ham bo'sh bo'lmagan slotlar bo'lsa, `TypeError` beradi.
4. **`weakref` uchun alohida e'lon kerak** (pastda ko'ramiz).

```python
class BazaviySlots:
    __slots__ = ('x',)

class BolaSlots(BazaviySlots):
    __slots__ = ('y',)   # meros zanjiri bo'ylab __slots__ TO'LIQ e'lon qilingan

b = BolaSlots()
b.x = 1
b.y = 2
try:
    b.z = 3   # baribir AttributeError — chunki HAR IKKALA klass ham __slots__ ishlatgan
except AttributeError as e:
    print("Xatolik:", e)
```

### Zaif havolalar (weak references) — reference counting'ning "yashirin" muammosi

7.1-darsda reference counting'ni ko'rdik: obyektga havola bo'lar ekan, u xotirada qoladi. Lekin ba'zan sizga **"men bu obyektni kuzatib turaman, lekin uni tirik ushlab turishga sabab bo'lmayman"** degan havola kerak bo'ladi. Klassik misol — **kesh** (cache): siz obyektlarni tezkor topish uchun keshda saqlashni xohlaysiz, lekin agar dasturning boshqa hech bir joyida bu obyektga ehtiyoj qolmasa, u xotiradan **chiqib ketishini** ham xohlaysiz — kesh o'zi uni "sun'iy ravishda" tirik ushlab turmasligi kerak.

Aynan shu muammoni **zaif havola (weak reference)** hal qiladi — bu, oddiy havoladan farqli, obyektning `ob_refcnt`ini **oshirmaydi**:

```python
import weakref


class Katta_Obyekt:
    def __init__(self, nom):
        self.nom = nom

    def __del__(self):
        print(f"[O'CHIRILDI] {self.nom}")


obj = Katta_Obyekt("Muhim ma'lumot")

# Oddiy havola:
oddiy = obj
# Zaif havola:
zaif = weakref.ref(obj)

print("Zaif havola orqali obyektga murojaat:", zaif())   # <Katta_Obyekt obyekti>

del obj
del oddiy
# Endi hech qanday ODDIY havola qolmadi -> obyekt DARHOL o'chiriladi,
# "[O'CHIRILDI] Muhim ma'lumot" chop etiladi

print("Zaif havola endi:", zaif())   # None — obyekt allaqachon yo'q qilingan!
```

`weakref.ref(obj)` — bu **chaqiriladigan** obyekt: `zaif()` deb chaqirilganda, agar asl obyekt hali tirik bo'lsa — uni qaytaradi; agar u allaqachon o'chirilgan bo'lsa — `None` qaytaradi. Bu — kesh, kuzatuvchi (observer) va shunga o'xshash naqshlarda **xotira sizib chiqishining (memory leak) oldini olish** uchun juda muhim vosita.

### `WeakValueDictionary` — amaliy kesh naqshi

Standart kutubxonadagi `weakref` moduli tayyor, amaliy vositalarni ham taqdim etadi — masalan, `WeakValueDictionary`, u oddiy lug'atga o'xshaydi, lekin qiymatlariga faqat **zaif** havola saqlaydi:

```python
import weakref


class Sessiya:
    def __init__(self, foydalanuvchi_id):
        self.foydalanuvchi_id = foydalanuvchi_id

    def __del__(self):
        print(f"Sessiya {self.foydalanuvchi_id} tozalandi")


kesh = weakref.WeakValueDictionary()

sessiya1 = Sessiya(101)
kesh[101] = sessiya1   # keshga QO'SHAMIZ, lekin bu keshning o'zi refcountni OSHIRMAYDI

print(101 in kesh)   # True
del sessiya1           # oddiy havola yo'qolgan zahoti, kesh HAM avtomatik "unutadi"
print(101 in kesh)   # False — kesh o'zi obyektni tirik ushlab turmadi!
```

### `__slots__` bilan `weakref` birga ishlatilganda

Agar klassda `__slots__` ishlatilsa, zaif havolalarni qo'llab-quvvatlash uchun **alohida, aniq** e'lon qilish kerak — chunki `__dict__` bo'lmasa, obyektga zaif havola saqlash uchun ham maxsus joy kerak:

```python
class SlotliVaZaifHavolaBilan:
    __slots__ = ('qiymat', '__weakref__')   # __weakref__ ni ANIQ qo'shish kerak!

    def __init__(self, qiymat):
        self.qiymat = qiymat


import weakref
obj = SlotliVaZaifHavolaBilan(42)
zaif = weakref.ref(obj)   # __weakref__ e'lon qilinmasa, bu TypeError beradi!
print(zaif().qiymat)
```

## Amaliy misol

Katta miqdorda obyekt yaratishda `__slots__`ning real xotira/tezlik ta'sirini o'lchash, va zaif havola asosida oddiy kesh yaratish:

```python
# slots_weakref_demo.py
import sys
import time
import weakref


class NuqtaOddiy:
    def __init__(self, x, y):
        self.x = x
        self.y = y


class NuqtaSlots:
    __slots__ = ('x', 'y')

    def __init__(self, x, y):
        self.x = x
        self.y = y


def xotira_va_tezlik_taqqoslash(soni=500_000):
    boshlanish = time.perf_counter()
    oddiylar = [NuqtaOddiy(i, i) for i in range(soni)]
    oddiy_vaqt = time.perf_counter() - boshlanish

    boshlanish = time.perf_counter()
    slotlilar = [NuqtaSlots(i, i) for i in range(soni)]
    slots_vaqt = time.perf_counter() - boshlanish

    print(f"{soni:,} ta obyekt yaratish:")
    print(f"  Oddiy klass: {oddiy_vaqt:.4f} soniya")
    print(f"  __slots__ bilan: {slots_vaqt:.4f} soniya")
    print(f"  Bitta obyekt xotirasi (oddiy, taxminiy): "
          f"{sys.getsizeof(oddiylar[0]) + sys.getsizeof(oddiylar[0].__dict__)} bayt")
    print(f"  Bitta obyekt xotirasi (slots): {sys.getsizeof(slotlilar[0])} bayt")


class ObyektKeshi:
    """weakref.WeakValueDictionary asosidagi oddiy, avtomatik tozalanuvchi kesh."""

    def __init__(self):
        self._kesh = weakref.WeakValueDictionary()

    def olish_yoki_yaratish(self, kalit, yaratuvchi_funksiya):
        if kalit in self._kesh:
            print(f"[KESH] '{kalit}' keshdan olindi")
            return self._kesh[kalit]
        yangi = yaratuvchi_funksiya()
        self._kesh[kalit] = yangi
        print(f"[KESH] '{kalit}' yangi yaratildi va keshga qo'shildi")
        return yangi


if __name__ == "__main__":
    xotira_va_tezlik_taqqoslash()

    print("\n--- Kesh demo ---")
    kesh = ObyektKeshi()

    natija1 = kesh.olish_yoki_yaratish("A", lambda: NuqtaOddiy(1, 1))
    natija2 = kesh.olish_yoki_yaratish("A", lambda: NuqtaOddiy(999, 999))  # keshdan qaytishi kerak
    print("Ikkalasi bir xil obyektmi:", natija1 is natija2)

    del natija1
    del natija2
    # Endi "A" ga hech qanday ODDIY havola qolmadi -> kesh AVTOMATIK tozalanadi
    natija3 = kesh.olish_yoki_yaratish("A", lambda: NuqtaOddiy(5, 5))
    print("Uchinchi murojaat YANGI obyekt yaratdimi (chunki eski o'chgan edi):", natija3.x == 5)
```

## Keng tarqalgan xatolar

**Xato 1:** `__slots__`ni "har doim, hamma klassda" ishlatish kerak deb o'ylash.
❌ Kichik dasturdagi, atigi bir necha marta yaratiladigan klasslarda ham `__slots__`ni "eng yaxshi amaliyot" sifatida majburiy qo'llash.
✅ To'g'ri: `__slots__`ning foydasi faqat **ko'p sonli** (o'nlab minglab yoki millionlab) instance yaratilganda sezilarli bo'ladi. Kam sonli obyektlar uchun bu — moslashuvchanlikni (dinamik atribut qo'shish, ba'zi introspeksiya vositalari bilan mosligini) yo'qotib, kam foyda beradigan murakkablik qo'shish, xolos. Har doim — avval o'lchang (13-bob), keyin qaror qiling.

**Xato 2:** Zaif havolani (`weakref.ref(obj)`) oddiy havoladek ishlatib, `None` bo'lish ehtimolini tekshirmaslik.
❌
```python
zaif = weakref.ref(obj)
del obj
print(zaif().biror_atribut)   # AttributeError: 'NoneType' object has no attribute...
```
✅ To'g'ri: zaif havoladan foydalanishdan oldin, har doim uni chaqirib, natija `None` emasligini tekshiring: `qiymat = zaif(); if qiymat is not None: ...`.

**Xato 3:** `__slots__` bilan klassda `weakref`ni unutib, keyin `weakref.ref()` chaqirilganda kutilmagan xatoga duch kelish.
❌
```python
class Sinov:
    __slots__ = ('x',)   # __weakref__ yo'q!

s = Sinov(); s.x = 1
zaif = weakref.ref(s)   # TypeError: cannot create weak reference to 'Sinov' object
```
✅ To'g'ri: agar `__slots__`li klassga zaif havola kerak bo'lsa, `__slots__` ro'yxatiga aniq `'__weakref__'`ni qo'shing (yuqoridagi amaliy misolda ko'rganingizdek).

## Mashq/topshiriq

**(Oson)** `__slots__ = ('nom', 'yosh')` bilan `Talaba` klassini yozing. Instance yarating, `nom` va `yosh`ni bering, so'ng yangi, ro'yxatda bo'lmagan atribut (`fakultet`) qo'shishga urinib, `AttributeError` chiqishini tasdiqlang.

**(O'rtacha)** `weakref.ref()` yordamida oddiy "obyekt tirikligini kuzatuvchi" funksiya yozing: u obyektni qabul qiladi, unga zaif havola yaratadi, va sizga vaqti-vaqti bilan (masalan, `time.sleep(1)` bilan 3 marta) "obyekt hali tirikmi?" deb tekshirib, natijani chop etishga imkon beradi. Obyektni asosiy dastur qismida `del` qilib, kuzatuvchi buni qanday payqashini ko'ring.

**(Qiyin)** Ikki xil versiyada (bittasi oddiy klass, ikkinchisi `__slots__` bilan) 2,000,000 ta oddiy `(x, y)` juftlik saqlovchi obyekt yarating va `tracemalloc` bilan ikkalasining **umumiy** xotira sarfini solishtiring. ## Qisqacha xulosa

Har bir oddiy Python obyekti standart holatda o'zining shaxsiy `__dict__`ini olib yuradi — bu moslashuvchan, lekin ko'p sonli obyektlar uchun xotira jihatidan qimmat; `__slots__` bu `__dict__`ni descriptor-asosli, qat'iy belgilangan xotira joylashuviga almashtirib, sezilarli xotira va biroz tezlik yutug'ini beradi, biroq dinamik atribut qo'shish imkoniyatini va ba'zi meros holatlarining soddaligini yo'qotadi. **Zaif havola** (`weakref`) esa reference counting mexanizmiga (7.1-dars) "obyektga ishora qiluvchi, lekin uni tirik ushlab turmaydigan" havola turini qo'shadi — bu kesh, kuzatuvchi va shunga o'xshash naqshlarda xotira sizib chiqishining oldini olish uchun asosiy vosita hisoblanadi.

Ushbu darsni yakunlab, 09-bob — Python'ning "data model" deb ataluvchi eng chuqur qatlamini (descriptor, MRO/super, metaclass, slots/weakref) to'liq qamrab oldik. Keyingi, 10-bobda esa siz kundalik ishlatadigan `list`, `dict`, `str` kabi tuzilmalarning haqiqiy, C darajasidagi ichki implementatsiyasiga o'tamiz.
