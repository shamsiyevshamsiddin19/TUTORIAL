# Prototype naqshi

## Bu darsda nimalarni o'rganasiz

- Prototype naqshining qaysi muammoni (qimmat yoki murakkab obyektni nolidan yaratish o'rniga nusxalash) hal qilishini tushunasiz
- Python'ning `copy` moduli (`copy.copy` va `copy.deepcopy`) orqali Prototype naqshini tabiiy qo'llay olasiz
- "Shallow copy" va "deep copy" o'rtasidagi farqni va bu farqning Prototype uchun nega hal qiluvchi ahamiyatga ega ekanini tushunasiz
- `__copy__` va `__deepcopy__` magic metodlarini qayta belgilab, nusxalash xatti-harakatini moslashtira olasiz

## Nazariy qism

### Muammo — obyektni nolidan yaratish qimmat yoki murakkab bo'lganda

Ba'zan yangi obyekt yaratish — oddiy `Klass()` chaqirish emas, balki **qimmat** (masalan, tarmoqdan ma'lumot olish, fayldan o'qish, murakkab hisob-kitob) yoki **murakkab** (ko'p sonli, bir-biriga bog'liq ichki holatlarni to'g'ri sozlash kerak) jarayon bo'ladi.

Agar sizda **allaqachon tayyor, to'liq sozlangan** obyekt bo'lsa va sizga unga **juda o'xshash, kichik farqlari bo'lgan** yangi obyekt kerak bo'lsa — uni **nolidan qayta yaratishdan ko'ra**, mavjud obyektni **nusxalab**, so'ngra kerakli joylarini o'zgartirish ancha tezroq va ishonchliroq bo'ladi.

**Prototype naqshi** — aynan shu g'oyani ifodalaydi: obyektlar o'zlarini **nusxalash** (clone) qobiliyatiga ega bo'ladi, va yangi obyektlar konstruktor orqali emas, **mavjud "namuna" (prototype) obyektni nusxalash** orqali yaratiladi.

### Python'da Prototype — `copy` moduli bilan tabiiy yechim

Ko'p tillarda Prototype naqshi uchun klassda alohida `clone()` metodi yozish kerak bo'ladi. Python'da esa standart kutubxonadagi **`copy` moduli** bu vazifani deyarli **til darajasida** hal qilib beradi:

```python
import copy
from dataclasses import dataclass, field


@dataclass
class Foydalanuvchiprofil:
    ism: str
    sozlamalar: dict = field(default_factory=dict)


asl = Foydalanuvchiprofil(ism="Ali", sozlamalar={"til": "o'zbek", "tema": "qorong'u"})

# copy.copy() — "shallow copy" (yuzaki nusxa)
nusxa = copy.copy(asl)
nusxa.ism = "Vali"           # bu — mustaqil, asl obyektga ta'sir qilmaydi

print(asl.ism, nusxa.ism)    # Ali Vali — ikkisi MUSTAQIL
```

Bu yerda `copy.copy(asl)` — yangi `Foydalanuvchiprofil` obyekti yaratadi, uning **yuzaki (top-level)** atributlari (`ism`) mustaqil bo'ladi. Lekin **ichki, mutable** obyektlar (bu yerda `sozlamalar` lug'ati) haqida ehtiyot bo'lish kerak — bu keyingi bo'limda ko'riladi.

### Shallow copy va deep copy — hal qiluvchi farq

Bu — Prototype naqshini to'g'ri qo'llashdagi **eng muhim** tushuncha, va ko'p xatolarning sababi aynan shu farqni bilmaslikdan kelib chiqadi:

```python
import copy

asl = Foydalanuvchiprofil(ism="Ali", sozlamalar={"til": "o'zbek", "tema": "qorong'u"})

# --- SHALLOW COPY — faqat YUZAKI darajani nusxalaydi, ICHKI mutable obyektlar UMUMIY qoladi ---
yuzaki_nusxa = copy.copy(asl)
yuzaki_nusxa.sozlamalar["tema"] = "yorug'"     # bu — ICHKI lug'atni o'zgartiradi!

print(asl.sozlamalar)          # {'til': "o'zbek", 'tema': "yorug'"} — ASL OBYEKT HAM o'zgardi!
print(asl.sozlamalar is yuzaki_nusxa.sozlamalar)   # True — ikkisi AYNAN BIR XIL lug'atga ishora qiladi!


# --- DEEP COPY — ICHKI obyektlarni ham REKURSIV ravishda to'liq nusxalaydi ---
asl2 = Foydalanuvchiprofil(ism="Ali", sozlamalar={"til": "o'zbek", "tema": "qorong'u"})
chuqur_nusxa = copy.deepcopy(asl2)
chuqur_nusxa.sozlamalar["tema"] = "yorug'"

print(asl2.sozlamalar)         # {'til': "o'zbek", 'tema': "qorong'u"} — ASL OBYEKT O'ZGARMADI!
print(asl2.sozlamalar is chuqur_nusxa.sozlamalar)   # False — ikkisi MUSTAQIL lug'atlar
```

**Xulosa:** `copy.copy()` — faqat **birinchi darajadagi** obyektni nusxalaydi, ichidagi mutable obyektlarga (list, dict, boshqa obyektlar) **havolalar** (reference) bir xil qolади. `copy.deepcopy()` — **butun obyekt grafini rekursiv ravishda** to'liq, mustaqil nusxalaydi. Prototype naqshini qo'llashda, agar obyektingiz ichida mutable (o'zgaruvchan) ichki holat bo'lsa, **deyarli har doim `deepcopy` kerak bo'ladi** — aks holda nusxalar bir-biriga "yashirin ta'sir qiladi", bu esa topish qiyin bo'lgan xatolarga olib keladi.

### `__copy__` va `__deepcopy__` — nusxalash xatti-harakatini moslashtirish

Ba'zan standart nusxalash xatti-harakati **yetarli emas** — masalan, obyekt ichida ulanish (fayl, tarmoq) bo'lsa, uni nusxalashda **qayta yaratish** kerak, "nusxalash" emas. Shu uchun Python magic metodlar (bu — 4.4-darsda ko'rgan magic metodlar oilasining davomi) orqali moslashtirish imkonini beradi:

```python
import copy


class Hujjat:
    def __init__(self, matn: str, versiya: int = 1):
        self.matn = matn
        self.versiya = versiya
        self.id = id(self)       # soddalashtirilgan "noyob identifikator" simulyatsiyasi

    def __copy__(self):
        """Nusxa olinganda versiya avtomatik OSHIRILSIN — bu MAXSUS biznes qoida."""
        yangi = Hujjat(self.matn, self.versiya + 1)
        print(f"Hujjat nusxalandi: versiya {self.versiya} -> {yangi.versiya}")
        return yangi

    def __deepcopy__(self, memo):
        """memo — rekursiv tsikllarning oldini olish uchun ishlatiladigan lug'at (deepcopy ICHKI mexanizmi)."""
        yangi = Hujjat(copy.deepcopy(self.matn, memo), self.versiya + 1)
        return yangi


hujjat1 = Hujjat("Shartnoma matni")
hujjat2 = copy.copy(hujjat1)     # __copy__ AVTOMATIK chaqiriladi
print(hujjat2.versiya)            # Hujjat nusxalandi: versiya 1 -> 2  /  keyin: 2
```

Bu yerda `memo` parametri — `deepcopy`ning **ichki mexanizmi**: agar obyekt grafida **tsikl** bo'lsa (A obyekt B'ga, B esa qayta A'ga ishora qilsa), `memo` lug'ati allaqachon nusxalangan obyektlarni eslab qolib, **cheksiz rekursiyaning oldini oladi**.

### Real dunyoda qayerda ishlatiladi

- **O'yin dasturlash** — xarita (map) yoki "dushman" (enemy) shablonini bir marta sozlab, keyin o'yin davomida ko'plab nusxalarini (`deepcopy` orqali) tezda yaratish, har safar nolidan sozlashdan ko'ra ancha tezroq.
- **Konfiguratsiya shablonlari** — asosiy (`default`) konfiguratsiya obyektini bir marta tayyorlab, har bir muhit (dev/staging/prod) uchun uni nusxalab, kerakli joylarini o'zgartirish.
- **`sklearn` (machine learning)** — model obyektlarini `clone()` qilish (bu funksiya ichida aynan `copy.deepcopy`ga o'xshash mexanizm ishlaydi) — bir xil sozlamalar bilan, lekin mustaqil holatga ega yangi model nusxasini olish uchun.

## Amaliy misol

To'liq misol — o'yin xarakterlari uchun "shablon" (prototype) asosida tezkor nusxalash tizimi:

```python
# xarakter_prototype.py
import copy
from dataclasses import dataclass, field


@dataclass
class Qurol:
    nomi: str
    zarar: int


@dataclass
class Xarakter:
    turi: str
    jon: int
    tezlik: int
    qurollar: list[Qurol] = field(default_factory=list)

    def nusxa_yarat(self) -> "Xarakter":
        """Prototype metodi — obyektning o'zi o'zini DEEP COPY orqali nusxalaydi."""
        return copy.deepcopy(self)


# --- Shablonlarni (prototiplarni) BIR MARTA, batafsil sozlaymiz ---
jangchi_shabloni = Xarakter(turi="Jangchi", jon=150, tezlik=5,
                             qurollar=[Qurol("Qilich", 25), Qurol("Qalqon", 0)])

sehrgar_shabloni = Xarakter(turi="Sehrgar", jon=80, tezlik=7,
                             qurollar=[Qurol("Tayoq", 35)])


# --- O'yinda 3 ta jangchi va 2 ta sehrgar kerak bo'lsa — SHABLONLARDAN tezda nusxalaymiz ---
jangchilar = [jangchi_shabloni.nusxa_yarat() for _ in range(3)]
sehrgarlar = [sehrgar_shabloni.nusxa_yarat() for _ in range(2)]

# Har bir nusxa — MUSTAQIL, ichki qurollar ro'yxatini o'zgartirish boshqalarga ta'sir qilmaydi:
jangchilar[0].qurollar.append(Qurol("Kamon", 15))

print(f"1-jangchi qurollari: {[q.nomi for q in jangchilar[0].qurollar]}")
print(f"2-jangchi qurollari: {[q.nomi for q in jangchilar[1].qurollar]}")
print(f"Shablon qurollari (o'zgarmagan): {[q.nomi for q in jangchi_shabloni.qurollar]}")
# 1-jangchi qurollari: ['Qilich', 'Qalqon', 'Kamon']
# 2-jangchi qurollari: ['Qilich', 'Qalqon']
# Shablon qurollari (o'zgarmagan): ['Qilich', 'Qalqon']

# Agar deepcopy O'RNIGA copy.copy (shallow) ishlatilgan bo'lsa edi,
# jangchilar[0].qurollar.append(...) BARCHA jangchilarning qurollar ro'yxatiga
# va hatto shablonning o'ziga ham ta'sir qilib, kutilmagan xatolarga olib kelardi.
```

## Keng tarqalgan xatolar

**Xato 1:** mutable ichki holatga ega obyektlarda `copy.deepcopy()` o'rniga `copy.copy()` ishlatish.
❌ Yuqoridagi "Shallow copy va deep copy" bo'limidagi misoldagi kabi — ichki lug'at/ro'yxatni o'zgartirish **asl obyektga ham** ta'sir qiladi, bu juda sezilmaydigan, "qayerdan kelib chiqdi?" degan savol tug'diradigan xatolarga olib keladi.
✅ To'g'ri: agar obyekt ichida mutable atribut (list, dict, boshqa obyekt) bo'lsa va nusxalar **to'liq mustaqil** bo'lishi kerak bo'lsa, har doim `copy.deepcopy()`dan foydalaning.

**Xato 2:** `__init__`dagi barcha boshlang'ich sozlashni (fayldan o'qish, tarmoq so'rovi) nusxalashda ham qayta bajarilishiga yo'l qo'yish.
❌
```python
class MalumotYuklaguvchi:
    def __init__(self, fayl_nomi):
        self.malumot = self._fayldan_oqi(fayl_nomi)    # qimmat operatsiya!

# copy.copy()/deepcopy() __init__ni QAYTA chaqirmaydi — bu TO'G'RI,
# lekin agar __copy__ qo'lda yozilsa va ichida __init__ chaqirilsa — qimmat operatsiya TAKRORLANADI
class YomonPrototype(MalumotYuklaguvchi):
    def __copy__(self):
        return MalumotYuklaguvchi(self.fayl_nomi)   # bu — Prototype emas, QAYTA YARATISH!
```
✅ To'g'ri: `__copy__`/`__deepcopy__` ichida **yangi `__init__` chaqirmasdan**, allaqachon mavjud ma'lumotni **to'g'ridan-to'g'ri nusxalash** (masalan, `copy.deepcopy(self.malumot)`) — bu naqshning asosiy maqsadi (qimmat operatsiyani **qayta bajarmaslik**) bilan mos keladi.

**Xato 3:** `__deepcopy__`da `memo` parametrini e'tiborsiz qoldirish.
❌
```python
def __deepcopy__(self, memo):
    return Klass(copy.deepcopy(self.malumot))   # memo ICHKI deepcopy chaqiriqqa UZATILMADI!
```
Agar obyekt grafida tsiklik havolalar bo'lsa, bu **cheksiz rekursiya**ga (`RecursionError`) olib kelishi mumkin.
✅ To'g'ri: har doim `memo`ni ichki `copy.deepcopy(qiymat, memo)` chaqiriqlariga ham uzating — bu `deepcopy`ning tsiklik havolalarni to'g'ri aniqlashini ta'minlaydi.

## Mashq/topshiriq

**(Oson)** `Mashina` dataclassini (`model: str`, `rang: str`, `aksessuarlar: list[str]`) yarating va `nusxa_yarat()` metodi orqali uning `deepcopy` asosidagi Prototype metodini yozing. Ikki nusxa yaratib, birining `aksessuarlar`iga element qo'shib, ikkinchisiga ta'sir qilmasligini tekshiring.

**(O'rtacha)** Quyidagi kodda qanday muammo borligini aniqlang va `copy` modulidan foydalanib to'g'rilang:
```python
class Savat:
    def __init__(self):
        self.tovarlar = []

savat1 = Savat()
savat1.tovarlar.append("Olma")
import copy
savat2 = copy.copy(savat1)
savat2.tovarlar.append("Nok")
print(savat1.tovarlar)   # kutilmagan natija qaytaradi — nega?
```

**(Qiyin)** `KonfiguratsiyaShabloni` klassini yozing: unda `sozlamalar: dict` va `manbalar: list[str]` atributlari bo'lsin. `__deepcopy__` metodini **qo'lda** yozing (memo parametri bilan to'g'ri), unda nusxalanish paytida avtomatik `versiya` hisoblagichi (klass darajasidagi `_versiya_hisoblagich` orqali) oshirilsin va har bir nusxaga noyob `versiya` atributi berilsin.

class KonfiguratsiyaShabloni:
    _versiya_hisoblagich = 0

    def __init__(self, sozlamalar: dict, manbalar: list[str]):

## Qisqacha xulosa

Prototype naqshi — qimmat yoki murakkab obyektlarni nolidan qayta yaratish o'rniga, tayyor "namuna" (prototype) obyektni nusxalab, so'ngra kerakli joylarini o'zgartirish g'oyasiga asoslanadi; Python'da bu naqsh standart `copy` moduli (`copy.copy()` — shallow, `copy.deepcopy()` — rekursiv to'liq nusxa) orqali til darajasida tabiiy qo'llab-quvvatlanadi, va `__copy__`/`__deepcopy__` magic metodlari orqali nusxalash xatti-harakati moslashtirilishi mumkin; bu naqshni to'g'ri qo'llashdagi eng muhim nuqta — obyekt ichidagi **mutable** holatni nusxalashda shallow va deep copy farqini aniq tushunish, aks holda nusxalar bir-biriga yashirin ta'sir qiladigan xatolar yuzaga keladi.
