# Composite naqshi

## Bu darsda nimalarni o'rganasiz

- Composite naqshi daraxt-shaklidagi tuzilmalarni qanday soddalashtirishini tushuntira olasiz
- Yakka (Leaf) va guruh (Composite) obyektlarni **bir xil interfeys** orqali, farqlamasdan ishlata olasiz
- Rekursiya Composite naqshi bilan qanday tabiiy bog'langanini bilasiz
- O'z daraxt-tuzilmangizni (fayl tizimi, menyu, tashkiliy tuzilma) loyihalay olasiz
- Composite'ning qachon ortiqcha murakkablik keltirishini (kamchiliklarini) bilasiz

## Nazariy qism

### Composite nima — asosiy g'oya

**Composite** (tarkibiy) naqshi — obyektlarni **daraxt** shaklida tashkil etish, shunda mijoz kodi **yakka element**ni (leaf) ham, **elementlar guruhini** (composite, o'zi ham boshqa elementlarni o'z ichiga oladi) ham **aynan bir xil interfeys** orqali ishlata oladi, ularni farqlamasdan.

Haqiqiy hayotdagi o'xshatish — fayl tizimi: siz `papka.hajmi()` deb so'raganingizda, siz bilishingiz shart emaski, u bitta fayl yoki ichida yana yuzlab fayl/papkalarni saqlagan katta papka — natija bir xil usulda, rekursiv ravishda hisoblanadi.

### Tuzilma — Component, Leaf, Composite

Composite naqshi uch asosiy qismdan iborat:

1. **Component** — umumiy interfeys (abstrakt klass), Leaf ham, Composite ham shu interfeysga amal qiladi.
2. **Leaf** — daraxtning "barg"i — ichida boshqa elementlar bo'lmaydigan yakka obyekt.
3. **Composite** — ichida boshqa Component'larning (Leaf yoki yana Composite) ro'yxatini saqlaydigan "tugun" (node) — o'zining metodlari odatda **bolalariga chaqiriqni tarqatib, natijalarni birlashtiradi** (rekursiya!).

```python
from abc import ABC, abstractmethod


class FaylTizimiElementi(ABC):      # Component — umumiy interfeys
    @abstractmethod
    def hajmi(self) -> int: ...

    @abstractmethod
    def korsat(self, chekinish: int = 0) -> None: ...


class Fayl(FaylTizimiElementi):     # Leaf — "barg", bolalari yo'q
    def __init__(self, nomi: str, hajmi_bayt: int) -> None:
        self.nomi = nomi
        self._hajmi = hajmi_bayt

    def hajmi(self) -> int:
        return self._hajmi                       # bazaviy holat — to'g'ridan-to'g'ri qiymat

    def korsat(self, chekinish: int = 0) -> None:
        print(" " * chekinish + f"📄 {self.nomi} ({self._hajmi} bayt)")


class Papka(FaylTizimiElementi):    # Composite — bolalarni saqlaydi
    def __init__(self, nomi: str) -> None:
        self.nomi = nomi
        self._elementlar: list[FaylTizimiElementi] = []

    def qosh(self, element: FaylTizimiElementi) -> None:
        self._elementlar.append(element)         # Fayl HAM, Papka HAM qo'shilishi mumkin!

    def hajmi(self) -> int:
        # REKURSIYA — har bir bolaning hajmi so'raladi, u Fayl yoki Papka bo'lishi muhim emas
        return sum(element.hajmi() for element in self._elementlar)

    def korsat(self, chekinish: int = 0) -> None:
        print(" " * chekinish + f"📁 {self.nomi}/")
        for element in self._elementlar:
            element.korsat(chekinish + 2)         # rekursiv chaqiriq — chekinishni oshirib
```

### Mijoz kodi — farqlamasdan ishlatish

```python
hujjatlar = Papka("Hujjatlar")
hujjatlar.qosh(Fayl("rezyume.pdf", 50_000))
hujjatlar.qosh(Fayl("xat.docx", 20_000))

suratlar = Papka("Suratlar")
suratlar.qosh(Fayl("tatil.jpg", 3_000_000))
suratlar.qosh(Fayl("oila.png", 2_500_000))

bosh_papka = Papka("Mening_fayllarim")
bosh_papka.qosh(hujjatlar)       # Papka Papkaga qo'shiladi
bosh_papka.qosh(suratlar)        # Papka Papkaga qo'shiladi
bosh_papka.qosh(Fayl("eslatma.txt", 500))   # Fayl ham to'g'ridan-to'g'ri qo'shiladi

bosh_papka.korsat()
# 📁 Mening_fayllarim/
#   📁 Hujjatlar/
#     📄 rezyume.pdf (50000 bayt)
#     📄 xat.docx (20000 bayt)
#   📁 Suratlar/
#     📄 tatil.jpg (3000000 bayt)
#     📄 oila.png (2500000 bayt)
#   📄 eslatma.txt (500 bayt)

print(f"Jami hajm: {bosh_papka.hajmi()} bayt")
# Jami hajm: 5570500 bayt
```

E'tibor bering: mijoz kodi (yoki `Papka.hajmi()` ning o'zi) hech qachon "bu Fayl, shunday hisoblayman; bu Papka, boshqacha hisoblayman" deb **tekshirmaydi** (`isinstance` yo'q!) — bu Composite naqshining butun mohiyati: **bir xil chaqiriq, ikki xil (yoki cheksiz chuqur) real tuzilma**.

### Nega bu muhim — murojaat qilmaslik tamoyili (uniform treatment)

Composite'siz, ushbu kod tipik ravishda shunday ko'rinardi:

```python
def hajmini_hisobla(element):
    if isinstance(element, Fayl):
        return element.hajmi_bayt
    elif isinstance(element, Papka):
        jami = 0
        for ichki in element.elementlar:
            jami += hajmini_hisobla(ichki)     # qo'lda rekursiya, qo'lda tur tekshirish
        return jami
```

Bu kod ishlaydi, lekin har safar yangi tur (masalan, `Yorliq` — symlink) qo'shilganda, **shu `if/elif` zanjirini topib, unga yangi shart qo'shish** kerak bo'ladi — bu Ochiq/Yopiq tamoyilini (Open/Closed Principle) buzadi. Composite naqshida esa yangi tur qo'shish — shunchaki yangi klass yozib, `FaylTizimiElementi`dan meros olish, **mavjud kodni o'zgartirmasdan**.

### Qachon ishlatiladi — real hayotiy misollar

- **GUI widget daraxtlari** — `tkinter`, Qt, HTML DOM: `Window` ichida `Panel`lar, `Panel` ichida `Button`/`Label`lar — har biri `render()` metodiga ega, va `Panel.render()` barcha bolalariga `render()`ni chaqiradi.
- **Tashkiliy tuzilma** — `Xodim.ish_haqi_jami()` — oddiy xodim uchun o'zining ish haqi, menejer uchun — o'zining + barcha bo'ysunuvchilarining ish haqi yig'indisi.
- **Matematik ifodalar daraxti** — `(2 + 3) * (4 - 1)` kabi ifoda — `Son` (Leaf) va `Amal` (Composite, chap/o'ng operandlarni saqlaydi) orqali qurilib, `baholash()` rekursiv chaqiriladi.
- **JSON/XML tuzilmalari** — ichma-ich lug'at/ro'yxatlar — har bir tugun o'zi ham qiymat, ham boshqa tugunlar konteyneri bo'la oladi.

## Amaliy misol

Menyu tizimi — kategoriyalar (Composite) va taomlar (Leaf) orqali umumiy narxni hisoblash:

```python
# menyu_composite.py
from abc import ABC, abstractmethod


class MenyuElementi(ABC):
    @abstractmethod
    def narxi(self) -> float: ...

    @abstractmethod
    def chop_et(self, chekinish: int = 0) -> None: ...


class Taom(MenyuElementi):
    def __init__(self, nomi: str, narx: float) -> None:
        self.nomi = nomi
        self._narx = narx

    def narxi(self) -> float:
        return self._narx

    def chop_et(self, chekinish: int = 0) -> None:
        print(" " * chekinish + f"- {self.nomi}: {self._narx:,.0f} so'm")


class Kategoriya(MenyuElementi):
    def __init__(self, nomi: str) -> None:
        self.nomi = nomi
        self._elementlar: list[MenyuElementi] = []

    def qosh(self, element: MenyuElementi) -> "Kategoriya":
        self._elementlar.append(element)
        return self                       # method chaining uchun self qaytarish

    def narxi(self) -> float:
        return sum(e.narxi() for e in self._elementlar)

    def chop_et(self, chekinish: int = 0) -> None:
        print(" " * chekinish + f"## {self.nomi}")
        for element in self._elementlar:
            element.chop_et(chekinish + 2)


# Daraxt qurish — Kategoriya ichida yana Kategoriya bo'lishi mumkin
ichimliklar = Kategoriya("Ichimliklar").qosh(Taom("Choy", 5_000)).qosh(Taom("Qahva", 15_000))

issiq_taomlar = (Kategoriya("Issiq taomlar")
                 .qosh(Taom("Osh", 35_000))
                 .qosh(Taom("Lagmon", 30_000)))

kombo = (Kategoriya("Kombo-to'plam #1")      # Kombo ICHIDA boshqa Kategoriyalar!
         .qosh(issiq_taomlar)
         .qosh(ichimliklar))

bosh_menyu = Kategoriya("Restoran menyusi").qosh(kombo).qosh(Taom("Non", 3_000))

bosh_menyu.chop_et()
# ## Restoran menyusi
#   ## Kombo-to'plam #1
#     ## Issiq taomlar
#       - Osh: 35,000 so'm
#       - Lagmon: 30,000 so'm
#     ## Ichimliklar
#       - Choy: 5,000 so'm
#       - Qahva: 15,000 so'm
#   - Non: 3,000 so'm

print(f"Umumiy narx: {bosh_menyu.narxi():,.0f} so'm")
# Umumiy narx: 88,000 so'm
```

`Kombo-to'plam` o'zi ham `Kategoriya` (ya'ni Composite) bo'lib, ichida yana ikki `Kategoriya`ni (ularning har biri yana `Taom`larni) saqlaydi — daraxt necha qavat chuqur bo'lishi muhim emas, `narxi()` va `chop_et()` har doim to'g'ri ishlaydi, chunki ular **rekursiv** qurilgan.

## Keng tarqalgan xatolar

**Xato 1:** Composite va Leaf uchun `isinstance` tekshiruvlarini qo'llash.
❌
```python
def jami_hajm(element):
    if isinstance(element, Papka):
        return sum(jami_hajm(e) for e in element.elementlar)
    return element.hajmi_bayt
```
Bu Composite naqshining butun maqsadini yo'qqa chiqaradi — yangi tur qo'shilganda shu funksiyani o'zgartirish kerak bo'ladi.
✅ To'g'ri: umumiy `Component` interfeysidagi metodga (`hajmi()`) tayaning, `isinstance` ishlatmang — har bir klass o'zining `hajmi()` metodida o'z mantig'ini (bazaviy qiymat yoki rekursiya) amalga oshirsin.

**Xato 2:** Leaf klassga, unga mos kelmaydigan Composite-ga xos metodlarni (`qosh()`, `olib_tashla()`) ham qo'shib qo'yish.
❌
```python
class Fayl(FaylTizimiElementi):
    def qosh(self, element):     # Fayl ichiga boshqa narsa QO'SHILMAYDI!
        raise NotImplementedError("Faylga element qo'shib bo'lmaydi")
```
Bu mijoz kodida kutilmaganda `AttributeError`/`NotImplementedError` chiqishiga olib keladi, chunki Leaf obyekt Composite'ga xos metodga ega bo'lib ko'rinadi, lekin aslida ishlamaydi.
✅ To'g'ri: `qosh()`/`olib_tashla()` metodlarini faqat `Papka` (Composite) klassida aniqlang, umumiy `Component` interfeysiga qo'ymang — shunda `Fayl` obyektida bu metod umuman mavjud bo'lmaydi, va bu xatoni **loyihalash darajasida**, runtime xatosiz oldini oladi.

**Xato 3:** Siklik (cyclic) tuzilma yaratib qo'yish — Papka o'z-o'zini (bevosita yoki bolalari orqali) ichiga qo'shib yuborish.
❌
```python
papka_a.qosh(papka_b)
papka_b.qosh(papka_a)    # SIKL! hajmi() cheksiz rekursiyaga tushadi
```
✅ To'g'ri: `qosh()` metodida (ayniqsa, foydalanuvchi kiritadigan ierarxiyalarda) elementni qo'shishdan oldin, u allaqachon ota-ajdodlar zanjirida bor-yo'qligini tekshiring, yoki hech bo'lmaganda rekursiya chuqurligini cheklang (`sys.setrecursionlimit` ga tayanmang — bu faqat belgi, yechim emas).

## Mashq/topshiriq

**(Oson)** `Shakl` abstrakt klassi (`yuzasi()` metodi bilan), `Doira(radius)` (Leaf) va `ShakllarGuruhi` (Composite, `qosh()` va `yuzasi()` — barcha bolalar yuzasining yig'indisi) yozing. Ikki doirani guruhga qo'shib, umumiy yuzani chiqaring.

**(O'rtacha)** Tashkiliy tuzilma: `Xodim(ism, ish_haqi)` — Leaf, `Bolim(nomi)` — Composite (ichida `Xodim` HAM, boshqa `Bolim` HAM bo'lishi mumkin). Har ikkisi uchun umumiy `ish_haqi_jami()` metodini yozing. Ikki darajali tuzilma (Bosh bo'lim → Kichik bo'lim → Xodimlar) qurib, umumiy ish haqini hisoblang.

**(Qiyin)** Yuqoridagi `FaylTizimiElementi`ga yangi metod qo'shing: `fayllar_sonini_hisobla() -> int` — bu daraxtdagi barcha **Fayl** obyektlarining umumiy sonini (Papkalarni sanamasdan) rekursiv hisoblashi kerak. `Fayl` uchun bu doim `1` qaytarishi, `Papka` uchun bolalarining yig'indisi bo'lishi kerak. Yuqoridagi `bosh_papka` misolida sinab ko'ring (javob: 5).

import math

class Shakl(ABC):
    @abstractmethod
    def yuzasi(self) -> float: ...

class Doira(Shakl):

    def yuzasi(self):

    def __init__(self):
        self._shakllar = []
    def qosh(self, shakl):
        self._shakllar.append(shakl)
    def yuzasi(self):
        return sum(s.yuzasi() for s in self._shakllar)

guruh.qosh(Doira(3))

## Qisqacha xulosa

Composite naqshi — yakka obyektlarni (Leaf) va ularning guruhlarini (Composite, o'zi ham boshqa Leaf/Composite'larni saqlaydi) **umumiy interfeys** orqali, mijoz kodida `isinstance` tekshiruvlarisiz, bir xil usulda ishlatish imkonini beradi; bu — rekursiya bilan tabiiy bog'langan: Composite'ning metodlari odatda bolalariga chaqiriqni tarqatib, natijalarni yig'adi; fayl tizimlari, GUI widget daraxtlari, tashkiliy tuzilmalar va matematik ifodalar — Composite naqshining klassik qo'llanilish sohalari; asosiy e'tibor — Leaf klassga Composite'ga xos (`qosh()` kabi) metodlarni qo'shib qo'ymaslik va siklik tuzilmalardan ehtiyot bo'lish kerak.
