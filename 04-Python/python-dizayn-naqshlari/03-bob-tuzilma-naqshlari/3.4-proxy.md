# Proxy naqshi

## Bu darsda nimalarni o'rganasiz

- Proxy naqshi nima ekanini va u "o'rinbosar obyekt" sifatida qanday ishlashini tushuntira olasiz
- Virtual Proxy (lazy loading), Protection Proxy (ruxsat nazorati) va Remote Proxy farqlarini bilasiz
- Python'da `__getattr__` orqali shaffof (transparent) proxy yoza olasiz
- Proxy'ni Decorator va Facade'dan aniq farqlay olasiz
- Proxy naqshining qachon haqiqiy foyda, qachon ortiqcha murakkablik keltirishini bilasiz

## Nazariy qism

### Proxy nima — asosiy g'oya

**Proxy** (vakil, o'rinbosar) — asl obyektga (**Real Subject**) **bir xil interfeys** orqali kirishni nazorat qiluvchi "o'rinbosar" obyekt. Mijoz kodi Proxy bilan ishlayotganini **bilmasligi** ham mumkin — u xuddi asl obyekt bilan ishlayotgandek ishlaydi, lekin Proxy orqaga, chaqiriqdan oldin yoki keyin, qo'shimcha mantiq (tekshirish, keshlash, log yozish, kechiktirish) qo'shadi.

Real hayotiy o'xshatish — kредит karta: siz pulni bevosita bankdan emas, karta (proxy) orqali ishlatasiz; karta tranzaksiyani tekshiradi, keyin asl hisobga murojaat qiladi.

Proxy — Adapter'dan farqli, **interfeysni o'zgartirmaydi** (aynan bir xil interfeys), va Decorator'dan farqli, **funksionallikni kengaytirish uchun emas, kirishni nazorat qilish uchun** ishlatiladi (garchi amalda ikkisi ko'rinishda juda o'xshash bo'lsa ham — pastda buni aniqlaymiz).

### Virtual Proxy — lazy loading (kechiktirilgan yuklash)

Eng keng tarqalgan Proxy turi — **Virtual Proxy**: asl obyekt yaratish/yuklash **qimmat** (vaqt yoki xotira jihatidan) bo'lsa, uni haqiqatan kerak bo'lgunga qadar yaratmaslik.

```python
class KattaRasm:
    """Asl obyekt — yaratish QIMMAT (masalan, diskdan katta faylni o'qish)."""

    def __init__(self, fayl_nomi: str) -> None:
        self.fayl_nomi = fayl_nomi
        self._yukla()

    def _yukla(self) -> None:
        print(f"[KattaRasm] {self.fayl_nomi} diskdan yuklanmoqda... (sekin, 2 soniya)")

    def korsat(self) -> None:
        print(f"[KattaRasm] {self.fayl_nomi} ekranga chiqarildi")


class RasmProxy:
    """Virtual Proxy — asl KattaRasm'ni FAQAT kerak bo'lganda yaratadi."""

    def __init__(self, fayl_nomi: str) -> None:
        self.fayl_nomi = fayl_nomi
        self._asl_rasm: KattaRasm | None = None     # hali yaratilmagan — None

    def korsat(self) -> None:
        if self._asl_rasm is None:                   # faqat BIRINCHI chaqiriqda yuklanadi
            self._asl_rasm = KattaRasm(self.fayl_nomi)
        self._asl_rasm.korsat()


# Proxy yaratish — HECH NARSA yuklanmaydi, tezkor:
rasmlar = [RasmProxy(f"surat_{i}.jpg") for i in range(100)]
print("100 ta proxy yaratildi, lekin hech biri hali yuklanmagan")

rasmlar[5].korsat()     # FAQAT shu yerda, haqiqatan kerak bo'lganda, asl obyekt yuklanadi
# [KattaRasm] surat_5.jpg diskdan yuklanmoqda... (sekin, 2 soniya)
# [KattaRasm] surat_5.jpg ekranga chiqarildi

rasmlar[5].korsat()     # ikkinchi chaqiriqda ALLAQACHON yuklangan, qayta yuklamaydi
# [KattaRasm] surat_5.jpg ekranga chiqarildi
```

Bu naqsh 09-darsda ko'rgan **descriptor**lar yordamida yoziladigan `cached_property`ning g'oyasiga juda yaqin — ikkisi ham "kerak bo'lgunga qadar hisoblamaslik" tamoyiliga asoslangan.

### Protection Proxy — ruxsatlarni nazorat qilish

```python
class Hujjat:
    def __init__(self, matn: str) -> None:
        self._matn = matn

    def oqish(self) -> str:
        return self._matn

    def tahrirlash(self, yangi_matn: str) -> None:
        self._matn = yangi_matn
        print("[Hujjat] tahrirlandi")


class HujjatProtectionProxy:
    """Protection Proxy — faqat ruxsati bor foydalanuvchiga amal bajarishga ruxsat beradi."""

    def __init__(self, hujjat: Hujjat, foydalanuvchi_roli: str) -> None:
        self._hujjat = hujjat
        self._rol = foydalanuvchi_roli

    def oqish(self) -> str:
        return self._hujjat.oqish()         # o'qish — har kimga ruxsat

    def tahrirlash(self, yangi_matn: str) -> None:
        if self._rol != "muharrir":
            raise PermissionError(f"'{self._rol}' roliga tahrirlashga ruxsat yo'q")
        self._hujjat.tahrirlash(yangi_matn)


asl_hujjat = Hujjat("Boshlang'ich matn")
oquvchi_proxy = HujjatProtectionProxy(asl_hujjat, foydalanuvchi_roli="oquvchi")
muharrir_proxy = HujjatProtectionProxy(asl_hujjat, foydalanuvchi_roli="muharrir")

print(oquvchi_proxy.oqish())                 # ishlaydi
muharrir_proxy.tahrirlash("Yangilangan matn")   # ishlaydi

try:
    oquvchi_proxy.tahrirlash("Ruxsatsiz urinish")
except PermissionError as xato:
    print(f"Xato: {xato}")
# Xato: 'oquvchi' roliga tahrirlashga ruxsat yo'q
```

### Remote Proxy — masofadagi obyektga "mahalliy" kabi murojaat

**Remote Proxy** — tarmoq orqali boshqa mashinada (serverda) joylashgan obyektga, xuddi u mahalliy obyekt bo'lgandek murojaat qilish imkonini beradi — tarmoq chaqiriqlarining murakkabligi (ulanish, ketma-ketlashtirish/serialization, xatolarga ishlov berish) proxy ichida yashiriladi:

```python
class MasofaviyHisoblashServisi:
    """Haqiqiy loyihada bu HTTP/gRPC so'rov yuborardi — bu yerda simulyatsiya."""

    def hisobla(self, a: int, b: int) -> int:
        print(f"[Tarmoq] serverga so'rov yuborilmoqda: hisobla({a}, {b})")
        return a + b        # haqiqiy hayotda — tarmoq orqali javob keladi


class HisoblashRemoteProxy:
    """Mijoz uchun bu — oddiy mahalliy obyekt kabi ko'rinadi."""

    def __init__(self) -> None:
        self._ulanish_ornatildi = False

    def hisobla(self, a: int, b: int) -> int:
        if not self._ulanish_ornatildi:
            print("[Proxy] serverga ulanish o'rnatilmoqda...")
            self._servis = MasofaviyHisoblashServisi()
            self._ulanish_ornatildi = True
        return self._servis.hisobla(a, b)


proxy = HisoblashRemoteProxy()
print(proxy.hisobla(5, 7))     # mijoz uchun oddiy funksiya chaqiruvi kabi ko'rinadi
# [Proxy] serverga ulanish o'rnatilmoqda...
# [Tarmoq] serverga so'rov yuborilmoqda: hisobla(5, 7)
# 12
```

### Python'ga xos — `__getattr__` orqali "shaffof" (umumiy) Proxy

Python'ning dinamik tabiati tufayli, **har bir metodni qo'lda qayta yozmasdan**, umumiy Proxy yozish mumkin — `__getattr__` magic metodi yordamida (bu — 4.4-darsda ko'rgan magic metodlar mavzusining davomi):

```python
class LogProxy:
    """Asl obyektning HAR QANDAY metod chaqiruvini avtomatik logga yozadi."""

    def __init__(self, asl_obyekt) -> None:
        self._asl_obyekt = asl_obyekt

    def __getattr__(self, nom: str):
        # Faqat Proxy'da MAVJUD BO'LMAGAN atribut so'ralganda chaqiriladi (standart Python xatti-harakati)
        asl_atribut = getattr(self._asl_obyekt, nom)
        if callable(asl_atribut):
            def orash(*args, **kwargs):
                print(f"[LOG] {nom} chaqirilmoqda, argumentlar={args}")
                natija = asl_atribut(*args, **kwargs)
                print(f"[LOG] {nom} natija qaytardi: {natija}")
                return natija
            return orash
        return asl_atribut


class Kalkulyator:
    def qoshish(self, a: int, b: int) -> int:
        return a + b

    def ayirish(self, a: int, b: int) -> int:
        return a - b


kalk_proxy = LogProxy(Kalkulyator())
kalk_proxy.qoshish(10, 3)
# [LOG] qoshish chaqirilmoqda, argumentlar=(10, 3)
# [LOG] qoshish natija qaytardi: 13
```

Bu yondashuv — **yangi metod qo'shilganda Proxy'ni o'zgartirmasdan ham ishlashi** sababli juda qulay, lekin kamchiligi — IDE/statik tur tekshirgichlar (`mypy`) Proxy'ning qaysi metodlarga ega ekanini "ko'ra olmaydi" (chunki bularning hammasi runtime'da dinamik hal qilinadi).

### Qachon ishlatiladi — real hayotiy misollar

- **ORM "lazy" bog'lanishlar** (Django, SQLAlchemy) — `maqola.muallif` murojaat qilinganda, haqiqiy obyekt FAQAT shu paytda ma'lumotlar bazasidan yuklanadi (N+1 so'rov muammosi aynan shu bilan bog'liq — 13-bobda ko'rilgan).
- **`unittest.mock.Mock`/`MagicMock`** — test yozishda, haqiqiy obyekt o'rniga, uning chaqiriqlarini "yozib boruvchi" Proxy-ga o'xshash obyekt ishlatiladi.
- **Keshlash proxy** (Caching Proxy) — natijani birinchi chaqiriqda hisoblab, keyingi chaqiriqlarda keshdan qaytarish (`functools.lru_cache` ham, mohiyatan, funksiyalar uchun Proxy g'oyasini amalga oshiradi).
- **Xavfsizlik devorlari/API gateway** — so'rovni haqiqiy serverga yuborishdan oldin autentifikatsiya/avtorizatsiyani tekshiradigan oraliq qatlam.

## Amaliy misol

Ma'lumotlar bazasi ulanishi uchun keshlash + ruxsat nazorati proxy'si:

```python
# db_proxy.py
class MalumotlarBazasi:
    """Asl, 'qimmat' resurs — har bir so'rov sekin deb hisoblaymiz."""

    def sorov_yubor(self, sql: str) -> list:
        print(f"[DB] SO'ROV BAJARILMOQDA: {sql}")
        return [{"id": 1, "nomi": "Mahsulot A"}, {"id": 2, "nomi": "Mahsulot B"}]


class DBKeshProxy:
    """Keshlash (Caching) Proxy + Protection Proxy — bir nechta vazifani birlashtiradi."""

    def __init__(self, db: MalumotlarBazasi, foydalanuvchi_roli: str) -> None:
        self._db = db
        self._rol = foydalanuvchi_roli
        self._kesh: dict[str, list] = {}

    def sorov_yubor(self, sql: str) -> list:
        if "DELETE" in sql.upper() and self._rol != "admin":
            raise PermissionError("Faqat admin DELETE so'rov yuborishi mumkin")

        if sql in self._kesh:
            print(f"[Proxy] KESHDAN qaytarildi: {sql}")
            return self._kesh[sql]

        natija = self._db.sorov_yubor(sql)
        self._kesh[sql] = natija             # keyingi safar uchun saqlab qo'yamiz
        return natija


db = MalumotlarBazasi()
oddiy_foydalanuvchi = DBKeshProxy(db, foydalanuvchi_roli="oddiy")

print(oddiy_foydalanuvchi.sorov_yubor("SELECT * FROM mahsulotlar"))
# [DB] SO'ROV BAJARILMOQDA: SELECT * FROM mahsulotlar
# [{'id': 1, 'nomi': 'Mahsulot A'}, {'id': 2, 'nomi': 'Mahsulot B'}]

print(oddiy_foydalanuvchi.sorov_yubor("SELECT * FROM mahsulotlar"))     # IKKINCHI chaqiriq
# [Proxy] KESHDAN qaytarildi: SELECT * FROM mahsulotlar      <- DB'ga umuman murojaat qilinmadi!
# [{'id': 1, 'nomi': 'Mahsulot A'}, {'id': 2, 'nomi': 'Mahsulot B'}]

try:
    oddiy_foydalanuvchi.sorov_yubor("DELETE FROM mahsulotlar")
except PermissionError as xato:
    print(f"Xato: {xato}")
# Xato: Faqat admin DELETE so'rov yuborishi mumkin
```

## Keng tarqalgan xatolar

**Xato 1:** Proxy va Decorator naqshini bir xil narsa deb hisoblash.
❌ "Ikkisi ham obyektni o'rab oladi, demak bir xil" deb o'ylash.
✅ To'g'ri: tuzilma darajasida ikkisi haqiqatan o'xshash (ikkisi ham bir xil interfeysga ega obyektni "o'raydi"), lekin **niyat** (intent) farqli: Decorator — obyektga **yangi funksionallik qo'shish** uchun (va odatda bir nechtasi birlashtirilib, zanjir hosil qiladi), Proxy — asl obyektga **kirishni nazorat qilish/kechiktirish** uchun (odatda bitta Proxy, aniq bir maqsad bilan).

**Xato 2:** Virtual Proxy'da "yuklanganlik" holatini noto'g'ri saqlash — har chaqiriqda qayta yuklash.
❌
```python
class RasmProxy:
    def korsat(self):
        asl_rasm = KattaRasm(self.fayl_nomi)   # HAR SAFAR qayta yaratiladi!
        asl_rasm.korsat()
```
Bu Virtual Proxy'ning butun maqsadini (qimmat operatsiyani FAQAT bir marta bajarish) yo'qqa chiqaradi.
✅ To'g'ri: yuklangan obyektni instance atributida (`self._asl_rasm`) saqlang va `None` tekshiruvi orqali faqat birinchi marta yarating.

**Xato 3:** `__getattr__` asosidagi umumiy Proxy'da `__init__`dagi atributlarni noto'g'ri saqlash, bu esa cheksiz rekursiyaga olib kelishi.
❌
```python
class LogProxy:
    def __init__(self, obyekt):
        self.asl_obyekt = obyekt     # oddiy nom bilan saqlash

    def __getattr__(self, nom):
        return getattr(self.asl_obyekt, nom)   # self.asl_obyekt o'zi ham __getattr__ orqali qidiriladi -> SIKL!
```
✅ To'g'ri: `__getattr__` faqat **oddiy atribut qidiruvi muvaffaqiyatsiz bo'lgandagina** chaqiriladi, shuning uchun `self._asl_obyekt`ni `__init__`da `self.__dict__["_asl_obyekt"] = obyekt` orqali to'g'ridan-to'g'ri yozish (yoki ehtiyotkorlik bilan nomlash) muhim — amalda, agar `__init__` orqali oddiy `self._asl_obyekt = obyekt` qilinsa (yuqoridagi `LogProxy` misolidagi kabi), bu atribut `self.__dict__`da haqiqatan mavjud bo'ladi va `__getattr__` uni qidirib sikl hosil qilmaydi — lekin agar siz `__setattr__`ni ham override qilsangiz, xuddi shunday ehtiyotkorlik u yerda ham kerak bo'ladi.

## Mashq/topshiriq

**(Oson)** `VideoFayl(nomi)` klassi uchun `VideoProxy` yozing — u `__init__`da hech narsa yuklamasin, faqat `ijro_et()` metodi chaqirilganda "Video yuklanmoqda..." deb chiqarib, keyin "Video ijro etilmoqda: {nomi}" chiqarsin (Virtual Proxy).

**(O'rtacha)** `BankHisobi(balans)` klassi (`balans` atributi, `yechish(summa)` metodi bilan) uchun `BankProtectionProxy(hisob, parol, togri_parol)` yozing — `yechish()` chaqirilganda, agar `parol != togri_parol` bo'lsa, `PermissionError("Noto'g'ri parol")` chiqarsin, aks holda asl `yechish()`ni chaqirsin.

**(Qiyin)** `__getattr__` asosidagi `HisoblashProxy` yozing — u ixtiyoriy obyektni o'rab oladi va **faqat raqamli (int/float) natija qaytaruvchi** metodlarni chaqirishga ruxsat bersin; agar natija raqam bo'lmasa, `TypeError("Faqat raqamli natijalar ruxsat etilgan")` chiqarsin. (Maslahat: `orash` ichida natijani tekshiring, `isinstance(natija, (int, float))` orqali.)

## Qisqacha xulosa

Proxy naqshi — asl obyekt bilan **bir xil interfeysga** ega "o'rinbosar" obyekt yaratib, unga kirishni nazorat qilish, kechiktirish yoki qo'shimcha mantiq bilan boyitish imkonini beradi; Virtual Proxy — qimmat obyektni faqat kerak bo'lganda yaratadi (lazy loading), Protection Proxy — ruxsatlarni tekshiradi, Remote Proxy — tarmoq murakkabligini yashiradi; Python'da `__getattr__` orqali har qanday obyektni qamrab oluvchi umumiy Proxy yozish mumkin; Proxy Decorator'ga tuzilishi jihatidan o'xshash bo'lsa-da, niyati farqli — Decorator funksionallik **qo'shadi**, Proxy esa kirishni **nazorat qiladi**.
