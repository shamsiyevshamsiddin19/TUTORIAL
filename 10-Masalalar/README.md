## Python masalalari

```
Python/
├── Masalalar/
│   ├── Modul 1/
│   │   ├── Masala fayl/                     ← masalalar to'plami (PDF)
│   │   └── Tanlangan masalalar yechimlari/  ← 60 ta .py yechim
│   └── Modul 2/
│       ├── Masala fayl/
│       └── Tanlangan masalalar yechimlari/  ← 66 ta .py yechim
└── o'rganish jarayoni/                      ← shaxsiy qaydlar
```

Yechimlar `masala_001.py … masala_NNN.py` tartibida nomlangan — masala raqami bo'yicha to'g'ridan-to'g'ri topiladi.

## TypeScript masalalari

Har bir masala — brauzerda ochib ko'rish mumkin bo'lgan mustaqil mini-loyiha:

```
TS/Modul 1/Masala N/
├── index.html    ← sahifa
├── main.css      ← uslub
├── script.ts     ← asosiy yechim (TypeScript)
└── script.js     ← kompilyatsiya natijasi
```

Ochish uchun `index.html` faylini brauzerda oching yoki papkada:

```bash
python3 -m http.server 8000
```
