# 6.2. `tempfile` va `shutil` — vaqtinchalik fayllar va fayl amallari

## Bu darsda nimalarni o'rganasiz

- `tempfile.NamedTemporaryFile` bilan avtomatik tozalanadigan vaqtinchalik fayl yaratishni o'rganasiz
- Qachon xotirada (`io.BytesIO`, 6.1-dars) emas, aynan diskdagi vaqtinchalik fayl kerakligini tushunasiz
- `shutil.copyfileobj`, `shutil.move`, `shutil.disk_usage` bilan fayl amallarini bajarishni o'rganasiz
- Katta fayl yuklashni (upload) xavfsiz, bosqichma-bosqich qayta ishlashni o'rganasiz

## Nazariy qism

### Qachon `BytesIO` emas, haqiqiy vaqtinchalik fayl kerak

6.1-darsda `io.BytesIO` — xotirada fayl yaratganini ko'rdik. Lekin ba'zi holatlarda bu yetarli emas: (1) fayl juda katta (masalan bir necha yuz MB — butunlay xotirada ushlab turish xavfli), (2) tashqi dastur (masalan buyruq qatori vositasi, `subprocess` orqali chaqiriladigan) haqiqiy **fayl yo'li**ni talab qiladi, xotiradagi obyektni emas. Bunday holatlarda `tempfile` moduli yordamga keladi — u operatsion tizimning vaqtinchalik fayllar papkasida (`/tmp` Linux'da) fayl yaratadi va, muhimi, **avtomatik o'chirishni** ta'minlaydi:

```python
import tempfile

with tempfile.NamedTemporaryFile(suffix=".jpg") as vaqtinchalik:
    vaqtinchalik.write(b"...rasm bayt ma'lumoti...")
    vaqtinchalik.flush()
    print(vaqtinchalik.name)   # /tmp/tmpAbC123.jpg — haqiqiy fayl yo'li

# `with` blokidan chiqishi bilan, fayl AVTOMATIK o'chiriladi
```

`with` bloki tugagach, fayl diskdan avtomatik olib tashlanadi — qo'lda `os.remove()` chaqirishni "unutish" xavfi yo'q. Agar fayl `with` blokidan tashqarida ham kerak bo'lsa (masalan tashqi jarayonga uzatilib, keyin o'qilishi kerak bo'lsa), `delete=False` parametri bilan avtomatik o'chirishni o'chirib qo'yish, va keyin **o'zingiz** tozalash mumkin:

```python
vaqtinchalik = tempfile.NamedTemporaryFile(suffix=".jpg", delete=False)
vaqtinchalik.write(b"...")
vaqtinchalik.close()
# ... vaqtinchalik.name bilan boshqa jarayonga uzatiladi ...
import os
os.unlink(vaqtinchalik.name)   # ishlatib bo'lgach, qo'lda o'chirish shart
```

### `shutil` — yuqori darajadagi fayl amallari

`os` moduli (1.2-dars) past darajadagi amallarni beradi, `shutil` esa ko'proq "amaliy" vazifalarni oson qiladi:

| Funksiya | Vazifasi |
|---|---|
| `shutil.copy(manba, maqsad)` | Faylni nusxalash |
| `shutil.copyfileobj(manba_f, maqsad_f)` | Ochiq fayl obyektlari orasida bo'lak-bo'lak nusxalash (xotirani tejab) |
| `shutil.move(manba, maqsad)` | Faylni ko'chirish (papkalar orasida ham) |
| `shutil.rmtree(papka)` | Papkani, ichidagi hammasi bilan o'chirish |
| `shutil.disk_usage(yol)` | Disk bo'sh joyi haqida ma'lumot |

```python
import shutil

jami, band, bosh = shutil.disk_usage("/")
print(f"Bo'sh joy: {bosh / (1024**3):.1f} GB")
```

## Amaliy misol

`onlayn_dokon`da mijoz katta hajmli rasm yuklaganda, uni to'g'ridan-to'g'ri xotirada emas, vaqtinchalik faylga yozib, tashqi buyruq qatori vositasi (masalan rasm siqish uchun `optipng` yoki shunga o'xshash) bilan qayta ishlaymiz, so'ng natijani asosiy media papkaga ko'chiramiz:

```python
# apps/mahsulotlar/utils.py
import shutil
import subprocess
import tempfile
from pathlib import Path

from django.conf import settings


def rasmni_siqib_saqlash(yuklangan_fayl, mahsulot_sku: str) -> Path:
    """Yuklangan rasmni vaqtinchalik faylga yozadi, siqadi va media papkaga ko'chiradi."""

    # 1-qadam: yuklangan faylni vaqtinchalik faylga yozamiz (xotirada emas, diskda)
    with tempfile.NamedTemporaryFile(suffix=".jpg", delete=False) as vaqtinchalik:
        shutil.copyfileobj(yuklangan_fayl, vaqtinchalik)
        vaqtinchalik_yol = Path(vaqtinchalik.name)

    try:
        # 2-qadam: tashqi vositani vaqtinchalik fayl ustida ishga tushiramiz
        # (8.2-darsda subprocess'ni chuqur ko'ramiz)
        subprocess.run(
            ["jpegoptim", "--max=85", str(vaqtinchalik_yol)],
            check=True,
            capture_output=True,
        )

        # 3-qadam: siqilgan faylni doimiy media papkaga ko'chiramiz
        maqsad_papka = settings.MEDIA_ROOT / "mahsulotlar"
        maqsad_papka.mkdir(parents=True, exist_ok=True)
        maqsad_yol = maqsad_papka / f"{mahsulot_sku}.jpg"

        shutil.move(str(vaqtinchalik_yol), str(maqsad_yol))
        return maqsad_yol

    finally:
        # 4-qadam: agar vaqtinchalik fayl hali ham mavjud bo'lsa (masalan xato tufayli
        # move bosqichigacha yetmagan bo'lsa), uni albatta tozalaymiz
        if vaqtinchalik_yol.exists():
            vaqtinchalik_yol.unlink()
```

`finally` bloki — bu yerda muhim: agar `subprocess.run` xato bersa (masalan `jpegoptim` o'rnatilmagan bo'lsa), dastur `except`siz to'xtaganda ham, vaqtinchalik fayl **albatta** o'chiriladi. Bu naqsh (pattern) — "resursni oching, `try` ichida ishlating, `finally` ichida albatta tozalang" — fayl, tarmoq ulanishi kabi har qanday "tashqi resurs" bilan ishlashning umumiy qoidasi.

## Keng tarqalgan xatolar

**Xato 1:** `delete=False` bilan yaratilgan vaqtinchalik faylni tozalashni unutish.

❌ `tempfile.NamedTemporaryFile(delete=False)` orqali fayl yaratib, keyin uni hech qachon `os.unlink()` bilan o'chirmaslik — vaqt o'tishi bilan `/tmp` papkasi minglab "yetim" fayllar bilan to'lib, disk joyini yeb qo'yishi mumkin.

✅ `delete=False` ishlatilganda, **har doim** `try/finally` (yoki xato yuz berganda ham ishlaydigan boshqa mexanizm) bilan faylni keyinroq o'chirishni ta'minlang — yuqoridagi amaliy misoldagi kabi.

**Xato 2:** `shutil.move()`ni turli fayl tizimlari (disklar) orasida "nusxalash kabi tez" deb kutish.

❌ Katta faylni bitta diskdan boshqa diskka (masalan tarmoq orqali ulangan saqlash joyiga) `shutil.move()` bilan ko'chirish — agar manba va maqsad boshqa fayl tizimida bo'lsa, `move` ichida avtomatik ravishda "nusxalab, keyin eskisini o'chirish"ga o'tadi, bu katta fayllarda kutilganidan sekinroq bo'lishi mumkin.

✅ Buni normal holat deb qabul qiling (`shutil.move` buni o'zi to'g'ri boshqaradi), lekin juda katta fayllar va tez-tez ko'chirish kerak bo'lsa, ikkala joy bir xil diskda/hajmda (volume) bo'lishini ta'minlashga harakat qiling — bu operatsiyani sezilarli tezlashtiradi.

**Xato 3:** Yuklangan faylni to'liq `.read()` bilan xotiraga olib, keyin vaqtinchalik faylga yozish.

❌ `vaqtinchalik.write(yuklangan_fayl.read())` — bu butun faylni avval xotiraga yuklaydi, keyin diskka yozadi — vaqtinchalik faylning butun maqsadi (xotirani tejash) shu bilan yo'qqa chiqadi.

✅ `shutil.copyfileobj(yuklangan_fayl, vaqtinchalik)` ishlating — u ikkala fayl obyekti orasida ma'lumotni **bo'lak-bo'lak** (standart holda 64 KB) ko'chiradi, hech qachon butun faylni birdaniga xotiraga yuklamaydi.

## Mashq/topshiriq

**(Oson)** Shell'da `import shutil; jami, band, bosh = shutil.disk_usage("/"); print(f"{bosh / 1024**3:.1f} GB bo'sh")` bajarib, serveringizda qancha bo'sh disk joyi borligini ko'ring.

**(O'rtacha)** `rasmni_siqib_saqlash` funksiyasiga, vaqtinchalik fayl hajmi 10 MB'dan oshsa, `subprocess.run` chaqirilishidan **oldin** `ValueError("Fayl juda katta")` chiqaradigan tekshiruv qo'shing (`vaqtinchalik_yol.stat().st_size`dan foydalaning — 1.1-darsni eslang).

**(Qiyin)** `onlayn_dokon` uchun, `media/vaqtinchalik/` papkasidagi, 24 soatdan ortiq turgan barcha fayllarni tozalovchi management command yozing (masalan yuklash jarayoni yarim to'xtab qolgan fayllar to'planib qolishining oldini olish uchun). `Path.stat().st_mtime` (fayl oxirgi o'zgartirilgan vaqti, Unix timestamp) va `datetime.fromtimestamp()`dan foydalaning.

from datetime import datetime, timedelta

from django.conf import settings
from django.core.management.base import BaseCommand
from django.utils import timezone


class Command(BaseCommand):
    help = "24 soatdan eski vaqtinchalik fayllarni tozalaydi"

    def handle(self, *args, **options):
        papka = settings.MEDIA_ROOT / "vaqtinchalik"
        chegara = timezone.now() - timedelta(hours=24)

        for fayl in papka.glob("*"):
            ozgartirilgan_vaqt = datetime.fromtimestamp(fayl.stat().st_mtime, tz=timezone.get_current_timezone())
            if ozgartirilgan_vaqt < chegara:
                fayl.unlink()
                self.stdout.write(f"O'chirildi: {fayl.name}")

## Qisqacha xulosa

`tempfile.NamedTemporaryFile` — operatsion tizimning vaqtinchalik papkasida, `with` blokidan chiqishi bilan (yoki `delete=False` bilan qo'lda) tozalanadigan fayl yaratadi; bu tashqi vositalar haqiqiy fayl yo'lini talab qilganda yoki fayl juda katta bo'lganda `io.BytesIO`ga muqobil. `shutil` — nusxalash, ko'chirish, bo'lak-bo'lak ko'chirish (`copyfileobj`) kabi yuqori darajadagi fayl amallarini beradi, va katta fayl yuklashda `.read()` bilan xotiraga to'liq yuklash o'rniga har doim `copyfileobj` orqali bo'lak-bo'lak ishlash tavsiya etiladi. `delete=False` bilan yaratilgan har bir vaqtinchalik fayl — `try/finally` orqali albatta tozalanishi kerak bo'lgan javobgarlik. Keyingi bobda — Django loyihasining diagnostikasi: `logging` va unumdorlikni oshiruvchi `functools`/`collections` bilan tanishamiz.
