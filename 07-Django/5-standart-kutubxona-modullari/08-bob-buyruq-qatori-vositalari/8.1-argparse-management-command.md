# 8.1. `argparse` — management command'larga argument qo'shish

## Bu darsda nimalarni o'rganasiz

- `argparse.ArgumentParser` bilan buyruq qatori argumentlarini qanday e'lon qilinishini tushunasiz
- Django management command'ning `add_arguments()` metodi ostida `argparse` qanday ishlashini bilib olasiz
- Majburiy, ixtiyoriy va bayroq (flag) turidagi argumentlarni farqlashni o'rganasiz
- `onlayn_dokon` uchun moslashuvchan, argumentlarga ega management command yozasiz

## Nazariy qism

### `argparse` — mustaqil skriptda

`argparse` — buyruq qatori dasturlariga argument qabul qilish imkonini beruvchi standart modul. Mustaqil skriptda u shunday ishlaydi:

```python
# sinov_skripti.py
import argparse

parser = argparse.ArgumentParser(description="Mahsulotlarni import qiladi")
parser.add_argument("fayl_yoli", help="CSV fayl yo'li")            # majburiy (positional)
parser.add_argument("--dry-run", action="store_true", help="Faqat ko'rsatadi, saqlamaydi")
parser.add_argument("--limit", type=int, default=100, help="Nechta qatorni import qilish")

argumentlar = parser.parse_args()
print(argumentlar.fayl_yoli, argumentlar.dry_run, argumentlar.limit)
```

```bash
python sinov_skripti.py mahsulotlar.csv --limit 50 --dry-run
# mahsulotlar.csv True 50
```

Uch turdagi argument:

| Tur | Misol | Xossasi |
|---|---|---|
| **Positional** (o'rin bo'yicha) | `fayl_yoli` | Majburiy, tire bilan boshlanmaydi, tartib muhim |
| **Optional** (ixtiyoriy, qiymatli) | `--limit 50` | `--` bilan boshlanadi, qiymat qabul qiladi |
| **Flag** (bayroq) | `--dry-run` | `action="store_true"` — faqat mavjud/yo'qligi (`True`/`False`) |

### Django management command — `argparse` ustidan qatlam

Django'ning `BaseCommand` klassi ichida to'g'ridan-to'g'ri `argparse.ArgumentParser` ishlatiladi — `add_arguments(self, parser)` metodiga uzatiladigan `parser` — aynan shu `ArgumentParser` obyektining o'zi:

```python
# apps/mahsulotlar/management/commands/mahsulotlarni_import_qil.py
from django.core.management.base import BaseCommand


class Command(BaseCommand):
    help = "CSV fayldan mahsulotlarni import qiladi"

    def add_arguments(self, parser):
        parser.add_argument("fayl_yoli", type=str, help="CSV fayl yo'li")
        parser.add_argument(
            "--dry-run",
            action="store_true",
            help="Faqat natijani ko'rsatadi, hech narsa saqlamaydi",
        )
        parser.add_argument(
            "--limit",
            type=int,
            default=None,
            help="Faqat shuncha qatorni import qilish (test uchun)",
        )

    def handle(self, *args, **options):
        # options — parse_args() natijasi, dict shaklida
        fayl_yoli = options["fayl_yoli"]
        dry_run = options["dry_run"]      # Django avtomatik tire(-)ni pastki chiziqqa(_) aylantiradi
        limit = options["limit"]

        self.stdout.write(f"Fayl: {fayl_yoli}, dry_run={dry_run}, limit={limit}")
```

`options["dry_run"]` — e'tibor bering, `--dry-run` (tire bilan) e'lon qilingan, lekin `options` ichida `dry_run` (pastki chiziq bilan) kalit sifatida saqlanadi — `argparse` buni avtomatik qiladi, chunki Python o'zgaruvchi nomida tire bo'lishi mumkin emas.

## Amaliy misol

`onlayn_dokon` uchun, moslashuvchan CSV import buyrug'ini to'liq yozamiz — u nafaqat argument qabul qiladi, balki `argparse`ning validatsiya imkoniyatlaridan ham foydalanadi:

```python
# apps/mahsulotlar/management/commands/mahsulotlarni_import_qil.py
import csv
from decimal import Decimal, InvalidOperation
from pathlib import Path

from django.core.management.base import BaseCommand, CommandError

from apps.mahsulotlar.models import Mahsulot


class Command(BaseCommand):
    help = "CSV fayldan mahsulotlarni import qiladi (format: nomi,sku,narxi)"

    def add_arguments(self, parser):
        parser.add_argument("fayl_yoli", type=str)
        parser.add_argument("--dry-run", action="store_true")
        parser.add_argument("--limit", type=int, default=None)
        parser.add_argument(
            "--bolim",
            type=str,
            choices=["poyabzal", "kiyim", "aksessuar"],
            default="kiyim",
            help="Barcha import qilinadigan mahsulotlar shu bo'limga tegishli bo'ladi",
        )

    def handle(self, *args, **options):
        fayl_yoli = Path(options["fayl_yoli"])   # 1.1-darsdagi pathlib

        if not fayl_yoli.exists():
            raise CommandError(f"Fayl topilmadi: {fayl_yoli}")

        yaratilgan_soni = 0
        xato_soni = 0

        with open(fayl_yoli, encoding="utf-8") as f:
            reader = csv.DictReader(f)   # 4.2-darsdagi csv moduli

            for i, qator in enumerate(reader, start=1):
                if options["limit"] and i > options["limit"]:
                    break

                try:
                    narx = Decimal(qator["narxi"])
                except (InvalidOperation, KeyError):
                    self.stderr.write(self.style.WARNING(f"{i}-qator o'tkazib yuborildi: noto'g'ri narx"))
                    xato_soni += 1
                    continue

                if not options["dry_run"]:
                    Mahsulot.objects.create(
                        nomi=qator["nomi"], sku=qator["sku"], narxi=narx, bolim=options["bolim"]
                    )
                yaratilgan_soni += 1

        rejim = "DRY-RUN (hech narsa saqlanmadi)" if options["dry_run"] else "SAQLANDI"
        self.stdout.write(self.style.SUCCESS(
            f"{rejim}: {yaratilgan_soni} mahsulot, {xato_soni} xato"
        ))
```

```bash
python manage.py mahsulotlarni_import_qil mahsulotlar.csv --dry-run --limit 5 --bolim poyabzal
```

`--bolim`dagi `choices=[...]` — muhim `argparse` imkoniyati: agar foydalanuvchi ro'yxatda yo'q qiymat kiritsa (masalan `--bolim elektronika`), `argparse` **avtomatik ravishda** xato chiqarib, dasturni to'xtatadi — bu tekshiruvni qo'lda yozish shart emas.

## Keng tarqalgan xatolar

**Xato 1:** `options["nomi"]` kalitida tire bilan yozilgan nomni izlash.

❌ `options["dry-run"]` (tire bilan) — `KeyError: 'dry-run'` beradi, chunki `argparse` `--dry-run`ni ichki saqlashda avtomatik `dry_run` (pastki chiziq) ga aylantiradi.

✅ Har doim `options["dry_run"]` (pastki chiziq bilan) yozing — argument e'lon qilishda tire (`--dry-run`, CLI'da chiroyliroq ko'rinadi), o'qishda pastki chiziq (`dry_run`, Python o'zgaruvchisi sifatida to'g'ri).

**Xato 2:** Xatoni `raise Exception(...)` yoki oddiy `print` bilan ko'rsatish.

❌ `raise ValueError(f"Fayl topilmadi: {fayl_yoli}")` — management command ichida bu to'liq Python traceback'ini ko'rsatadi, foydalanuvchi (masalan boshqa dasturchi yoki deploy skripti) uchun keraksiz "qo'rqinchli" va tushunarsiz.

✅ Django'ning maxsus `django.core.management.base.CommandError`sidan foydalaning — u traceback'siz, faqat aniq xato xabari bilan, mos chiqish kodi (`exit code 1`) bilan to'xtaydi — bu buyruq qatori vositalari uchun standart, kutilgan xatti-harakat.

**Xato 3:** `type=int` kabi tur ko'rsatmasdan, argumentni har doim string deb qabul qilish.

❌ `parser.add_argument("--limit", default=100)` (`type=` yo'q) — `--limit 50` CLI'dan kelganda, `options["limit"]` **string** `"50"` bo'ladi, sonli solishtirish (`if i > options["limit"]`) `TypeError` beradi.

✅ Har doim mos `type=` ko'rsating: `type=int`, `type=float`, yoki `type=Path` (`pathlib.Path`ning o'zi ham `type=` sifatida ishlatilishi mumkin — `argparse` avtomatik chaqiradi).

## Mashq/topshiriq

**(Oson)** `mahsulotlarni_import_qil` buyrug'ini `--help` bilan chaqiring: `python manage.py mahsulotlarni_import_qil --help` — `argparse` avtomatik yaratgan yordam matnini ko'ring (bu — `argparse`ning bepul, hech qanday qo'shimcha kod talab qilmaydigan imkoniyati).

**(O'rtacha)** `add_arguments`ga yangi bayroq qo'shing: `--tozalash`, `action="store_true"` — agar berilsa, import boshlanishidan oldin, shu `--bolim`ga tegishli **barcha** mavjud mahsulotlarni o'chirsin (`Mahsulot.objects.filter(bolim=options["bolim"]).delete()`), lekin faqat `--dry-run` berilmagan holda.

**(Qiyin)** Buyruqqa `--format` argumentini qo'shing, `choices=["csv", "json"]`, standart qiymati `"csv"`. `handle()` ichida, `options["format"]`ga qarab, yoki joriy `csv.DictReader`, yoki `json.load()` (4.1-darsni eslang) orqali faylni o'qiydigan qilib moslang — ikkala holatda ham fayl formati bir xil maydonlarga (`nomi`, `sku`, `narxi`) ega deb hisoblang.

## Qisqacha xulosa

`argparse` — buyruq qatori argumentlarini (positional, optional, flag) e'lon qilish, turini tekshirish (`type=`) va ruxsat etilgan qiymatlarni cheklash (`choices=`) uchun standart vosita; Django'ning management command'lari `add_arguments(self, parser)` metodida aynan shu `ArgumentParser` obyektidan foydalanadi, `handle()`dagi `options` dictionary esa `parse_args()` natijasi. Muhim odatlar: argument nomidagi tire `options`da pastki chiziqqa aylanadi, xatolarni `CommandError` bilan (oddiy `raise`siz) ko'rsatish, va argumentga mos `type=`/`choices=` berish — bu buyruqni ham xavfsizroq, ham foydalanuvchi uchun qulayroq qiladi. Keyingi darsda — management command ichidan tashqi buyruqlarni chaqirish uchun `subprocess` bilan tanishamiz.
