# Yakuniy loyiha: avtomatlashtirish skripti

## Bu darsda nimalarni o'rganasiz

- Kursda o'rgangan barcha ko'nikmalarni (fayl bilan ishlash, shart, tsikl, funksiya, arxivlash, yo'naltirish, xavfsizlik) bitta, to'liq loyihada birlashtirasiz
- Belgilangan papkani tekshiruvchi, ma'lum turdagi fayllarni zaxiralab arxivlovchi, natijasini sanali log fayliga yozuvchi, va xato yuz berganda operatorga xabar beruvchi, ishlaydigan bash skript yaratasiz
- Skriptni, argumentlar orqali, moslashuvchan qilib yozasiz

## Nazariy qism

### Loyiha g'oyasi

Ushbu darslikda, siz, fayl tizimida yurish, fayllar bilan ishlash, matn qidirish, ruxsatlar, yo'naltirish, jarayonlar, muhit sozlash va, eng muhimi, bash skript yozishni (shart, tsikl, funksiya, xato boshqarish) o'rgandingiz. Yakuniy loyiha — bu bilimlarning barchasini, **bitta, haqiqiy hayotda foydali bo'ladigan** vazifada birlashtiradi: **avtomatik zaxira nusxa olish (backup) skripti**.

Bu skript, real hayotda, tez-tez ishlatiladigan vazifani bajaradi: belgilangan papkadagi, muayyan turdagi fayllarni (masalan, hujjatlar, loglar), muntazam ravishda, arxivlab, alohida, "zaxira" papkasiga joylaydi, va, har bir ishlash haqida, sanali jurnal (log) yozuvi qoldiradi — bu, 12-bobda o'rgangan, "muhim ma'lumotni muntazam zaxiralash" tavsiyasining, aynan amaliy ko'rinishidir.

### Skriptning talab qilinadigan imkoniyatlari

1. **Argumentlar orqali sozlanuvchan** bo'lishi kerak: qaysi papka zaxiralanishi (`$1`), va, zaxira qaerga saqlanishi (`$2`) — argument sifatida beriladi
2. **Manba papka mavjudligini tekshirishi** kerak — agar mavjud bo'lmasa, aniq xato xabari bilan, `exit 1` orqali to'xtashi kerak
3. **Zaxira papkasini, agar mavjud bo'lmasa, avtomatik yaratishi** kerak (`mkdir -p`)
4. **Manba papkani, sanali nom bilan, `.tar.gz` arxiviga joylashi** kerak (masalan, `zaxira-2026-08-19.tar.gz`)
5. **Har bir ishlash haqida**, alohida log fayliga (sana, vaqt, natija bilan) yozuv qo'shishi kerak (`>>` orqali, o'chirmasdan)
6. **Funksiyalarga bo'linган** bo'lishi kerak — kamida ikkita mustaqil funksiya (masalan, tekshirish va arxivlash)
7. **Xato yuz berganda**, aniq xabar bilan, `exit` orqali to'xtashi kerak (`set -e` bilan qo'shimcha himoyalangan)

## Amaliy misol — to'liq skript

```bash
mkdir -p ~/skriptlar
nano ~/skriptlar/zaxira-skripti.sh
```

Quyidagi, to'liq, ishlaydigan skriptni kiritamiz:

```bash
#!/bin/bash
set -e

LOG_FAYL="$HOME/skriptlar/zaxira.log"

# Manba papkani tekshiruvchi funksiya
manba_tekshir() {
    if [ -z "$1" ]; then
        echo "Xato: manba papka ko'rsatilmadi." | tee -a "$LOG_FAYL"
        exit 1
    fi

    if [ ! -d "$1" ]; then
        echo "$(date '+%Y-%m-%d %H:%M:%S') XATO: '$1' papkasi topilmadi." | tee -a "$LOG_FAYL"
        exit 1
    fi
}

# Arxivlash funksiyasi
arxivla() {
    manba="$1"
    zaxira_papka="$2"
    sana=$(date '+%Y-%m-%d')
    arxiv_nomi="zaxira-$sana.tar.gz"

    mkdir -p "$zaxira_papka"

    tar -czf "$zaxira_papka/$arxiv_nomi" -C "$(dirname "$manba")" "$(basename "$manba")"

    echo "$(date '+%Y-%m-%d %H:%M:%S') MUVAFFAQIYAT: '$manba' -> '$zaxira_papka/$arxiv_nomi'" | tee -a "$LOG_FAYL"
}

# Asosiy mantiq
manba_papka="$1"
zaxira_manzil="$2"

if [ -z "$zaxira_manzil" ]; then
    zaxira_manzil="$HOME/zaxiralar"
fi

manba_tekshir "$manba_papka"
arxivla "$manba_papka" "$zaxira_manzil"

echo "Skript muvaffaqiyatli yakunlandi."
```

Saqlab (`Ctrl+O`, `Enter`), chiqamiz (`Ctrl+X`), va, bajarish ruxsatini beramiz:

```bash
chmod u+x ~/skriptlar/zaxira-skripti.sh
```

### Skriptni sinash

Avval, sinov uchun, kichik papka va bir nechta fayl tayyorlaymiz:

```bash
mkdir -p ~/sinov-hujjatlar
echo "Birinchi hujjat" > ~/sinov-hujjatlar/hisobot.txt
echo "Ikkinchi hujjat" > ~/sinov-hujjatlar/eslatma.txt
```

Skriptni, mavjud manba papka bilan ishga tushiramiz:

```bash
~/skriptlar/zaxira-skripti.sh ~/sinov-hujjatlar ~/zaxiralar
```

Natija:

```
MUVAFFAQIYAT: '/home/shamsiddin/sinov-hujjatlar' -> '/home/shamsiddin/zaxiralar/zaxira-2026-08-19.tar.gz'
Skript muvaffaqiyatli yakunlandi.
```

Yaratilgan arxivni tekshiramiz:

```bash
ls -lh ~/zaxiralar
```

Log faylini ko'ramiz:

```bash
cat ~/skriptlar/zaxira.log
```

Endi, **mavjud bo'lmagan** papka bilan sinaymiz (xato holatini tekshirish uchun):

```bash
~/skriptlar/zaxira-skripti.sh ~/mavjud-bolmagan-papka
```

Natija: aniq xato xabari, va skript, `exit 1` orqali, darhol to'xtaydi. Log faylini yana tekshiramiz — yangi, "XATO" yozuvi qo'shilganini ko'rasiz:

```bash
cat ~/skriptlar/zaxira.log
```

Skriptni, **argument berilmasdan** ham sinaymiz:

```bash
~/skriptlar/zaxira-skripti.sh
```

Natija: "Xato: manba papka ko'rsatilmadi." xabari bilan, to'xtaydi.

### Skriptni, muntazam ishga tushirish (yo'nalish)

Bu skript, endi, qo'lda, xohlagan vaqtda ishga tushirilishi mumkin. Uni, **har kuni, avtomatik** ishga tushirish uchun (masalan, tunda), `cron` deb ataluvchi, alohida tizim vositasidan foydalaniladi — bu, ushbu darslikning chegarasidan tashqarida, ammo, endi siz, buni, mustaqil o'rganish uchun yetarli bilimga egasiz: `man crontab` orqali, boshlash mumkin.

## Keng tarqalgan xatolar

❌ **Skriptni, sinov papkasi bilan, faqat **bir marta** sinab, "ishladi" deb, qolgan holatlarni (mavjud bo'lmagan papka, argumentsiz chaqiruv) tekshirmasdan qoldirish.**
✅ Har bir skriptni, kamida uchta holatda sinang: **to'g'ri** ma'lumot bilan, **noto'g'ri** (mavjud bo'lmagan) ma'lumot bilan, va **argumentsiz**.

**Nega xato:** Skript, "to'g'ri yo'l"da, ko'pincha, osongina ishlaydi — haqiqiy sifat, aynan, **kutilmagan** holatlarda (xato ma'lumot, bo'sh argument) qanday harakat qilishida ko'rinadi; 7.4-darsda o'rganilgan, "aniq va foydali xato xabarlari" — shu sababli muhim.

❌ **Log faylini, `>` bilan yozib, har safar ishga tushirilganda, oldingi yozuvlarni o'chirib yuborish.**
✅ Log faylga yozishda, doim `>>` (yoki, yuqoridagi skriptdagi kabi, `tee -a`) ishlating — bu, 4.1-darsda o'rgangan, muhim farq.

**Nega xato:** Log faylning butun maqsadi — vaqt o'tishi bilan, **barcha** ishlashlar tarixini saqlash; `>` bilan yozish, har safar, faqat, eng so'nggi ishlash haqidagi ma'lumotni qoldiradi, avvalgi tarix esa yo'qoladi.

❌ **`set -e` qo'yilgan skriptda, funksiyalar ichidagi xato tekshiruvini (masalan, `if [ ! -d ... ]`) yozmasdan, faylning "o'zi" xato bersin deb kutish.**
✅ `set -e`, umumiy "xavfsizlik to'ri" bo'lsa-da, **aniq, tushunarli** xato xabarlari uchun, hali ham, o'zingiz, `if` orqali, muhim shartlarni, alohida tekshirishingiz kerak (7.4-darsda ko'rilganidek).

**Nega xato:** `set -e`, skriptni, xato yuz berganda, to'xtatadi, ammo, u, foydalanuvchiga, **nima xato bo'lganini, tushunarli tilda** tushuntirmaydi — bu, faqat, sizning, o'zingiz yozgan, aniq xato xabarlaringiz orqali ta'minlanadi.

## Mashq/topshiriq (yakuniy loyihani kengaytirish)

**(Oson)** Yuqoridagi `zaxira-skripti.sh`ni, endi, faqat, arxivlashdan oldin, manba papkadagi fayllar sonini (`ls` va `wc -l` orqali) ham, log fayliga yozadigan qilib kengaytiring.

**(O'rtacha)** Skriptga, uchinchi funksiya qo'shing — `eski_zaxiralarni_tozala`, u, zaxira papkasida, `7` kundan eski (`.tar.gz` fayllar orasidan, `find ... -mtime +7`, 2.3-darsda o'rganilgan) arxivlarni topib, ularni o'chiradi, va, bu haqida ham, log fayliga yozadi.

**(Qiyin)** Skriptni, **faqat**, muayyan kengaytmali fayllarni (masalan, faqat `.txt` va `.log` fayllarni, boshqa fayl turlarini emas) arxivlaydigan qilib o'zgartiring — buning uchun, `tar` o'rniga, avval, `find` bilan, kerakli fayllarni alohida topib, so'ng, ularni, `tar`ga, aniq ro'yxat sifatida berish kerak bo'ladi (maslahat: `find "$manba" -type f \( -name "*.txt" -o -name "*.log" \) | tar -czf "$arxiv_nomi" -T -` — bu yerda, `-T -` bayrog'i, `tar`ga, arxivlanadigan fayllar ro'yxatini, standart kirish oqimidan olishni buyuradi).

## Qisqacha xulosa

Ushbu yakuniy loyiha — fayl tizimi bilan ishlash, shart va tsikl operatorlari, funksiyalar, `tar` orqali arxivlash, `>>` orqali logga yozish, va xatolarni to'g'ri boshqarish (aniq xabarlar + `set -e`)ni, bitta, real hayotda foydali bo'ladigan zaxiralash skriptida birlashtiradi — bu, darslik davomida o'rganilgan barcha alohida ko'nikmalarning, birgalikda, qanday, kattaroq, amaliy vazifani hal qilishini ko'rsatadi, va, endi, siz, xuddi shu yondashuv bilan, o'z kundalik ishingizdagi, boshqa takrorlanuvchi vazifalarni ham, mustaqil ravishda, avtomatlashtira olasiz.
