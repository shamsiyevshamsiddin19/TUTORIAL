# Foydalanuvchilar va sudo

## Bu darsda nimalarni o'rganasiz

- `whoami` va `id` bilan, joriy foydalanuvchi va uning guruhlari haqida ma'lumot olasiz
- `sudo` bilan, vaqtincha administrator huquqiga ega bo'lib, tizim darajasidagi amallarni bajarasiz
- `chown` bilan, faylning egasi va guruhini o'zgartirasiz
- `sudo`dan nega ehtiyotkorlik bilan foydalanish kerakligini tushunasiz

## Nazariy qism

### `root` — tizimning "super foydalanuvchisi"

Har bir Linux tizimida, **`root`** deb ataluvchi, maxsus foydalanuvchi mavjud — u, tizimdagi **istalgan** faylni o'qiy, o'zgartira yoki o'chira oladi, ruxsatlardan qat'i nazar. Oddiy foydalanuvchi sifatida ishlaganda (masalan, `shamsiddin` nomi bilan), sizda bunday cheksiz huquq yo'q — bu, ataylab shunday qilingan: agar siz doim `root` sifatida ishlasangiz, bitta xato buyruq (masalan, adashib yozilgan `rm -rf`), butun tizimni buzib qo'yishi mumkin.

### `whoami` va `id` — men kimman

`whoami` (avvalgi darslarda ko'rilgan) — joriy foydalanuvchi nomini ko'rsatadi. `id` — bundan ham batafsilroq: foydalanuvchi ID raqami (UID), asosiy guruhi va a'zo bo'lgan **barcha** qo'shimcha guruhlarni ko'rsatadi. Bu, ayniqsa "nega menda bu faylga kirish huquqi yo'q" degan savolga javob topishda foydali — chunki ruxsat, ko'pincha, siz qaysi guruhga a'zoligingizga bog'liq.

### `sudo` — vaqtincha administrator bo'lish

`sudo` (superuser do — "super foydalanuvchi sifatida bajar") — oddiy foydalanuvchiga, **bitta buyruqni**, `root` huquqlari bilan bajarish imkonini beradi, butun sessiyani `root`ga aylantirmasdan. `sudo <buyruq>` yozilganda, tizim odatda sizning **shaxsiy parolingizni** so'raydi (root parolini emas) — va agar siz, tizim administratori tomonidan `sudo` ishlatishga ruxsat berilgan foydalanuvchilar ro'yxatida bo'lsangiz, buyruq bajariladi.

`sudo` — kundalik ishlarda kamdan-kam kerak bo'ladi: asosan, dastur o'rnatish (9-bobda ko'riladi), tizim xizmatlarini boshqarish (5-bobda ko'rilgan `systemctl`) yoki tizimga tegishli fayllarni (masalan, `/etc` papkasidagi konfiguratsiya) tahrirlashda ishlatiladi.

### `chown` — egasini o'zgartirish

`chown <yangi-egasi> <fayl>` — faylning **egasini** o'zgartiradi. Guruhini ham birga o'zgartirish uchun: `chown <egasi>:<guruh> <fayl>`. Bu amal, odatda, faqat `root` (yoki `sudo` orqali) bajara oladi — chunki, aks holda, istalgan foydalanuvchi, boshqasining faylini "o'ziniki" qilib olishi mumkin bo'lardi.

## Amaliy misol

Joriy foydalanuvchi haqida ma'lumot olamiz:

```bash
whoami
id
```

Natija (misol):

```
shamsiddin
uid=1000(shamsiddin) gid=1000(shamsiddin) groups=1000(shamsiddin),27(sudo),1001(docker)
```

Bu, `shamsiddin` foydalanuvchisi, `sudo` va `docker` guruhlariga ham a'zo ekanini ko'rsatadi — bu, unga, mos ravishda, administrator buyruqlarini bajarish va Docker'ni boshqarish huquqini beradi.

Endi, `sudo` talab qiladigan (odatiy foydalanuvchi huquqi yetmaydigan) buyruqni sinaymiz — masalan, tizim paketlar ro'yxatini yangilash:

```bash
sudo apt update
```

Terminal, parolingizni so'raydi (yozilganda, ekranda **hech narsa ko'rinmaydi** — bu, normal holat, parol maxfiyligini saqlash uchun shunday qilingan). Parolni kiritib, `Enter` bosing.

`chown` misoli — faraz qiling, sizda, boshqa foydalanuvchiga tegishli (masalan, o'rnatish jarayonida `root` egaligida qolib ketgan) fayl bor:

```bash
sudo touch /tmp/tizim-fayli.txt
ls -l /tmp/tizim-fayli.txt
```

Natija (misol):

```
-rw-r--r-- 1 root root 0 avg 19 15:30 /tmp/tizim-fayli.txt
```

Endi, uning egasini, o'zimizga o'zgartiramiz:

```bash
sudo chown shamsiddin:shamsiddin /tmp/tizim-fayli.txt
ls -l /tmp/tizim-fayli.txt
```

Natija:

```
-rw-r--r-- 1 shamsiddin shamsiddin 0 avg 19 15:30 tizim-fayli.txt
```

## Keng tarqalgan xatolar

❌ **Kundalik ishlarda, "ishlamasa, `sudo` qo'shib ko'raman" tamoyili bilan, har bir xato bergan buyruq oldiga `sudo` yozib yuborish.**
✅ Avval, xato **nima sababdan** yuz berayotganini tushunishga harakat qiling — ko'pincha muammo, ruxsatga emas, boshqa narsaga (masalan, noto'g'ri yo'l yoki buyruq nomi) bog'liq bo'ladi.

**Nega xato:** `sudo`, ko'p hollarda **haqiqiy muammoni yashiradi** — masalan, agar siz o'z shaxsiy fayllaringizni tahrirlashda "Permission denied" xatosini olsangiz, va buni `sudo` bilan "hal qilsangiz", fayl endi **`root`ga tegishli** bo'lib qoladi, va keyingi safar, `sudo`siz, unga sizning o'zingiz ham kira olmay qolishingiz mumkin.

❌ **`sudo rm -rf` buyrug'ini, yo'lni ikki marta tekshirmasdan ishga tushirish.**
✅ `sudo` bilan birga `rm -rf` ishlatishdan oldin, **albatta**, avval `sudo`siz, faqat `ls` bilan, aynan qaysi fayllar o'chirilishini ko'rib chiqing.

**Nega xato:** `sudo`, `root` huquqlari bilan ishlagani uchun, **hech qanday ruxsat tekshiruvisiz**, tizimdagi istalgan faylni o'chira oladi — oddiy foydalanuvchi huquqida bo'lganda himoya qiluvchi ruxsat tizimi, `sudo` ostida ishlamaydi.

❌ **`chown`ni, faylni "o'ziniki qilib olish" uchun, tushunmasdan, tasodifiy foydalanuvchi nomi bilan ishlatish.**
✅ `chown`dan foydalanishdan oldin, `id` yoki `whoami` bilan, o'zingizning aniq foydalanuvchi nomingizni tekshiring, va uni to'g'ri yozing.

**Nega xato:** Noto'g'ri yozilgan foydalanuvchi nomi (masalan, mavjud bo'lmagan nom), `chown`ning "invalid user" xatosi berishiga, yoki (yomonroq holatda) faylni, mavjud bo'lgan, lekin xato foydalanuvchiga o'tkazib qo'yishga olib kelishi mumkin.

## Mashq/topshiriq

**(Oson)** `whoami` va `id` buyruqlarini ishga tushiring, va o'zingiz qaysi guruhlarga a'zo ekanligingizni yozib qo'ying.

**(O'rtacha)** `sudo` yordamida, tizim paketlari ro'yxatini yangilang (`sudo apt update`), va parol so'ralganda, uni to'g'ri kiritishni mashq qiling.

**(Qiyin)** `/tmp` papkasida (bu — vaqtinchalik fayllar uchun, barcha foydalanuvchilar yoza oladigan papka), `sudo touch /tmp/mashq.txt` orqali fayl yarating. `ls -l` bilan uning egasi `root` ekanini tasdiqlang. So'ng, `sudo chown` orqali, uning egasini o'zingizga o'zgartiring, va endi uni, `sudo`siz, oddiy `rm` bilan o'chira olishingizni tekshiring (agar egasi hali `root` bo'lsa, oddiy `rm` "Operation not permitted" xatosi berishi mumkin).

## Qisqacha xulosa

Har bir Linux tizimida, cheksiz huquqqa ega `root` foydalanuvchisi mavjud, va oddiy foydalanuvchilar, kundalik xavfsizlik uchun, undan cheklangan huquqlar bilan ishlaydi; `sudo`, kerak bo'lganda, **bitta buyruqqa**, vaqtincha `root` huquqini beradi (o'z parolingiz orqali), `chown` esa — faylning egasi/guruhini o'zgartiradi; ikkalasi ham kuchli vositalar bo'lgani uchun, ularni faqat **haqiqatan zarur bo'lganda**, va nima qilayotganingizni tushungan holda ishlatish tavsiya etiladi.
