# Internetdan yuklab olish (curl va wget)

## Bu darsda nimalarni o'rganasiz

- `wget` bilan, faylni, internetdan, to'g'ridan-to'g'ri diskka yuklab olasiz
- `curl` bilan, veb-sahifa yoki API'ga so'rov yuborasiz, va natijani ko'rasiz
- `curl` va `wget` orasidagi asosiy farqni tushunasiz
- `curl` orqali, faylni saqlashni (`-o`) va API javobini o'qishni o'rganasiz

## Nazariy qism

### `wget` — fayl yuklab olishga ixtisoslashgan

**`wget`** — o'z nomidan ko'rinib turganidek ("web get"), internetdan, faylni (masalan, dastur, arxiv yoki hujjat), to'g'ridan-to'g'ri, joriy papkaga yuklab olish uchun mo'ljallangan:

```bash
wget <URL>
```

`wget`, standart holatda, faylni, URL'dagi **aynan shu nom bilan**, joriy papkaga saqlaydi, va yuklash jarayonini (foiz, tezlik, qolgan vaqt) ekranda ko'rsatadi.

### `curl` — universalroq, ko'p qirrali vosita

**`curl`** — `wget`dan ko'ra, ancha keng qamrovli vosita: u, nafaqat fayl yuklab olishi, balki, veb-server yoki API bilan, turli usulda (`GET`, `POST` va boshqalar) "gaplashishi" mumkin. Eng katta farq: `curl`, standart holatda, natijani, **faylga emas, to'g'ridan-to'g'ri terminal ekraniga** chiqaradi:

```bash
curl <URL>
```

Faylni, diskка saqlash uchun, `-o <fayl-nomi>` (kichik nom bilan saqlash) yoki `-O` (URL'dagi asl nom bilan saqlash) bayrog'i kerak:

```bash
curl -o mening-faylim.html https://example.com
curl -O https://example.com/hujjat.pdf
```

### Qачон qaysi birini ishlatish

| Vaziyat | Tavsiya etiladigan vosita |
|---|---|
| Faylni, to'g'ridan-to'g'ri diskка yuklab olish | `wget` (soddaroq, standart holatda faylga saqlaydi) |
| Veb-sahifa yoki API javobini, terminalda ko'rish | `curl` |
| API'ga so'rov yuborish (masalan, ma'lumot jo'natish) | `curl` (`wget`, buni tabiiy ravishda qo'llab-quvvatlamaydi) |
| Butun papka yoki saytni, ichma-ich yuklab olish | `wget -r` (rekursiv rejimi, `curl`da yo'q) |

### `curl` bilan API'ga so'rov yuborish (qisqa kirish)

`curl`, ko'pincha, dasturiy interfeys (API)larni sinash uchun ishlatiladi. Eng oddiy holat — `GET` so'rovi (ma'lumot **olish**):

```bash
curl https://api.example.com/malumot
```

`POST` so'rovi (ma'lumot **yuborish**) uchun, `-X POST` va `-d` (ma'lumot) bayroqlari ishlatiladi — bu, keyingi, chuqurroq mavzu bo'lib, bu yerda faqat asosiy tushuncha sifatida keltiriladi.

## Amaliy misol

`wget` bilan, ochiq, sinov uchun mavjud faylni yuklab olamiz:

```bash
mkdir -p ~/sinov-yuklash
cd ~/sinov-yuklash
wget https://www.gnu.org/graphics/heckert_gnu.small.png
```

Natija (misol):

```
Saving to: 'heckert_gnu.small.png'
heckert_gnu.small.png   100%[===================>]   3.98K   --.-KB/s   in 0.001s
```

Yuklangan faylni tekshiramiz:

```bash
ls -lh ~/sinov-yuklash
```

Endi, `curl` bilan, veb-sahifa mazmunini, to'g'ridan-to'g'ri terminalda ko'ramiz:

```bash
curl https://example.com
```

Natijada, sahifaning HTML kodi, uzun matn sifatida, ekranga chiqadi.

Xuddi shu sahifani, endi, faylga saqlaymiz:

```bash
curl -o sahifa.html https://example.com
cat sahifa.html | head -n 5
```

`curl`ning, faqat sarlavha (header) ma'lumotini ko'rish imkoniyati (bu, ayniqsa, server "ishlab turibdimi" yoki qanday javob qaytarayotganini tekshirishda foydali):

```bash
curl -I https://example.com
```

Natija (misol):

```
HTTP/1.1 200 OK
Content-Type: text/html; charset=UTF-8
```

`200 OK` — server, so'rovga, muvaffaqiyatli javob berganini bildiradi.

## Keng tarqalgan xatolar

❌ **`curl`ni ishlatib, natija ekranga "quyilib" ketganda, uni fayl sifatida saqlashni unutish** (`-o` yoki `-O` bayrog'isiz ishlatish).
✅ Agar natijani, keyinroq ishlatish uchun **saqlash** kerak bo'lsa, albatta `-o <nom>` yoki `-O` bayrog'ini qo'shing.

**Nega xato:** `curl`, `wget`dan farqli, standart holatda, hech qanday faylga saqlamaydi — u, faqat, natijani, terminal ekraniga "chop etadi"; agar bu, ataylab qilinmagan bo'lsa, ma'lumot, hech qayerda saqlanmasdan, faqat ko'rinib, yo'qolib qoladi.

❌ **URL manzilini, tirnoqsiz yozish, ayniqsa u, maxsus belgilar (`&`, `?`) o'z ichiga olganda.**
✅ URL manzilini, doim, tirnoq ichiga oling: `curl "https://example.com/qidiruv?soz=terminal&til=uz"`.

**Nega xato:** Ba'zi belgilar (masalan, `&`), shell uchun, **maxsus ma'no** ga ega (`&` — buyruqni fonga yuborish, 5-bobda ko'rilgan) — tirnoqsiz yozilgan URL, shell tomonidan, noto'g'ri, bir nechta qismga bo'lib yuborilishi mumkin.

❌ **Ishonchsiz manbadan, faylni, uning nima ekanini tekshirmasdan yuklab olish va darhol ishga tushirish.**
✅ Internetdan yuklab olingan har qanday fayl, ayniqsa ijro etiladigan (skript yoki dastur) bo'lsa, uni ishga tushirishdan **oldin**, manba qanchalik ishonchli ekanini baholang, va imkon bo'lsa, mazmunini (`cat`, `less` bilan) ko'rib chiqing.

**Nega xato:** `wget`/`curl` orqali yuklab olingan fayl, avtomatik ravishda, hech qanday xavfsizlik tekshiruvidan o'tmaydi — bu, oddiy fayl ko'chirish amali, xolos; uning zararli yoki zararsizligini, foydalanuvchining o'zi baholashi kerak.

## Mashq/topshiriq

**(Oson)** `curl -I https://example.com` buyrug'i orqali, `example.com` saytining, faqat sarlavha ma'lumotini ko'ring, va javob kodi (masalan, `200 OK`) nimani bildirishini tushunib oling.

**(O'rtacha)** `wget` yordamida, `https://example.com` sahifasini, `~/sinov-yuklash/mening-sahifam.html` nomi bilan saqlang (maslahat: `wget -O <nom> <url>` — `wget`da ham, `curl`dagiga o'xshash, `-O` bayrog'i, saqlash nomini belgilash uchun ishlatiladi).

**(Qiyin)** `curl` yordamida, `https://example.com` sahifasining, faqat, `<title>` teg ichidagi matnini toping (maslahat: `curl -s https://example.com | grep -i "<title>"` — `-s` bayrog'i, yuklash jarayonining progress-barini yashiradi, `grep`, avvalgi bobda o'rgangan bilim, kerakli qatorni topadi).

## Qisqacha xulosa

`wget` — internetdan, faylni, to'g'ridan-to'g'ri diskка yuklab olish uchun soddaroq va qulayroq vosita (standart holatda faylga saqlaydi), `curl` esa — ancha ko'p qirrali bo'lib, veb-sahifa yoki API bilan, turli usulda (ko'rish, saqlash, so'rov yuborish) ishlash imkonini beradi (standart holatda, natijani terminalga chiqaradi, saqlash uchun `-o`/`-O` kerak) — ikkalasi ham, terminaldan, internet bilan ishlashning asosiy vositalari hisoblanadi.
