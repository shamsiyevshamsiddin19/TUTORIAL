# Profilni moslashtirish

## Bu darsda nimalarni o'rganasiz

- `.bashrc` fayli nima ekanini va u qачон ishga tushishini tushunasiz
- Unga, doimiy muhit o'zgaruvchilari va sozlamalar qo'sha olasiz
- `alias` bilan, uzun buyruqlarga, o'zingizga qulay, qisqa nom bera olasiz
- O'zgarishlarni, terminalni qayta ochmasdan, darhol qo'llashni (`source`) o'rganasiz

## Nazariy qism

### `.bashrc` — bash sizga "qulay" bo'lib qolishining siri

Avvalgi darsda ko'rganingizdek, `export` bilan yaratilgan o'zgaruvchi, terminal yopilganda yo'qoladi. Bu muammoni hal qilish uchun, bash, har safar **interaktiv sessiya** (ya'ni, siz to'g'ridan-to'g'ri buyruq yozadigan terminal) ochilganda, avtomatik ravishda, uy papkangizdagi **`.bashrc`** faylini o'qiydi va undagi barcha buyruqlarni bajaradi.

Shuning uchun, agar biror sozlamani (masalan, `export` yoki `alias`ni), **har safar terminal ochilganda** avtomatik qo'llanilishini xohlasangiz, uni, qo'lda, har safar yozish o'rniga, **`.bashrc`ga bir marta yozib qo'yish** kifoya.

(Agar siz, `bash` o'rniga `zsh` ishlatsangiz, xuddi shu vazifani, `.zshrc` fayli bajaradi — mantiq bir xil, faqat fayl nomi boshqacha.)

### `.bashrc`ni tahrirlash

Bu — oddiy matn fayli, uni, 2.4-darsda o'rgangan `nano` yoki `vim` bilan ochish mumkin:

```bash
nano ~/.bashrc
```

Fayl oxiriga, xohlagan sozlamalaringizni qo'shishingiz mumkin (masalan, `export` buyruqlari yoki `alias`lar).

### `alias` — uzun buyruqqa qisqa nom

`alias` — bir yoki bir nechta so'zdan iborat, uzun yoki tez-tez ishlatiladigan buyruqqa, **qisqa taxallus** berish imkonini beradi:

```bash
alias <qisqa-nom>='<to'liq-buyruq>'
```

Masalan:

```bash
alias ll='ls -lah'
```

Shundan so'ng, siz, `ls -lah` o'rniga, shunchaki `ll` deb yozishingiz mumkin — natija xuddi shunday bo'ladi. Xuddi `export` kabi, terminalda to'g'ridan-to'g'ri yozilgan `alias`, faqat joriy sessiyada ishlaydi — doimiy bo'lishi uchun, uni ham `.bashrc`ga yozish kerak.

### `source` — o'zgarishlarni darhol qo'llash

`.bashrc`ni tahrirlagandan so'ng, odatda, o'zgarishlar, faqat **yangi** terminal oynasi ochilganda kuchga kiradi. Agar, terminalni qayta ochmasdan, o'zgarishlarni **darhol** qo'llash kerak bo'lsa, `source` buyrug'i ishlatiladi:

```bash
source ~/.bashrc
```

Bu, `.bashrc` faylini, xuddi terminal yangi ochilgandek, **qaytadan o'qib chiqadi**, va undagi barcha o'zgarishlarni, joriy sessiyaga qo'llaydi.

## Amaliy misol

`.bashrc` faylini, `nano` bilan ochamiz:

```bash
nano ~/.bashrc
```

Faylning **eng oxiriga**, quyidagi qatorlarni qo'shamiz:

```bash
# Mening shaxsiy sozlamalarim
alias ll='ls -lah'
alias ..='cd ..'
alias gitlog='git log --oneline --graph'
export KURS_NOMI="Terminal darsligi"
```

Saqlab (`Ctrl+O`, `Enter`), chiqamiz (`Ctrl+X`).

O'zgarishlarni, terminalni qayta ochmasdan, darhol qo'llaymiz:

```bash
source ~/.bashrc
```

Endi, yangi `alias`larni sinaymiz:

```bash
ll
```

Bu, `ls -lah` bilan bir xil natijani beradi.

```bash
cd ~/mening-skriptlarim
..
pwd
```

`..` — `cd ..` bilan bir xil ishlaydi, va sizni, bitta yuqori papkaga qaytaradi.

Yangi `export` qilingan o'zgaruvchini tekshiramiz:

```bash
echo $KURS_NOMI
```

Natija: `Terminal darsligi`

Endi, **yangi** terminal oynasi oching (yoki yangi tab), va u yerda ham, xuddi shu buyruqlarni sinab ko'ring — ular, `source` qilmasdan ham, avtomatik ishlaydi, chunki yangi terminal, `.bashrc`ni, ochilishida, o'zi avtomatik o'qiydi.

## Keng tarqalgan xatolar

❌ **`.bashrc`ga o'zgarish kiritgandan so'ng, `source` qilmasdan (yoki terminalni qayta ochmasdan), "nega ishlamayapti" deb hayron bo'lish.**
✅ O'zgarishlarni darhol ko'rish uchun, `source ~/.bashrc` ishlating, yoki yangi terminal oynasi oching.

**Nega xato:** `.bashrc`, faqat, terminal **ochilayotgan paytda**, bir marta o'qiladi — allaqachon ochiq turgan terminal sessiyasi, faylning yangi o'zgarishlaridan **avtomatik xabardor bo'lmaydi**.

❌ **`alias` nomini, mavjud, muhim buyruq nomi bilan bir xil qilib qo'yish** (masalan, `alias rm='rm -i'` deb emas, adashib `alias ls='rm -rf'` kabi xato yozish — bu, misol sifatida, juda xavfli).
✅ `alias` nomlarini, ehtiyotkorlik bilan tanlang, va ularni yaratishdan oldin, ular nima qilishini, ikki marta tekshiring.

**Nega xato:** Agar `alias`, mavjud buyruq nomini "qoplab" qo'ysa (masalan, `ls`), keyingi safar, siz `ls` deb yozganingizda, **haqiqiy `ls` o'rniga**, sizning noto'g'ri yozilgan `alias`ingiz ishga tushadi — bu, ayniqsa xavfli buyruqlar (masalan, `rm`) bilan bog'liq bo'lsa, katta zarar keltirishi mumkin.

❌ **`.bashrc`ni tahrirlashda, uning **oldingi, tizim tomonidan qo'shilgan** qatorlarini bilmasdan o'chirib yoki o'zgartirib yuborish.**
✅ Har doim, o'z sozlamalaringizni, faylning **eng oxiriga**, mavjud qatorlarni o'chirmasdan qo'shing — kerak bo'lsa, o'z qismingizni, aniq izoh (masalan, `# Mening shaxsiy sozlamalarim`) bilan ajratib qo'ying.

**Nega xato:** `.bashrc`ning boshlang'ich qismida, ko'pincha, terminalning to'g'ri ishlashi uchun zarur, tizim tomonidan avtomatik qo'shilgan sozlamalar bo'ladi — ularni bilmasdan o'chirish, terminalning kutilmagan tarzda ishlashiga olib kelishi mumkin.

## Mashq/topshiriq

**(Oson)** `.bashrc` faylingizga, `alias c='clear'` qatorini qo'shing, `source` qiling, va `c` buyrug'ining, ekranni tozalashini tekshiring.

**(O'rtacha)** `.bashrc`ga, `alias hisobot='cd ~/loyihalar && ls -lah'` qatorini qo'shing (agar `~/loyihalar` papkasi mavjud bo'lmasa, avval yarating). `source` qilib, `hisobot` buyrug'ini sinab ko'ring — bu, bitta qisqa buyruq bilan, ikkita amalni (papkaga o'tish va ro'yxatlash) ketma-ket bajarishi kerak.

**(Qiyin)** `.bashrc`ga, terminal ochilganda, avtomatik ravishda, joriy sana va foydalanuvchi nomini ko'rsatadigan qator qo'shing (maslahat: `echo "Xush kelibsiz, $(whoami)! Bugun: $(date +%Y-%m-%d)"` — `$(...)` konstruksiyasi, ichidagi buyruqning natijasini, matn ichiga "qo'yadi"). `source` qilib sinab ko'ring, so'ng yangi terminal oynasi ochib, xabarning avtomatik chiqishini tasdiqlang.

## Qisqacha xulosa

`.bashrc` — har safar interaktiv terminal ochilganda, avtomatik o'qiladigan fayl bo'lib, unga qo'shilgan `export` va `alias`lar, **doimiy** (har safar terminalda mavjud) bo'lib qoladi; `alias`, uzun yoki tez-tez ishlatiladigan buyruqlarga qisqa nom berish imkonini beradi, `source ~/.bashrc` esa — faylga kiritilgan o'zgarishlarni, terminalni qayta ochmasdan, joriy sessiyaga darhol qo'llash uchun ishlatiladi.
