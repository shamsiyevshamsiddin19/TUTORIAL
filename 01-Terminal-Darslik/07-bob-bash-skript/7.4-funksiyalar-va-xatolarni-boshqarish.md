# Funksiyalar va xatolarni boshqarish

## Bu darsda nimalarni o'rganasiz

- Skriptni, qayta ishlatiladigan **funksiyalarga** bo'lib yozasiz
- `exit code` (chiqish kodi) nima ekanini va uni qanday tekshirishni tushunasiz
- `set -e` bilan, skriptni, birinchi xatoda avtomatik to'xtatasiz
- Oddiy, ammo samarali xato tekshiruvini skriptga qo'shasiz

## Nazariy qism

### Funksiya — skriptning "kichik, nomlangan bo'lagi"

Skript kattalashgan sari, bir xil kod bo'lagi, bir necha joyda takrorlanishi mumkin. **Funksiya** — kodning shu qismini, bir marta yozib, keyin, xohlagan joyda, **nomi orqali chaqirish** imkonini beradi:

```bash
funksiya_nomi() {
    # bajariladigan buyruqlar
}
```

Chaqirish — juda oddiy, xuddi oddiy buyruqdek:

```bash
funksiya_nomi
```

Funksiyaga ham, oddiy skriptga o'xshab, argument berish mumkin — funksiya ichida, ular ham xuddi `$1`, `$2`, `$@` orqali o'qiladi (bu, skriptning o'z argumentlaridan **alohida**).

### `exit code` — buyruq muvaffaqiyatli bo'ldimi

Terminaldagi **har bir** buyruq (va har bir skript), tugagach, tizimga, **chiqish kodi (exit code)** deb ataluvchi, bitta son qaytaradi: `0` — buyruq **muvaffaqiyatli** bajarildi degani, `0`dan boshqa istalgan son (odatda `1`) — **xato yuz berdi** degani.

Oxirgi bajarilgan buyruqning chiqish kodini, `$?` orqali ko'rish mumkin:

```bash
ls /mavjud-bolmagan-joy
echo $?
```

Skript ichida, `exit <son>` buyrug'i, skriptni, ko'rsatilgan kod bilan, **darhol to'xtatadi**.

### `&&` va `||` — chiqish kodiga qarab, zanjir qurish

Avvalgi darslarda ko'rilgan `&&` (VA) va `||` (YOKI), aslida, aynan shu chiqish kodiga asoslanadi:

- `buyruq1 && buyruq2` — `buyruq1` **muvaffaqiyatli** (kod `0`) bo'lsagina, `buyruq2` ishga tushadi
- `buyruq1 || buyruq2` — `buyruq1` **xato** bersa (kod `0` emas), shundagina `buyruq2` ishga tushadi

### `set -e` — birinchi xatoda to'xtash

Standart holatda, bash skript, ichida biror buyruq xato bersa ham, **davom etishda davom etadi** — bu, ba'zan, xato ustiga xatoni "qatlab" boradigan holatga olib kelishi mumkin. Skript boshiga, `set -e` qatorini qo'shish, bu xatti-harakatni o'zgartiradi: endi, **istalgan** buyruq xato bersa, skript, **darhol** to'xtaydi.

```bash
#!/bin/bash
set -e
```

## Amaliy misol

**1-misol (funksiya):**

```bash
nano ~/skriptlar/funksiya-misoli.sh
```

```bash
#!/bin/bash

salomlash() {
    echo "Salom, $1! Bugungi kayfiyating qanday?"
}

xayrlashish() {
    echo "Xayr, $1! Ko'rishguncha!"
}

salomlash "Shamsiddin"
salomlash "Malika"
xayrlashish "Shamsiddin"
```

```bash
chmod u+x ~/skriptlar/funksiya-misoli.sh
~/skriptlar/funksiya-misoli.sh
```

**2-misol (exit code va `&&`/`||`):**

```bash
nano ~/skriptlar/papka-yaratish-tekshiruv.sh
```

```bash
#!/bin/bash

mkdir ~/skriptlar/yangi-papka && echo "Papka muvaffaqiyatli yaratildi." || echo "Xato: papka yaratib bo'lmadi (balki allaqachon mavjud)."
```

```bash
chmod u+x ~/skriptlar/papka-yaratish-tekshiruv.sh
~/skriptlar/papka-yaratish-tekshiruv.sh
```

Birinchi marta: "Papka muvaffaqiyatli yaratildi." Endi, **qayta** ishga tushiring:

```bash
~/skriptlar/papka-yaratish-tekshiruv.sh
```

Bu safar: "Xato: papka yaratib bo'lmadi..." — chunki, papka allaqachon mavjud, va `mkdir`, xato (`exit code` — `0` emas) qaytaradi.

**3-misol (funksiya + shart + `set -e`, real vaziyat):**

```bash
nano ~/skriptlar/xavfsiz-nusxa.sh
```

```bash
#!/bin/bash
set -e

nusxa_ol() {
    manba="$1"
    manzil="$2"

    if [ ! -f "$manba" ]; then
        echo "Xato: '$manba' fayli topilmadi."
        exit 1
    fi

    cp "$manba" "$manzil"
    echo "Nusxa olindi: $manba -> $manzil"
}

nusxa_ol "$1" "$2"
```

```bash
chmod u+x ~/skriptlar/xavfsiz-nusxa.sh
touch ~/skriptlar/asl-fayl.txt
~/skriptlar/xavfsiz-nusxa.sh ~/skriptlar/asl-fayl.txt ~/skriptlar/nusxa-fayl.txt
~/skriptlar/xavfsiz-nusxa.sh ~/skriptlar/mavjud-emas.txt ~/skriptlar/nusxa2.txt
```

Birinchi chaqiruv — muvaffaqiyatli nusxalaydi. Ikkinchi chaqiruv — fayl topilmagani uchun, aniq xato xabari bilan, `exit 1` orqali to'xtaydi.

## Keng tarqalgan xatolar

❌ **Funksiya ichidagi o'zgaruvchini, skriptning boshqa joylarida ham "global" deb hisoblab, nomlarni to'qnashtirib yuborish** (masalan, funksiya ichida ham, tashqarida ham, bir xil nomli `natija` o'zgaruvchisidan foydalanish).
✅ Funksiya ichidagi, faqat o'sha funksiyaga tegishli o'zgaruvchilar uchun, `local` kalit so'zidan foydalaning: `local natija="qiymat"`.

**Nega xato:** Bash'da, standart holatda, funksiya ichida yaratilgan o'zgaruvchi, funksiyadan tashqarida ham **ko'rinadi** (global hisoblanadi) — bu, katta skriptlarda, turli funksiyalarning, bir-birining o'zgaruvchilarini bilmasdan "ustidan yozib qo'yishi"ga olib kelishi mumkin.

❌ **`$?`ni, kerakli buyruqdan **darhol keyin** tekshirmasdan, orada boshqa buyruq (hatto oddiy `echo`) yozib qo'yish.**
✅ `$?`ni, faqat, tekshirmoqchi bo'lgan buyruqdan **bevosita keyingi qatorda** ishlating.

**Nega xato:** `$?`, doim, **eng oxirgi** bajarilgan buyruqning kodini saqlaydi — agar orada, boshqa (hatto zararsiz ko'ringan) buyruq bajarilsa, `$?`, endi, kerakli buyruqning emas, o'sha oraliq buyruqning natijasini ko'rsatadi.

❌ **`set -e` qo'yilgan skriptda, ataylab "xato berishi mumkin" bo'lgan buyruqni (masalan, faylni tekshirish uchun) ishlatib, butun skriptning kutilmaganda to'xtab qolishi.**
✅ Agar biror buyruqning xato berishi **kutilayotgan va normal** holat bo'lsa (masalan, faylni oldindan tekshirish), uni, `if` sharti ichida ishlating, yoki `|| true` qo'shing — bu, `set -e`ning, o'sha bitta buyruq uchun ta'sirini bekor qiladi.

**Nega xato:** `set -e`, **har qanday** nol bo'lmagan chiqish kodini, avtomatik ravishda, "skriptni to'xtatish kerak bo'lgan jiddiy xato" deb hisoblaydi — hatto, agar dasturchi, aslida, o'sha holatni, oddiy tekshiruv sifatida rejalashtirgan bo'lsa ham.

## Mashq/topshiriq

**(Oson)** `xush_kelibsiz` nomli funksiya yozing — u, bitta argument (ism) qabul qilib, "Xush kelibsiz, [ism]!" deb chiqarsin. Funksiyani, ikkita turli ism bilan, ketma-ket ikki marta chaqirib sinang.

**(O'rtacha)** `papka_tozala` nomli funksiya yozing — u, bitta argument (papka nomi) qabul qiladi, agar shu papka mavjud bo'lsa, ichidagi barcha `.tmp` fayllarni `rm` bilan o'chiradi va "Tozalandi: [papka]" deb yozadi; agar papka mavjud bo'lmasa, "Xato: papka topilmadi" deb yozib, `exit 1` bilan to'xtaydi.

**(Qiyin)** Ikkita funksiyadan iborat skript yozing: `fayl_yarat` (argument sifatida fayl nomini oladi, `touch` bilan yaratadi va muvaffaqiyat xabarini chiqaradi) va `fayl_ochir` (argument sifatida fayl nomini oladi, agar fayl mavjud bo'lsa `rm` bilan o'chiradi va xabar beradi, aks holda, xato xabarini chiqaradi). Skript oxirida, ikkala funksiyani ham, ketma-ket chaqirib, bitta faylni avval yaratib, so'ng o'chirishni, avtomatik ravishda ko'rsating. Skript boshiga `set -e` qo'shing va, natijaning, `set -e` bilan ham, xatosiz ishlashini tekshiring.

## Qisqacha xulosa

Funksiyalar (`nom() { ... }`), skriptni, qayta ishlatiladigan, o'qish qulay bo'laklarga bo'ladi, va `local` kalit so'zi, ularning ichidagi o'zgaruvchilarni, boshqa qismlar bilan to'qnashuvdan himoya qiladi; har bir buyruq, o'zining muvaffaqiyat/xato holatini bildiruvchi **chiqish kodini** (`$?` orqali o'qiladigan, `0` — muvaffaqiyat) qaytaradi, va `set -e`, skriptni, birinchi kutilmagan xatoda avtomatik to'xtatib, katta zararning oldini oladi — bu bilimlar, kursning yakuniy loyihasida (15-bobda) to'liq birlashtiriladi.
