# Birinchi bash skript

## Bu darsda nimalarni o'rganasiz

- `#!/bin/bash` (shebang) qatorining vazifasini tushunasiz
- Skript ichida o'zgaruvchi yaratasiz va undan foydalanasiz
- Skriptga, terminal orqali argument berasiz (`$1`, `$2`, `$@`, `$#`)
- To'liq, ishlaydigan birinchi bash skriptingizni yozib, ishga tushirasiz

## Nazariy qism

### Skript nima — allaqachon o'rgangan bilimlaringiz "faylga yoziladi"

Bash skript — bu, aslida, siz shu paytgacha terminalga, bittalab yozgan buyruqlaringizni, **bitta faylga, ketma-ket** yozib qo'yish, va o'sha faylni, bitta buyruq bilan, **to'liq ishga tushirish** imkonini beradigan usul. Agar siz, muayyan buyruqlar ketma-ketligini, tez-tez, deyarli o'zgarishsiz takrorlayotgan bo'lsangiz — bu, skript yozish kerakligining aniq belgisi.

### `#!/bin/bash` — shebang qatori

Har bir bash skript, odatda, birinchi qatorida, quyidagi maxsus yozuvdan boshlanadi:

```bash
#!/bin/bash
```

Bu — **shebang** deb ataladi, va u, tizimga: "bu faylni ishga tushirganda, uni, aynan `/bin/bash` dasturi orqali bajar" deb aytadi. Bu qator bo'lmasa ham, skriptni, `bash skript.sh` deb, aniq ko'rsatib ishga tushirish mumkin, lekin shebang bilan, skriptni, mustaqil, ijro etiladigan fayl sifatida (`./skript.sh`) ishga tushirish mumkin bo'ladi — bu, ancha qulayroq va standart amaliyot.

### Skriptdagi o'zgaruvchilar

Bash skriptida, o'zgaruvchi, `=` belgisi orqali yaratiladi — **muhim: `=` atrofida probel bo'lmasligi kerak**:

```bash
ism="Shamsiddin"
echo "Salom, $ism!"
```

### Argumentlar: `$1`, `$2`, `$@`, `$#`

Skriptga, terminaldan, ishga tushirish paytida, qo'shimcha ma'lumot (argument) berish mumkin:

```bash
./skript.sh birinchi-argument ikkinchi-argument
```

Skript ichida, bu argumentlarga, quyidagi maxsus o'zgaruvchilar orqali murojaat qilinadi:

| Belgi | Ma'nosi |
|---|---|
| `$1` | Birinchi argument |
| `$2` | Ikkinchi argument (va hokazo, `$3`, `$4`...) |
| `$@` | **Barcha** argumentlar, ro'yxat sifatida |
| `$#` | Argumentlar **soni** |
| `$0` | Skriptning **o'zining nomi** |

## Amaliy misol

Papka tayyorlaymiz va birinchi skriptimizni yozamiz:

```bash
mkdir -p ~/skriptlar
nano ~/skriptlar/salom.sh
```

Quyidagi matnni kiritamiz:

```bash
#!/bin/bash

ism="$1"
yosh="$2"

echo "Salom, $ism!"
echo "Sen $yosh yoshdasan."
echo "Skriptga berilgan argumentlar soni: $#"
echo "Barcha argumentlar: $@"
echo "Skriptning nomi: $0"
```

Saqlab (`Ctrl+O`, `Enter`), chiqamiz (`Ctrl+X`).

Skriptga, bajarish ruxsatini beramiz (3.1-darsda o'rganilgan):

```bash
chmod u+x ~/skriptlar/salom.sh
```

Endi, skriptni, argumentlar bilan ishga tushiramiz:

```bash
~/skriptlar/salom.sh Shamsiddin 25
```

Natija:

```
Salom, Shamsiddin!
Sen 25 yoshdasan.
Skriptga berilgan argumentlar soni: 2
Barcha argumentlar: Shamsiddin 25
Skriptning nomi: /home/shamsiddin/skriptlar/salom.sh
```

Endi, argumentsiz ishga tushirib ko'ramiz:

```bash
~/skriptlar/salom.sh
```

Natija:

```
Salom, !
Sen  yoshdasan.
Skriptga berilgan argumentlar soni: 0
Barcha argumentlar: 
Skriptning nomi: /home/shamsiddin/skriptlar/salom.sh
```

E'tibor bering — `$1` va `$2`, agar berilmagan bo'lsa, oddiy **bo'sh qiymat** bo'lib qoladi (xato bermaydi). Bu holatni to'g'ri boshqarish — keyingi darsda (shart operatorlari) o'rganiladi.

## Keng tarqalgan xatolar

❌ **O'zgaruvchi belgilashda, `=` atrofiga probel qo'yish** (masalan, `ism = "Shamsiddin"`).
✅ `=` atrofida, **hech qanday probel bo'lmasligi kerak**: `ism="Shamsiddin"`.

**Nega xato:** Bash, `ism = "Shamsiddin"` yozuvini, o'zgaruvchi belgilash sifatida emas, balki, `ism` nomli **buyruqni**, `=` va `"Shamsiddin"` argumentlari bilan ishga tushirishga urinish sifatida talqin qiladi — va bunday buyruq odatda mavjud emasligi sababli, `command not found` xatosi chiqadi.

❌ **Skriptga bajarish ruxsati (`chmod u+x`) bermasdan, `./skript.sh` orqali ishga tushirishga urinish.**
✅ Yangi yozilgan skriptga, ishga tushirishdan oldin, doim `chmod u+x skript.sh` bilan, bajarish ruxsatini bering (3.1-darsda batafsil ko'rilgan).

**Nega xato:** Yangi yaratilgan fayl, standart holatda, hech qachon bajarish ruxsatiga ega bo'lmaydi — bu, xavfsizlik uchun ataylab shunday qilingan, va uni, har bir yangi skript uchun, qo'lda berish kerak.

❌ **O'zgaruvchini ishlatishda, `$` belgisini yozishni unutish** (masalan, `echo "Salom, ism!"` — `$ism` o'rniga, oddiy "ism" so'zi).
✅ O'zgaruvchining **qiymatini** chiqarish uchun, doim `$` belgisi bilan yozing: `echo "Salom, $ism!"`.

**Nega xato:** `$`siz, `ism` — shell uchun, oddiy, so'zma-so'z matn hisoblanadi, o'zgaruvchi sifatida "ochilmaydi" — natijada, ekranga, o'zgaruvchining qiymati emas, "ism" so'zining o'zi chiqadi.

## Mashq/topshiriq

**(Oson)** `~/skriptlar/hisoblash.sh` nomli skript yozing, u, ikkita argument (`$1` va `$2`) qabul qilib, ularni, "Birinchi son: X, ikkinchi son: Y" ko'rinishida chiqarsin. Skriptni, `10` va `20` argumentlari bilan sinab ko'ring.

**(O'rtacha)** `~/skriptlar/tanishtiruv.sh` skriptini yozing — u, birinchi argument sifatida ismni, ikkinchi argument sifatida kasbni qabul qilib, "Mening ismim [ism], men [kasb] bo'lib ishlayman" ko'rinishida, bitta gap chiqarsin. Skriptni, kamida ikkita turli argument to'plami bilan sinang.

**(Qiyin)** `~/skriptlar/argument-sanash.sh` skriptini yozing — u, `$#` yordamida, o'ziga berilgan argumentlar sonini hisoblab, agar son **3 tadan kam** bo'lsa, "Kamida 3 ta argument bering!" deb yozsin, aks holda, "Yetarli argument berildi: $# ta" deb yozsin (bu — to'liq shart operatoridan foydalanmasdan, faqat `echo` va `$#` bilan, informativ xabar chiqarish mashqi; to'liq shart operatorlari keyingi darsda o'rganiladi, hozircha shunчaki, `$#` ning qiymatini, ikkita alohida holatda (2 ta va 4 ta argument bilan) chaqirib, natijalarni solishtiring).

Sinash: `~/skriptlar/argument-sanash.sh a b` (natija: `2`) va `~/skriptlar/argument-sanash.sh a b c d` (natija: `4`) — bu, keyingi darsda o'rganiladigan `if` bilan, avtomatik tekshiruvga aylantiriladi.

## Qisqacha xulosa

Bash skript — `#!/bin/bash` (shebang) bilan boshlanadigan, oddiy matn fayl bo'lib, uning ichida, oddiy terminal buyruqlari, ketma-ket yoziladi; skript ichida o'zgaruvchilar (`nom=qiymat`, probelsiz) yaratiladi va `$nom` orqali o'qiladi, terminaldan berilgan argumentlarga esa, `$1`, `$2`, `$@` (hammasi) va `$#` (soni) orqali murojaat qilinadi — va har bir yangi skriptni ishga tushirishdan oldin, unga `chmod u+x` bilan bajarish ruxsatini berish shart.
