# Terminaldagi matn muharrirlari

## Bu darsda nimalarni o'rganasiz

- `nano` bilan, faylni ochib, tahrirlab, saqlaysiz — hech qanday qo'shimcha bilimsiz
- `vim`ning ikkita asosiy rejimini (Normal va Insert) farqlaysiz
- `vim`da faylni ochish, tahrirlash, saqlash va yopishning minimal zarur buyruqlarini o'rganasiz

## Nazariy qism

### Nega terminalda alohida matn muharriri kerak

Server bilan `ssh` orqali ishlaganda (8-bobda o'rganiladi), sizda odatda **GUI yo'q** — ya'ni, tanish matn muharriringizni (masalan, VS Code) ochib bo'lmaydi. Konfiguratsiya faylini tahrirlash yoki skript yozish uchun, terminalning o'zida ishlaydigan muharrir kerak bo'ladi. Linux'da ikkita eng mashhur variant bor: **nano** (sodda, boshlovchilar uchun qulay) va **vim** (kuchli, ammo o'zgacha boshqaruvga ega, o'rganish egri chizig'i tikroq).

### `nano` — sodda va tushunarli

`nano <fayl>` — faylni ochadi, va siz, **to'g'ridan-to'g'ri yozishni boshlashingiz** mumkin — xuddi oddiy matn muharriridagidek. Ekranning pastki qismida, mavjud buyruqlar (`^` belgisi — `Ctrl` tugmasini bildiradi) doim ko'rsatib turiladi:

- `Ctrl+O` — saqlash (Write Out)
- `Ctrl+X` — chiqish (Exit)
- `Ctrl+K` — joriy qatorni kesish (o'chirish)
- `Ctrl+W` — qidirish

`nano`da hech qanday "rejim" tushunchasi yo'q — siz doim, xohlagan joyingizga, to'g'ridan-to'g'ri yozishingiz mumkin.

### `vim` — kuchli, ammo rejimlarga asoslangan

`vim <fayl>` — faylni ochadi, ammo `nano`dan farqli, u **rejimlar** asosida ishlaydi. Boshida adashtiruvchi tuyulishi mumkin, lekin ikkita asosiy rejimni tushunish yetarli:

- **Normal rejim** (`vim` ochilganda, standart holat) — bu yerda, harflar, **buyruq** sifatida ishlaydi (yozish uchun emas). Masalan, `dd` — joriy qatorni o'chiradi, `yy` — nusxalaydi, `x` — bitta belgini o'chiradi.
- **Insert rejim** — bu yerda, siz oddiy matn muharriridagidek, **erkin yozishingiz** mumkin. Normal rejimdan Insert rejimga o'tish uchun — `i` tugmasini bosing. Insert rejimdan **Normal**ga qaytish uchun — `Esc` tugmasi.

### `vim`ning minimal zarur buyruqlari

| Buyruq | Vazifasi |
|---|---|
| `i` | Insert rejimga o'tish (yozishni boshlash) |
| `Esc` | Insert rejimdan Normal rejimga qaytish |
| `:w` | Saqlash (Normal rejimda, `Esc`dan keyin yoziladi) |
| `:q` | Chiqish (agar o'zgarish saqlanmagan bo'lsa, xato beradi) |
| `:wq` | Saqlab, chiqish (eng ko'p ishlatiladigan birikma) |
| `:q!` | Saqlamasdan, **majburiy** chiqish (barcha o'zgarishlarni bekor qilish) |

**Eslab qolish uchun eng muhim narsa:** agar `vim`da adashib qolsangiz, `Esc` tugmasini bir necha marta bosing (Normal rejimga qaytish uchun), so'ng `:q!` yozib `Enter` bosing — bu, hech qanday o'zgarishni saqlamasdan, xavfsiz chiqadi.

## Amaliy misol

`nano` bilan, oddiy eslatma faylini yaratamiz:

```bash
nano ~/eslatma.txt
```

Ochilgan oynada, quyidagi matnni yozing:

```
Bugungi vazifalar:
- Terminal darsligini o'qish
- Amaliy mashqlarni bajarish
```

Saqlash uchun `Ctrl+O`, so'ng `Enter` (fayl nomini tasdiqlash uchun) bosing. Chiqish uchun — `Ctrl+X`.

Tekshiramiz:

```bash
cat ~/eslatma.txt
```

Endi, xuddi shu faylni `vim` bilan ochamiz va bitta qator qo'shamiz:

```bash
vim ~/eslatma.txt
```

Vim ochilgach (Normal rejimda turasiz):

1. `G` tugmasini bosing — bu, faylning **oxiriga** o'tkazadi
2. `o` tugmasini bosing (kichik harf) — bu, joriy qatordan **keyin yangi qator ochib**, avtomatik Insert rejimga o'tkazadi
3. Yozing: `- Vim bilan tanishish`
4. `Esc` bosing — Normal rejimga qaytish
5. `:wq` yozib, `Enter` bosing — saqlab, chiqish

Tekshiramiz:

```bash
cat ~/eslatma.txt
```

Natijada, uchinchi qator qo'shilgan bo'ladi.

## Keng tarqalgan xatolar

❌ **`vim`ni birinchi marta ochib, to'g'ridan-to'g'ri klaviaturada yozishga urinish** (Insert rejimga o'tmasdan). Bu, matn yozish o'rniga, harflarning **buyruq** sifatida bajarilishiga olib keladi — masalan, `d`, `d` ketma-ket bosilsa, butun qator kutilmaganda o'chib ketadi.
✅ `vim`da yozishdan oldin, doim avval **`i`** tugmasini bosib, Insert rejimga o'tganingizga ishonch hosil qiling.

**Nega xato:** `vim`, standart holatda **Normal rejimda** ochiladi — bu rejimda, harflar, matn emas, balki **buyruq** sifatida talqin qilinadi.

❌ **`vim`dan chiqa olmay, terminal oynasini butunlay yopib qo'yish yoki `Ctrl+C`ni son-sanoqsiz bosish.**
✅ Chiqish uchun: avval `Esc` (Normal rejimga qaytish uchun, ehtiyot chorasi sifatida bir necha marta bosish mumkin), so'ng `:q!` va `Enter` — bu, har qanday holatdan, o'zgarishlarni saqlamasdan, xavfsiz chiqaradi.

**Nega xato:** `vim`, `Ctrl+C` kabi "odatiy" to'xtatish tugmalariga, boshqa terminaldagi dasturlar kabi javob bermaydi — undan chiqish, faqat o'ziga xos buyruqlar (`:q`, `:q!`, `:wq`) orqali amalga oshiriladi.

❌ **`nano`da, `Ctrl+X` bilan saqlamasdan chiqishga urinish, so'ng o'zgarishlar yo'qolganini ko'rib hayron qolish.**
✅ Chiqishdan oldin, agar o'zgarishlarni saqlamoqchi bo'lsangiz, avval **`Ctrl+O`** (saqlash), so'ng `Enter` (tasdiqlash), va **shundan keyingina** `Ctrl+X` (chiqish) bosing.

**Nega xato:** `Ctrl+X` — faqat **chiqish** buyrug'i, saqlash emas; agar saqlanmagan o'zgarish bo'lsa, `nano` odatda saqlashni so'raydi, lekin buni chalkashtirib, "N" (No) bosib yuborish — barcha o'zgarishlarni yo'qotadi.

## Mashq/topshiriq

**(Oson)** `nano` bilan `~/sinov-fayl.txt` nomli yangi fayl oching, ichiga "Bu mening birinchi nano faylim" deb yozing, saqlang va chiqing. `cat` bilan tekshiring.

**(O'rtacha)** `vim` bilan xuddi shu faylni oching, Insert rejimga o'ting (`i`), oxiriga yangi qator sifatida "Vim bilan ham ishladim" deb qo'shing, `Esc` bosing, va `:wq` bilan saqlab chiqing.

**(Qiyin)** `vim` bilan `~/sinov-fayl.txt`ni yana oching, bu safar **atayin** noto'g'ri o'zgarish kiriting (masalan, butun matnni o'chirib tashlang — buning uchun Normal rejimda `dG` yozishingiz mumkin, bu "joriy qatordan faylning oxirigacha o'chirish" degani), so'ng bu o'zgarishni **saqlamasdan**, `:q!` orqali xavfsiz chiqing. `cat` bilan tekshirib, faylning **o'zgarishsiz** qolganini tasdiqlang.

## Qisqacha xulosa

`nano` — hech qanday rejim tushunchasisiz, to'g'ridan-to'g'ri yozish mumkin bo'lgan, boshlovchilar uchun eng qulay terminal muharriri (`Ctrl+O` — saqlash, `Ctrl+X` — chiqish), `vim` esa — Normal (buyruqlar) va Insert (yozish) rejimlariga asoslangan, ancha kuchliroq, ammo boshida g'ayrioddiy tuyuladigan muharrir bo'lib, undan xavfsiz chiqishning eng muhim yo'li — `Esc`, so'ng `:wq` (saqlab chiqish) yoki `:q!` (saqlamasdan majburiy chiqish)ni yodda tutish.
