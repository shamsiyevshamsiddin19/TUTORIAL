# Matnni qidirish va sanash

## Bu darsda nimalarni o'rganasiz

- `grep` bilan, fayl ichidan kerakli so'z yoki iborani topasiz
- `grep`ning eng foydali bayroqlarini (`-i`, `-r`, `-n`, `-v`, `-c`) qo'llaysiz
- `wc` bilan, fayldagi qatorlar, so'zlar va belgilar sonini hisoblaysiz

## Nazariy qism

### `grep` — matn ichidan qidirish

`grep <so'z> <fayl>` — ko'rsatilgan faylning, berilgan so'z yoki iborani **o'z ichiga olgan** qatorlarinigina chiqaradi (qolganlarini ko'rsatmaydi). Nomi — "Global Regular Expression Print" degan iboradan kelib chiqqan, va u, oddiy so'zlardan tortib, murakkab shablonlargacha (regex) qidira oladi (murakkab shablonlar — alohida, chuqurroq mavzu).

### `grep`ning eng ko'p ishlatiladigan bayroqlari

| Bayroq | Vazifasi |
|---|---|
| `-i` | Katta-kichik harflarga **e'tibor bermaydi** (`-i`siz, `Salom` va `salom` — boshqa-boshqa deb hisoblanadi) |
| `-r` | Papka ichidagi **barcha fayllarni**, ichma-ich papkalar bilan birga qidiradi (recursive) |
| `-n` | Topilgan qator, fayldagi **qator raqami** bilan birga ko'rsatiladi |
| `-v` | **Teskarisini** ko'rsatadi — so'z **uchramagan** qatorlarni chiqaradi |
| `-c` | Natijalarni ko'rsatmasdan, faqat **nechta qator** topilganini sanaydi |

Bayroqlarni birlashtirish mumkin, masalan `grep -rin "xato"` — papka ichidagi barcha fayllarda, katta-kichik harfga qaramay, "xato" so'zini, qator raqamlari bilan qidiradi.

### `wc` — sanash

`wc <fayl>` (word count) — standart holatda, uchta sonni chiqaradi: **qatorlar soni**, **so'zlar soni**, **belgilar (bayt) soni**. Alohida faqat bittasini bilish kerak bo'lsa: `wc -l` (faqat qatorlar), `wc -w` (faqat so'zlar), `wc -c` (faqat baytlar).

`wc -l`, ayniqsa `grep` bilan birga (keyingi bobda o'rganiladigan pipe, `|`, orqali) ishlatilganda, "nechta natija topildi" degan savolga tez javob berish uchun juda ko'p qo'llaniladi.

## Amaliy misol

Avval, qidirish uchun namuna fayl tayyorlaymiz:

```bash
mkdir -p ~/sinov-matn
cat > ~/sinov-matn/xatolar.log << 'EOF'
2026-08-19 10:01 INFO Server ishga tushdi
2026-08-19 10:02 ERROR Ma'lumotlar bazasiga ulanib bo'lmadi
2026-08-19 10:03 INFO Foydalanuvchi tizimga kirdi
2026-08-19 10:05 error Fayl topilmadi
2026-08-19 10:07 WARNING Xotira kam qolmoqda
2026-08-19 10:09 ERROR So'rov vaqti tugadi
EOF
```

Faqat "ERROR" so'zi bor qatorlarni topamiz:

```bash
grep "ERROR" ~/sinov-matn/xatolar.log
```

Natija:

```
2026-08-19 10:02 ERROR Ma'lumotlar bazasiga ulanib bo'lmadi
2026-08-19 10:09 ERROR So'rov vaqti tugadi
```

E'tibor bering — kichik harfdagi `error` (4-qatorda) natijaga **kirmadi**. Katta-kichik harfga e'tibor bermasdan qidiramiz:

```bash
grep -i "error" ~/sinov-matn/xatolar.log
```

Endi ikkalasi ham (ERROR va error) natijada chiqadi, qator raqamlari bilan:

```bash
grep -in "error" ~/sinov-matn/xatolar.log
```

Natija:

```
2:2026-08-19 10:02 ERROR Ma'lumotlar bazasiga ulanib bo'lmadi
4:2026-08-19 10:05 error Fayl topilmadi
6:2026-08-19 10:09 ERROR So'rov vaqti tugadi
```

Nechta xato borligini sanaymiz:

```bash
grep -ic "error" ~/sinov-matn/xatolar.log
```

Natija: `3`

Xato **bo'lmagan** qatorlarni ko'ramiz:

```bash
grep -iv "error" ~/sinov-matn/xatolar.log
```

Faylda jami nechta qator borligini bilamiz:

```bash
wc -l ~/sinov-matn/xatolar.log
```

Natija: `6 /home/shamsiddin/sinov-matn/xatolar.log`

## Keng tarqalgan xatolar

❌ **`grep`da so'zni tirnoqsiz yozish, ayniqsa so'z ichida probel yoki maxsus belgi bo'lganda** (masalan, `grep xato topilmadi fayl.log`).
✅ Qidirilayotgan iborani doim tirnoq ichiga oling: `grep "xato topilmadi" fayl.log`.

**Nega xato:** Tirnoqsiz yozilsa, shell, probeldan keyingi qismni (`topilmadi`) — `grep`ning **qidirish so'zi** emas, balki **fayl nomi** sifatida qabul qiladi, natijada "fayl topilmadi" xatosi chiqadi.

❌ **`-r` bayrog'ini unutib, butun papkani qidirmoqchi bo'lish** (masalan, `grep "xato" ~/loyihalar` — papka nomi, fayl o'rniga berilgan).
✅ Papka ichida (barcha fayllarda) qidirish uchun, albatta `-r` qo'shing: `grep -r "xato" ~/loyihalar`.

**Nega xato:** `-r`siz, `grep`, berilgan narsani **fayl** deb kutadi; agar u aslida papka bo'lsa, `grep`, "Is a directory" (bu — papka) degan xato beradi va hech narsani qidirmaydi.

❌ **`-i` va `-v` bayroqlarini, ular bir-birini "bekor qilmasligini" bilmasdan aralashtirish** — ba'zilar, `-v` natijasi bo'sh chiqsa, buni xato deb o'ylaydi.
✅ `-v` — "so'z uchramagan qatorlarni ko'rsat" degani; agar **barcha** qatorlarda so'z uchrasa, `-v` natijasi haqiqatan **bo'sh** bo'ladi — bu, xato emas, to'g'ri natija.

**Nega xato:** Bo'sh natija — har doim ham xato degani emas; bu holatda, u shunchaki, "izlangan so'z yo'q qatorlar mavjud emas" degan **to'g'ri** javobdir.

## Mashq/topshiriq

**(Oson)** `~/sinov-matn/xatolar.log` faylida, "INFO" so'zi bor qatorlarni toping.

**(O'rtacha)** Xuddi shu faylda, "WARNING" yoki "ERROR" (katta-kichik harfga qaramay) so'zlaridan kamida bittasi bor qatorlar nechtaligini, bitta buyruqda sanang (maslahat: `grep -E "WARNING|ERROR"` — `-E` bayrog'i, `|` belgisi orqali "yoki" shartini qidirish imkonini beradi).

**(Qiyin)** `~/sinov-matn` papkasi ichida (agar mavjud bo'lmasa, avvalgi darslardan qolgan boshqa fayllar bilan birga), barcha `.txt` va `.log` fayllar orasidan, "ERROR" (katta-kichik harfga qaramay) so'zi uchraydigan **umumiy qatorlar sonini**, bitta buyruqda toping (maslahat: `-r`, `-i`, `-c` bayroqlarini birlashtiring, va `wc -l` bilan solishtiring — ikkisi bir xil sonni berishi kerak, chunki har ikkisi ham "nechta joyda uchradi"ni turlicha hisoblaydi, farqni tushunishga harakat qiling).

<details>
<summary>Javoblarni ko'rish</summary>

1. `grep "INFO" ~/sinov-matn/xatolar.log`.
2. `grep -Ei "WARNING|ERROR" ~/sinov-matn/xatolar.log | wc -l` (yoki `grep -Eic "WARNING|ERROR" ~/sinov-matn/xatolar.log` — ikkalasi ham son beradi, birinchisi `wc -l` orqali qatorlarni sanaydi, ikkinchisi `-c` bayrog'i orqali `grep`ning o'zi sanaydi).
3. `grep -ric "error" ~/sinov-matn/` — bu, har bir faylda nechta mos qator topilganini, fayl nomi bilan birga ko'rsatadi (`-r` — papka ichida, `-i` — katta-kichik harfsiz, `-c` — sanoq). Umumiy sonni ko'rish uchun, natijalarni qo'lda qo'shish kerak bo'ladi — bu, keyingi bobda o'rganiladigan pipe (`|`) va boshqa vositalar bilan avtomatlashtiriladi.

## Qisqacha xulosa

`grep` — fayl (yoki `-r` bilan butun papka) ichidan, kerakli so'z yoki iborani o'z ichiga olgan qatorlarni topib beradi, va uning `-i` (katta-kichik harfsiz), `-n` (qator raqami bilan), `-v` (teskari — topilmaganlarni ko'rsatish) va `-c` (faqat sonini sanash) bayroqlari, kundalik qidiruv ishlarining aksariyatini qamrab oladi; `wc -l`/`-w`/`-c` esa, fayldagi qatorlar, so'zlar yoki belgilar sonini tezda hisoblab beradi.
