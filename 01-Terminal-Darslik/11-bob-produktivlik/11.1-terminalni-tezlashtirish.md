# Terminalni tezlashtirish

## Bu darsda nimalarni o'rganasiz

- `history` va `Ctrl+R` bilan, avval yozgan buyruqlaringizni tez topasiz
- `Tab` tugmasi orqali, buyruq va fayl nomlarini avtomatik to'ldirasiz
- `tmux` bilan, bitta terminal oynasida, bir nechta sessiyani boshqarasiz, va ularni, uzilishdan keyin ham davom ettirasiz

## Nazariy qism

### `history` — barcha yozgan buyruqlaringiz ro'yxati

Bash, siz yozgan **har bir buyruqni**, maxsus tarix (history) faylida (odatda, `~/.bash_history`) saqlab boradi. `history` buyrug'i, ushbu ro'yxatni, raqamlangan holda ko'rsatadi:

```bash
history
```

Ma'lum raqamli buyruqni, qayta ishga tushirish uchun: `!<raqam>` (masalan, `!245`).

### `Ctrl+R` — tarix bo'yicha teskari qidiruv

Uzun tarix ichidan, ma'lum buyruqni, qo'lda qidirib topish — noqulay. `Ctrl+R`, terminalda bosilganda, **interaktiv qidiruv rejimini** ochadi: siz, buyruqning bir qismini yozishni boshlaysiz, va terminal, tarixdan, shunga mos keluvchi, **eng so'nggi** buyruqni, avtomatik topib ko'rsatadi. Yana `Ctrl+R` bosilsa, undan oldingi mos keluvchi natijaga o'tadi. Topilgan buyruqni ishga tushirish uchun — `Enter`; qidiruvdan, buyruqni ishga tushirmasdan chiqish uchun — `Esc` yoki `Ctrl+C`.

### `Tab` — avtomatik to'ldirish

`Tab` tugmasi, terminaldagi eng ko'p vaqt tejaydigan odatlardan biri. Buyruq yoki fayl nomining, boshlang'ich bir necha harfini yozib, `Tab` bosilsa:

- Agar, shu harflar bilan boshlanadigan, **faqat bitta** variant mavjud bo'lsa — u, avtomatik, to'liq yoziladi
- Agar, **bir nechta** variant mavjud bo'lsa — birinchi `Tab` bosilganda, hech narsa o'zgarmasligi mumkin (yoki, umumiy mos qism to'ldiriladi); ikkinchi marta `Tab` bosilsa, mavjud **barcha variantlar** ro'yxati ko'rsatiladi

Bu, nafaqat vaqtni tejaydi, balki, fayl yoki papka nomini **noto'g'ri yozish** xatosining oldini ham oladi.

### `tmux` — terminal multiplekseri

**`tmux`** (agar o'rnatilmagan bo'lsa: `sudo apt install tmux`) — bitta terminal oynasi ichida, bir nechta, mustaqil "sessiya"larni yaratish va boshqarish imkonini beruvchi vosita. Uning eng katta afzalligi — **sessiyalar, terminal oynasi yopilsa ham, yoki SSH ulanishi uzilib qolsa ham, orqa fonda ishlashda davom etadi**, va keyinroq, ularga qayta ulanish mumkin.

Asosiy buyruqlar:

| Buyruq | Vazifasi |
|---|---|
| `tmux new -s <nom>` | Yangi, nomlangan `tmux` sessiyasini yaratadi |
| `Ctrl+B`, so'ng `D` | Sessiyadan, uni **to'xtatmasdan**, ajraladi (detach) |
| `tmux attach -t <nom>` | Ajralgan sessiyaga, **qaytadan ulanadi** |
| `tmux ls` | Mavjud barcha sessiyalar ro'yxatini ko'rsatadi |

## Amaliy misol

Tarixni ko'ramiz:

```bash
history | tail -n 10
```

Endi, `Ctrl+R` bilan, avval yozgan `chmod` so'zi bor buyruqni qidiramiz — klaviaturada, `Ctrl+R` bosing, so'ng, `chmod` deb yozing:

```
(reverse-i-search)`chmod': chmod u+x ~/skriptlar/salom.sh
```

`Enter` bosib, uni qayta ishga tushiring, yoki `Esc` bosib, qidiruvdan, ishga tushirmasdan chiqing.

`Tab` bilan avtomatik to'ldirishni sinaymiz:

```bash
cd ~/skript
```

(bu yerda, `Tab` tugmasini bosing — agar, `~` ichida, faqat `skriptlar` nomli, shunga mos papka bo'lsa, u, avtomatik, `cd ~/skriptlar/` ga to'ldiriladi.)

`tmux`ni ishga tushiramiz:

```bash
tmux new -s ishim
```

Yangi `tmux` sessiyasi ochiladi (pastda, yashil chiziq, sessiya nomi bilan ko'rinadi). Uzoq davom etadigan buyruqni, sinov uchun ishga tushiramiz:

```bash
sleep 300
```

Endi, sessiyadan, uni to'xtatmasdan ajralamiz: `Ctrl+B` bosing, tugmani qo'yib yuboring, so'ng `D` bosing. Terminal, oddiy holatga qaytadi, ammo `sleep 300`, orqa fonda, `tmux` sessiyasi ichida, ishlashda davom etmoqda.

Mavjud sessiyalarni ko'ramiz:

```bash
tmux ls
```

Natija:

```
ishim: 1 windows (created ...)
```

Sessiyaga, qayta ulanamiz:

```bash
tmux attach -t ishim
```

Siz, xuddi hech qачон chiqmagandek, `sleep 300` buyrug'i ishlab turgan holatga, qaytib kelasiz.

## Keng tarqalgan xatolar

❌ **`tmux` sessiyasidan, `Ctrl+B` + `D` (ajralish) o'rniga, terminal oynasini, to'g'ridan-to'g'ri yopib qo'yish**, so'ng, ishlagan narsangiz "yo'qolgan" deb o'ylash.
✅ Sessiyadan chiqishdan oldin, doim, avval, `Ctrl+B`, so'ng `D` bilan **ajraling** — bu, sessiyani, orqa fonda ishlashda davom ettiradi, va unga, keyinroq, `tmux attach` bilan qaytish mumkin.

**Nega xato:** Aslida, terminal oynasini yopish, ko'p hollarda, `tmux` sessiyasining o'zini **to'xtatmaydi** (u, orqa fonda davom etadi), ammo, to'g'ri "ajralish" (`detach`) qilinmasa, foydalanuvchi, buni tushunmay, ishi yo'qolgan deb, keraksiz tashvishlanishi, yoki, ba'zi sozlamalarda, chindan ham sessiyani yo'qotib qo'yishi mumkin.

❌ **Bir nechta `tmux` sessiyasini yaratib, ularning nomlarini eslab qololmay, keyin, qaysi sessiyada, qaysi ish qilinayotganini adashtirib yuborish.**
✅ Har bir `tmux` sessiyasiga, `tmux new -s <aniq-va-tavsiflovchi-nom>` orqali, ma'noli nom bering (masalan, `backup-skript`, `server-loglar`), tasodifiy raqamlar emas.

**Nega xato:** Agar sessiyalarga nom berilmasa, `tmux`, ularга, avtomatik, `0`, `1`, `2` kabi, ma'nosiz raqamlar beradi — bir nechta sessiya bo'lganda, qaysi biri, aynan qaysi ishga tegishli ekanini eslab qolish, qiyinlashadi.

❌ **`Ctrl+R` orqali qidiruvda, kerakli buyruq topilgach, uni tahrirlamasdan, to'g'ridan-to'g'ri `Enter` bosib, eski (endi kerak bo'lmagan) argumentlar bilan qayta ishga tushirish.**
✅ `Ctrl+R` orqali, kerakli buyruq **shakli** topilgach, agar unga o'zgartirish kiritish kerak bo'lsa, `Enter` bosishdan oldin, o'ng yoki chap strelka tugmasini bosib, oddiy tahrirlash rejimiga o'ting, va kerakli qismini o'zgartiring.

**Nega xato:** `Ctrl+R`, faqat, mos keluvchi buyruqni **topadi va ko'rsatadi** — u, avtomatik ravishda, sizning joriy ehtiyojingizga moslab, argumentlarni o'zgartirmaydi; agar buyruq, boshqa fayl yoki qiymat bilan ishlatilishi kerak bo'lsa, buni, qo'lda tahrirlash zarur.

## Mashq/topshiriq

**(Oson)** `history | grep "chmod"` buyrug'i orqali, o'zingiz, shu paytgacha, nechta marta `chmod` buyrug'ini ishlatganingizni toping (bu — avvalgi bobda o'rgangan `grep` va `history`ni birlashtirish mashqi).

**(O'rtacha)** `tmux new -s mashq` bilan, yangi sessiya yarating, ichida, `htop` (yoki `top`) ni ishga tushiring, so'ng, `Ctrl+B` + `D` bilan ajraling, `tmux ls` bilan sessiya mavjudligini tasdiqlang, va `tmux attach -t mashq` bilan, qayta ulanib, `htop`ning hali ham ishlab turganini ko'ring (chiqish uchun, `htop` ichida `q`, so'ng, sessiyani tugatish uchun, `exit` yozing).

**(Qiyin)** `~/skriptlar` papkasida, `Tab` tugmasidan, kamida uch marta foydalanib (fayl nomini to'liq yozmasdan), avvalgi darslarda yaratilgan skriptlaringizdan birortasini, to'liq yo'l bilan ishga tushiring (masalan, `~/skr` yozib `Tab`, so'ng, fayl nomining boshlang'ich harflarini yozib, yana `Tab`).

## Qisqacha xulosa

`history` va, ayniqsa, `Ctrl+R` (teskari qidiruv), avval yozilgan buyruqlarni, tezda topib, qayta ishlatish imkonini beradi; `Tab` tugmasi, buyruq va fayl nomlarini, xato qilmasdan, avtomatik to'ldiradi; `tmux` esa — bitta terminal oynasida, bir nechta, mustaqil sessiyalarni boshqarish, va, eng muhimi, ularni, terminal yopilgandan yoki ulanish uzilgandan **keyin ham**, orqa fonda ishlashda davom ettirish imkonini beradi — bu uch vosita, terminaldagi kundalik ishni, sezilarli tezlashtiradi.
