# Kirish/chiqishni yo'naltirish

## Bu darsda nimalarni o'rganasiz

- Buyruq natijasini, ekran o'rniga, faylga yozasiz (`>`)
- Fayl mazmunini o'chirmasdan, uning oxiriga qo'shasiz (`>>`)
- Faylni, buyruqqa "kirish ma'lumoti" sifatida bera olasiz (`<`)
- `>` va `>>` orasidagi xavfli farqni tushunasiz

## Nazariy qism

### Har bir buyruqda uchta "kanal" bor

Terminaldagi har bir buyruq, standart holatda, uchta kanal bilan ishlaydi:

- **standart kirish (stdin)** — buyruq, ma'lumotni **qayerdan oladi** (odatda — klaviaturadan)
- **standart chiqish (stdout)** — buyruq, natijani **qayerga chiqaradi** (odatda — ekranga)
- **standart xato (stderr)** — buyruq, xato xabarlarini **qayerga chiqaradi** (odatda — bu ham ekranga, ammo alohida "kanal")

**Yo'naltirish (redirection)** — bu, shu kanallarning "odatiy" manzilini (ekran, klaviatura) **boshqasiga** (masalan, faylga) o'zgartirish imkonini beradi.

### `>` — natijani faylga yozish (ustidan yozib)

`buyruq > fayl` — buyruqning natijasini, ekranga chiqarish o'rniga, ko'rsatilgan faylga yozadi. **Muhim:** agar fayl allaqachon mavjud bo'lsa, uning **butun avvalgi mazmuni o'chiriladi**, va faqat yangi natija yoziladi. Agar fayl mavjud bo'lmasa, u yangi yaratiladi.

### `>>` — natijani faylga qo'shish

`buyruq >> fayl` — xuddi `>` kabi, ammo mavjud mazmunni o'chirmaydi, faqat **oxiriga qo'shadi**. Bu, masalan, jurnal (log) fayliga, vaqt o'tishi bilan yangi yozuvlar qo'shib borish uchun ishlatiladi.

### `<` — fayldan kirish ma'lumotini olish

`buyruq < fayl` — buyruqqa, klaviaturadan emas, ko'rsatilgan **fayldan** ma'lumot beradi. Bu, ayniqsa, klaviaturadan interaktiv ma'lumot kutadigan buyruqlarni, avtomatlashtirilgan skriptlarda ishlatishda foydali.

### Xato xabarlarini alohida yo'naltirish

Standart xato (stderr)ni ham alohida yo'naltirish mumkin: `buyruq 2> xatolar.txt` — bu, faqat xato xabarlarini faylga yozadi, oddiy natija esa ekranda qoladi. `2>&1` — xato xabarlarini ham, oddiy natija bilan **bir xil joyga** (masalan, bir faylga) yo'naltiradi.

## Amaliy misol

Buyruq natijasini, birinchi marta faylga yozamiz:

```bash
mkdir -p ~/sinov-yonaltirish
ls ~ > ~/sinov-yonaltirish/royxat.txt
cat ~/sinov-yonaltirish/royxat.txt
```

Endi, **xuddi shu** buyruqni yana ishga tushiramiz, ammo bu safar, faylga **qo'shamiz**:

```bash
date >> ~/sinov-yonaltirish/royxat.txt
cat ~/sinov-yonaltirish/royxat.txt
```

Natijada, faylda, avvalgi `ls` natijasi **va** yangi qo'shilgan sana — ikkalasi ham bor.

Endi, `>` bilan **ustidan yozib** yuborsak nima bo'lishini ko'ramiz:

```bash
echo "yangi mazmun" > ~/sinov-yonaltirish/royxat.txt
cat ~/sinov-yonaltirish/royxat.txt
```

Natija: faylda endi faqat "yangi mazmun" bor — avvalgi barcha ma'lumot **o'chib ketdi**.

`<` misoli — `wc -l` buyrug'iga, fayl nomini argument sifatida berish o'rniga, uni "kirish" sifatida beramiz:

```bash
wc -l < ~/sinov-yonaltirish/royxat.txt
```

Natija: `1` (fayl nomi ko'rsatilmaydi — chunki `wc`, bu holatda, faylni emas, faqat "kirish oqimini" ko'radi).

Xatolarni alohida yo'naltirish misoli:

```bash
ls /mavjud-bolmagan-papka 2> ~/sinov-yonaltirish/xatolar.txt
cat ~/sinov-yonaltirish/xatolar.txt
```

Natija:

```
ls: cannot access '/mavjud-bolmagan-papka': No such file or directory
```

## Keng tarqalgan xatolar

❌ **`>>` o'rniga `>` yozib, mavjud, muhim faylning mazmunini bilmasdan o'chirib yuborish** — bu, ayniqsa jurnal fayllariga yozayotganda, eng ko'p uchraydigan va og'ir oqibatli xato.
✅ Agar fayl mazmunini **saqlab qolib**, unga qo'shimcha kiritmoqchi bo'lsangiz, doim `>>` ishlating; faqat **ataylab, avvalgi mazmunni almashtirmoqchi** bo'lganingizda `>` ishlating.

**Nega xato:** `>` va `>>` — ko'rinishidan bir-biriga juda o'xshash (bitta belgi farq), ammo natijasi butunlay boshqacha: biri — **o'chirib qayta yozadi**, ikkinchisi — **qo'shadi**. Bu farqni bilmaslik, ma'lumot yo'qotishning tez-tez uchraydigan sababi.

❌ **Faylni, o'zining o'ziga yo'naltirishga urinish** (masalan, `sort fayl.txt > fayl.txt` — faylni saralab, natijani xuddi shu faylga yozmoqchi bo'lish).
✅ Avval natijani **boshqa** faylga yo'naltiring (`sort fayl.txt > vaqtinchalik.txt`), so'ng, kerak bo'lsa, `mv vaqtinchalik.txt fayl.txt` bilan asl nomga qaytaring.

**Nega xato:** `>`, faylni, buyruq **hali ishlashni boshlashidan oldin**, bo'shatib qo'yadi (chunki yo'naltirish, buyruq o'zi ishga tushishidan **oldin** tayyorlanadi) — natijada, `sort`, allaqachon **bo'sh** bo'lib qolgan fayldan o'qishga harakat qiladi, va natijada fayl butunlay bo'shab qoladi.

❌ **`>` belgisi bilan, ekranga chiqadigan **xato** xabarlarini ham faylga tushadi deb o'ylash.**
✅ Oddiy `>`, faqat **standart chiqishni** (stdout) yo'naltiradi; xato xabarlarini ham qo'shish uchun, alohida `2>&1` kerak: `buyruq > fayl.txt 2>&1`.

**Nega xato:** Standart chiqish (natija) va standart xato — ikkita **alohida** kanal; oddiy `>`, faqat birinchisini yo'naltiradi, ikkinchisi (xatolar) hali ham ekranga chiqishda davom etadi.

## Mashq/topshiriq

**(Oson)** `date` buyrug'ining natijasini, `~/sinov-yonaltirish/vaqt.txt` fayliga yozing, so'ng `cat` bilan tekshiring.

**(O'rtacha)** Yuqoridagi buyruqni, ketma-ket **uch marta**, ammo bu safar `>>` bilan, xuddi shu faylga qo'shib ishga tushiring. `cat` bilan, faylda uchta sana qatori borligini tasdiqlang.

**(Qiyin)** `ls -l ~/sinov-yonaltirish/ /mavjud-bolmagan-joy` buyrug'ini (ikkita yo'l — bittasi mavjud, ikkinchisi mavjud emas), natija va xatoni **alohida ikkita faylga** ajratib yo'naltiring (`natija.txt` va `xato.txt`), so'ng ikkala faylni ham `cat` bilan ko'rib, qaysi ma'lumot qaysi faylga tushganini tushunib oling.

1. `date > ~/sinov-yonaltirish/vaqt.txt`, so'ng `cat ~/sinov-yonaltirish/vaqt.txt`.
2. `date >> ~/sinov-yonaltirish/vaqt.txt` (birinchi marta, `>` bilan yozilgan natijadan keyin, buni uch marta ketma-ket ishga tushiring) — `cat` natijasida, uchta (yoki, agar 1-mashqdagi yozuv bilan birga — to'rtta) sana qatori ko'rinadi.
3. `ls -l ~/sinov-yonaltirish/ /mavjud-bolmagan-joy > ~/sinov-yonaltirish/natija.txt 2> ~/sinov-yonaltirish/xato.txt` — `natija.txt`da, mavjud papkaning ro'yxati, `xato.txt`da esa, "No such file or directory" xabari saqlanadi.

## Qisqacha xulosa

`>` — buyruq natijasini faylga yozadi, **mavjud mazmunni o'chirib**; `>>` — xuddi shunday, ammo mavjud mazmunni saqlab, **oxiriga qo'shadi**; `<` — faylni, buyruqqa "kirish ma'lumoti" sifatida beradi; va standart xato (`2>`)ni, standart natijadan **alohida** yo'naltirish mumkin — bu to'rtta vosita, terminaldagi ma'lumot oqimini, ekrandan fayllarga (va aksincha) boshqarishning asosini tashkil qiladi.
