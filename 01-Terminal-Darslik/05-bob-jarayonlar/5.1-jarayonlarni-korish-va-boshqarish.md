# Jarayonlarni ko'rish va boshqarish

## Bu darsda nimalarni o'rganasiz

- `ps` bilan, hozir ishlayotgan jarayonlar (process) ro'yxatini ko'rasiz
- `top`/`htop` bilan, tizim resurslarini real vaqtda kuzatasiz
- Jarayonni fonga (`&`) yuborasiz va `jobs`, `fg`, `bg` bilan boshqarasiz
- `kill` bilan, muammoli jarayonni to'xtatasiz

## Nazariy qism

### Jarayon (process) nima

Har safar, biror dastur ishga tushirilganda (terminaldan buyruq yozilganda ham, GUI orqali dastur ochilganda ham), tizimda, o'sha dastur uchun **jarayon (process)** yaratiladi. Har bir jarayon, o'ziga xos **PID** (Process ID — jarayon raqami) ga ega bo'ladi, va tizim, shu PID orqali, uni kuzatadi va boshqaradi.

### `ps` — jarayonlar ro'yxati (bir martalik "surat")

`ps` — hozirgi vaqtdagi jarayonlar haqida, **bir martalik** ma'lumot beradi (u, `top`dan farqli, doimiy yangilanib turmaydi). Eng ko'p ishlatiladigan shakli:

```bash
ps aux
```

Bu, tizimdagi **barcha** foydalanuvchilarning, **barcha** jarayonlarini, batafsil (foydalanuvchi, PID, protsessor va xotira sarfi, ishga tushirilgan vaqt, buyruq) ko'rsatadi.

### `top` va `htop` — real vaqtli monitoring

`top` — tizimdagi jarayonlarni, **doimiy yangilanib turadigan** (odatda har 1-3 soniyada) ko'rinishda ko'rsatadi, eng ko'p protsessor yoki xotira sarflayotgan jarayonlar yuqorida chiqadi. `htop` — `top`ning, rangli, sichqoncha bilan ham boshqarish mumkin bo'lgan, ancha qulayroq versiyasi (ba'zi tizimlarda, alohida o'rnatish talab qilinadi: `sudo apt install htop`). Ikkalasidan ham chiqish uchun — `q` tugmasi.

### Fon jarayonlari: `&`, `jobs`, `fg`, `bg`

Odatda, terminalga buyruq yozib `Enter` bossangiz, terminal, o'sha buyruq **tugagunicha**, boshqa buyruq qabul qilmaydi ("band" bo'lib qoladi). Agar buyruqni, terminalni bandlamasdan, **fonda** ishga tushirish kerak bo'lsa, buyruq oxiriga `&` belgisi qo'yiladi:

```bash
uzoq-ishlaydigan-buyruq &
```

- `jobs` — joriy terminal sessiyasida, fonda ishlayotgan (yoki to'xtatilgan) barcha jarayonlarni ro'yxatlaydi
- `fg` — fondagi (yoki to'xtatilgan) jarayonni, qayta **oldingi planga** (foreground) qaytaradi
- `bg` — to'xtatilgan (masalan, `Ctrl+Z` bilan) jarayonni, **fonda davom ettiradi**
- `Ctrl+Z` — joriy ishlayotgan jarayonni, **to'xtatadi** (o'chirmaydi, faqat "pauza" qiladi)

### `kill` — jarayonni to'xtatish

`kill <PID>` — ko'rsatilgan PID raqamiga ega jarayonga, uni **muloyimlik bilan** to'xtatishni so'raydigan signal yuboradi (bu, dasturga, o'z ishini yakunlab, tozalab chiqish imkonini beradi). Agar jarayon, bunga javob bermasa (masalan, "osilib qolgan" bo'lsa), **majburiy** to'xtatish uchun: `kill -9 <PID>` — bu, jarayonni, hech qanday "so'rovsiz", darhol tugatadi.

## Amaliy misol

Barcha jarayonlarni ko'ramiz (natija juda uzun bo'lishi mumkin, shuning uchun `less` bilan sahifalaymiz):

```bash
ps aux | less
```

(`q` bilan chiqing.)

`top`ni ishga tushiramiz:

```bash
top
```

Eng ko'p protsessor sarflayotgan jarayonlarni ko'rasiz. Chiqish uchun — `q`.

Endi, fon jarayoni bilan ishlaymiz — uzoq davom etadigan (10 soniyalik) buyruqni, fonda ishga tushiramiz:

```bash
sleep 30 &
```

Natija (misol):

```
[1] 12345
```

Bu, `[1]` — job raqami, `12345` — PID ekanini bildiradi. Terminal, darhol, keyingi buyruqni qabul qilishga tayyor.

Fondagi jarayonlarni ko'ramiz:

```bash
jobs
```

Natija:

```
[1]+  Running                 sleep 30 &
```

Endi, uni oldingi planga qaytaramiz:

```bash
fg
```

Terminal endi, `sleep 30` tugaguncha (qolgan vaqt davomida) band bo'ladi. Uni, tugashini kutmasdan, to'xtatib qo'yish uchun — `Ctrl+Z` bosing:

```
[1]+  Stopped                 sleep 30
```

Endi, uni yana fonda davom ettiramiz:

```bash
bg
jobs
```

Natija:

```
[1]+  Running                 sleep 30 &
```

Endi, uni majburan to'xtatamiz. Avval, PID raqamini topamiz:

```bash
jobs -l
```

Natija (misol): `[1]+ 12345 Running    sleep 30 &`

```bash
kill 12345
```

## Keng tarqalgan xatolar

❌ **`kill`ni, "o'chirish" (fayl o'chirish kabi) bilan adashtirish** — ba'zilar, `kill`, faylni yoki dasturni **butunlay o'chiradi** deb noto'g'ri tushunadi.
✅ `kill` — hech qanday faylni o'chirmaydi, u faqat, **hozir ishlayotgan jarayonni to'xtatadi**. Dastur (masalan, terminal buyrug'i), keyinroq, xohlagan vaqtingizda, qayta ishga tushirilishi mumkin.

**Nega xato:** "Kill" so'zi, o'chirish bilan bog'liq tuyulishi mumkin, ammo bu yerda u, faqat **ishlab turgan jarayonni to'xtatish** ma'nosida ishlatiladi — bu, kompyuterni o'chirib-yoqish kabi, vaqtinchalik amal.

❌ **Har doim, to'g'ridan-to'g'ri `kill -9` ishlatish, oddiy `kill`ni sinamasdan.**
✅ Avval, oddiy `kill <PID>` bilan sinab ko'ring — bu, dasturга, ma'lumotlarni saqlab, "toza" yakunlanish imkonini beradi. Faqat, agar bu ishlamasa (jarayon javob bermasa), `kill -9`ga o'ting.

**Nega xato:** `kill -9`, jarayonni **darhol, hech qanday tozalash imkoniyatisiz** to'xtatadi — agar jarayon, o'sha payt faylga yozayotgan bo'lsa, bu, ma'lumotning buzilishiga olib kelishi mumkin.

❌ **`&` bilan fonga yuborilgan jarayonni "unutib qo'yish"**, va terminal oynasini yopganda, u ham to'xtab qolishini kutmaslik.
✅ Agar fon jarayoni, terminal oynasi yopilgandan **keyin ham** ishlashda davom etishi kerak bo'lsa (masalan, uzoq davom etadigan skript), buning uchun maxsus vositalar (masalan, 11-bobda o'rganiladigan `tmux`, yoki `nohup` buyrug'i) kerak bo'ladi — oddiy `&`, bu holatni ta'minlamaydi.

**Nega xato:** Terminalda `&` bilan ishga tushirilgan oddiy jarayon, odatda, terminal sessiyasi yopilganda (masalan, SSH ulanishi uzilganda), u bilan birga **to'xtaydi**.

## Mashq/topshiriq

**(Oson)** `ps aux | wc -l` buyrug'i orqali, hozir tizimda nechta jarayon ishlayotganini sanang.

**(O'rtacha)** `sleep 60 &` bilan fon jarayonini ishga tushiring, `jobs -l` bilan uning PID raqamini toping, so'ng, uni tugashini kutmasdan, `kill` bilan to'xtating. `jobs`ni yana ishga tushirib, uning ro'yxatdan yo'qolganini tasdiqlang.

**(Qiyin)** Ikkita fon jarayonini ketma-ket ishga tushiring: `sleep 100 &` va `sleep 200 &`. `jobs -l` bilan ikkalasining ham PID raqamlarini toping. So'ng, `ps aux | grep sleep` orqali, ularni, `ps` chiqishida ham topib ko'ring (maslahat: `grep sleep` natijasida, `grep`ning o'zi ham, "sleep" so'zini o'z ichiga olgani uchun, natijada ko'rinishi mumkin — bu normal). Oxirida, ikkalasini ham, ularning PID raqamlari orqali, alohida-alohida `kill` bilan to'xtating.

## Qisqacha xulosa

`ps aux` — jarayonlarning bir martalik ro'yxatini, `top`/`htop` esa — real vaqtli, doimiy yangilanadigan ko'rinishini beradi; `&` bilan jarayonni fonga yuborish, `jobs`/`fg`/`bg` bilan uni boshqarish, va `Ctrl+Z` bilan vaqtincha to'xtatish — terminalni bir vaqtning o'zida bir nechta vazifa uchun ishlatish imkonini beradi; `kill` (va zarur bo'lsa `kill -9`) esa — muammoli yoki kerak bo'lmay qolgan jarayonni, PID raqami orqali to'xtatadi.
