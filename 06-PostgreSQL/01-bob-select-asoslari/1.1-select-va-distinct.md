# 1.1. `SELECT` va `SELECT DISTINCT`

## Bu darsda nimalarni o'rganasiz

- `SELECT` buyrug'i bilan jadvaldan ma'lumot o'qiy olasiz
- Aniq ustunlarni yoki barcha ustunlarni (`*`) tanlashni bilasiz
- Ustunlarga taxallus (alias, `AS`) berishni o'rganasiz
- `SELECT DISTINCT` bilan takrorlanuvchi qatorlarni olib tashlashni bilasiz
- Ushbu darslikda butun davomida ishlatiladigan namuna bazani o'z kompyuteringizda quramiz

## Nazariy qism

### Namuna bazani tayyorlash

0.1-darsda tanishtirilgan "do'kon" mavzusidagi baza bilan ishlashni boshlaymiz. Formal `CREATE TABLE` sintaksisini 6-bobda batafsil o'rganamiz, lekin hozircha amaliyot uchun quyidagi tayyor skriptni ishga tushiring — bu bizga so'rovlarni yozish uchun real ma'lumot beradi:

```sql
CREATE TABLE bolimlar (
    id SERIAL PRIMARY KEY,
    nomi VARCHAR(50) NOT NULL,
    joylashuv VARCHAR(50)
);

CREATE TABLE xodimlar (
    id SERIAL PRIMARY KEY,
    ism VARCHAR(50) NOT NULL,
    familiya VARCHAR(50) NOT NULL,
    email VARCHAR(100) UNIQUE,
    lavozim VARCHAR(50),
    bolim_id INTEGER REFERENCES bolimlar(id),
    boshliq_id INTEGER REFERENCES xodimlar(id),
    ish_haqi NUMERIC(10,2),
    ishga_kirgan_sana DATE
);

CREATE TABLE mahsulotlar (
    id SERIAL PRIMARY KEY,
    nomi VARCHAR(100) NOT NULL,
    narxi NUMERIC(10,2),
    kategoriya VARCHAR(50),
    ombordagi_soni INTEGER
);
```

> 📌 To'liq skript (barcha jadvallar — `mijozlar`, `buyurtmalar`, `buyurtma_elementlari` — va namuna ma'lumotlar bilan) darslikning oxirida, ilova sifatida keltiriladi va har bir bo'lim boshida kerakli jadvallarga ishora qilinadi. Hozircha yuqoridagi uchta jadval va ularga tegishli ma'lumotlar yetarli.

Bu darsda asosan **`xodimlar`** va **`mahsulotlar`** jadvallaridan foydalanamiz.

### `SELECT` — ma'lumot o'qishning asosiy buyrug'i

`SELECT` — SQL'dagi eng ko'p ishlatiladigan buyruq bo'lib, jadvaldan ma'lumot **o'qish** (lekin o'zgartirmaslik) uchun xizmat qiladi. Eng oddiy shakli:

```sql
SELECT ustun1, ustun2 FROM jadval_nomi;
```

```sql
SELECT ism, familiya, lavozim FROM xodimlar;
```

### Barcha ustunlarni tanlash — `*`

Agar jadvaldagi **barcha** ustunlar kerak bo'lsa, ularning har birini qo'lda sanash o'rniga yulduzcha (`*`) ishlatiladi:

```sql
SELECT * FROM mahsulotlar;
```

> ⚠️ **Amaliy tavsiya:** `SELECT *` — o'rganish va tezkor tekshirish uchun qulay, lekin **production** kodida (haqiqiy ilova ichida) undan ehtiyot bo'lish kerak: (1) kerak bo'lmagan ustunlarni ham o'qish tarmoq va xotira resursini isrof qiladi, (2) agar kelajakda jadvalga yangi ustun qo'shilsa, `SELECT *` ishlatuvchi kod kutilmagan tarzda yangi ma'lumot qaytara boshlaydi, bu esa xatoga olib kelishi mumkin. Shu sababli professional kodda odatda faqat kerakli ustunlar aniq sanaladi.

### Ustunlarga taxallus (alias) berish — `AS`

`AS` — ustun (yoki jadval) nomiga vaqtinchalik, o'qilishi osonroq nom berish uchun ishlatiladi. Bu ayniqsa hisoblangan ustunlarda (keyingi darslarda ko'ramiz) yoki natijani boshqa dasturga tushunarliroq formatda uzatishda foydali:

```sql
SELECT ism AS "Ismi", familiya AS "Familiyasi", ish_haqi AS "Oylik maosh"
FROM xodimlar;
```

`AS` kalit so'zi ixtiyoriy — `ism AS "Ismi"` o'rniga shunchaki `ism "Ismi"` deb yozish ham ishlaydi, lekin aniqlik uchun `AS` yozish tavsiya etiladi. Agar taxallus bo'sh joy yoki katta harf talab qilsa (masalan `"Oylik maosh"`), uni qo'shtirnoq ichiga olish **shart** — aks holda PostgreSQL uni kichik harflarga, bo'sh joysiz alohida so'zlar sifatida talqin qilishga urinadi va xato beradi.

### Hisoblangan ifodalar `SELECT` ichida

`SELECT`ning ustun ro'yxatida shunchaki mavjud ustun nomlari emas, balki istalgan **ifoda** (arifmetik amal, funksiya chaqiruvi va h.k.) ham bo'lishi mumkin:

```sql
SELECT ism, familiya, ish_haqi, ish_haqi * 12 AS "Yillik maosh"
FROM xodimlar;
```

Bu — `ish_haqi` ustunidagi qiymatni 12ga ko'paytirib, natijani `"Yillik maosh"` nomli yangi, "virtual" ustun sifatida ko'rsatadi — bu ustun jadvalning o'zida saqlanmaydi, faqat so'rov natijasida hisoblanadi.

### `SELECT DISTINCT` — takrorlanishlarni olib tashlash

Ba'zan bizni bir ustundagi (yoki bir nechta ustun kombinatsiyasidagi) **noyob (unique)** qiymatlar qiziqtiradi, takrorlanuvchi qatorlar emas. `DISTINCT` kalit so'zi aynan shuni qiladi:

```sql
SELECT kategoriya FROM mahsulotlar;
```

```
   kategoriya    
-----------------
 Elektronika
 Elektronika
 Elektronika
 Elektronika
 Mebel
 Mebel
 Maishiy texnika
 Maishiy texnika
 Mebel
 Elektronika
(10 rows)
```

```sql
SELECT DISTINCT kategoriya FROM mahsulotlar;
```

```
   kategoriya    
-----------------
 Mebel
 Maishiy texnika
 Elektronika
(3 rows)
```

`DISTINCT` bir nechta ustun bilan ishlatilganda, **butun qator kombinatsiyasi** noyob bo'lishi tekshiriladi (faqat bitta ustun emas):

```sql
SELECT DISTINCT bolim_id, lavozim FROM xodimlar;
```

Bu — `bolim_id` va `lavozim`ning **birgalikdagi** noyob juftliklarini qaytaradi (masalan, agar ikkita "Sotuv menejeri" bir xil bo'limda bo'lsa, ular bitta qatorga birlashadi, lekin turli bo'limdagi bir xil lavozim alohida qatorlarda qoladi).

### `DISTINCT ON` — PostgreSQL'ning maxsus kengaytmasi

PostgreSQL, standart SQL'dan tashqari, `DISTINCT ON (ustun)` degan maxsus konstruksiyani ham taqdim etadi — bu har bir noyob qiymat guruhi uchun **birinchi** qatorni (odatda `ORDER BY` bilan birga ishlatilib, "eng qimmat", "eng yangi" kabi mantiq bilan) tanlab olish imkonini beradi:

```sql
SELECT DISTINCT ON (kategoriya) kategoriya, nomi, narxi
FROM mahsulotlar
ORDER BY kategoriya, narxi DESC;
```

Natija — har bir kategoriyadagi **eng qimmat** mahsulot:

```
   kategoriya    |          nomi          |   narxi    
-----------------+------------------------+------------
 Elektronika     | Noutbuk Lenovo IdeaPad | 8500000.00
 Maishiy texnika | Muzlatgich             | 6800000.00
 Mebel           | Ish stoli              | 2500000.00
(3 rows)
```

Bu — ko'plab boshqa DBMS'larda (MySQL, SQL Server) faqat murakkab subquery yoki window function bilan yechiladigan masalani PostgreSQL'da bir qatorda hal qiladigan, juda qulay, PostgreSQL'ga xos vosita. `DISTINCT ON` ishlatilganda, `ORDER BY`ning **birinchi** ustuni albatta `DISTINCT ON` ichidagi ustun bilan bir xil bo'lishi shart — bu PostgreSQL'ning qat'iy talabi.

## Amaliy misol

Do'konning barcha mahsulot kategoriyalarini va har bir kategoriyada nechta mahsulot borligini emas (buni 4-bobda `GROUP BY` bilan ko'ramiz), hozircha faqat kategoriyalar ro'yxatini va narxi 1,000,000 so'mdan qimmat mahsulotlarning nomini chiroyli ko'rinishda chiqaramiz:

```sql
SELECT DISTINCT kategoriya AS "Mavjud kategoriyalar"
FROM mahsulotlar
ORDER BY kategoriya;
```

```
 Mavjud kategoriyalar
-----------------------
 Elektronika
 Maishiy texnika
 Mebel
(3 rows)
```

(`ORDER BY` — keyingi darsimiz mavzusi, bu yerda natijani alifbo tartibida ko'rish uchun oldindan ishlatildi.)

## Keng tarqalgan xatolar

**Xato 1:** `SELECT *`ni har doim, hatto faqat 1-2 ta ustun kerak bo'lganda ham ishlatish.
❌ `SELECT * FROM xodimlar;` — agar sizga faqat `ism` va `ish_haqi` kerak bo'lsa, bu keraksiz ma'lumot (email, lavozim, sana va h.k.) ham qaytaradi.
✅ To'g'ri: faqat kerakli ustunlarni aniq sanang: `SELECT ism, ish_haqi FROM xodimlar;`.

**Xato 2:** `DISTINCT`ni bir nechta ustun bilan ishlatib, uning **butun qator** bo'yicha ishlashini tushunmaslik.
❌ `SELECT DISTINCT bolim_id, lavozim FROM xodimlar;` natijasida kutilganidan ko'proq qator chiqishi — chunki bu faqat `bolim_id` yoki faqat `lavozim`ni emas, ikkalasining **kombinatsiyasini** noyob qiladi.
✅ To'g'ri: agar faqat bitta ustunning noyob qiymatlari kerak bo'lsa, faqat o'sha bitta ustunni tanlang: `SELECT DISTINCT lavozim FROM xodimlar;`.

**Xato 3:** Taxallusda bo'sh joy bo'lsa, qo'shtirnoqni unutish.
❌ `SELECT ish_haqi AS Oylik maosh FROM xodimlar;` — bu `syntax error` beradi, chunki PostgreSQL `Oylik`ni taxallus, `maosh`ni esa noma'lum qo'shimcha token deb tushunadi.
✅ To'g'ri: bo'sh joyli taxalluslarni albatta qo'shtirnoq ichiga oling: `AS "Oylik maosh"`.

## Mashq/topshiriq

**(Oson)** `mahsulotlar` jadvalidan faqat `nomi` va `narxi` ustunlarini, `"Mahsulot"` va `"Narxi (so'm)"` taxalluslar bilan chiqaring.

**(O'rtacha)** `xodimlar` jadvalidan barcha noyob (`DISTINCT`) lavozimlar ro'yxatini chiqaring, alifbo tartibida (`ORDER BY` ishlatib).

**(Qiyin)** `DISTINCT ON` yordamida har bir bo'lim (`bolim_id`) bo'yicha eng katta maoshli xodimning ismi, familiyasi va maoshini chiqaring (`ORDER BY bolim_id, ish_haqi DESC` bilan).

## Qisqacha xulosa

`SELECT` — SQL'dagi ma'lumot o'qishning asosiy buyrug'i bo'lib, aniq ustunlarni yoki `*` bilan barchasini tanlash, `AS` bilan taxallus berish va hisoblangan ifodalarni ko'rsatish imkonini beradi; `DISTINCT` esa takrorlanuvchi qatorlarni olib tashlaydi (bir nechta ustun bilan ishlatilganda — butun qator kombinatsiyasi bo'yicha), `DISTINCT ON` esa PostgreSQL'ga xos, har bir guruh bo'yicha "birinchi" qatorni tanlovchi qulay kengaytma. Keyingi darsda natijalarni **tartiblash** — `ORDER BY` buyrug'ini chuqur o'rganamiz.
