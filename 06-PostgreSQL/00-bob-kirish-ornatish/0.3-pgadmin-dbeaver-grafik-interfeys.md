# 0.3. pgAdmin, DBeaver va grafik interfeys vositalari

## Bu darsda nimalarni o'rganasiz

- pgAdmin va DBeaver'ning nima uchun kerakligini va ular orasidagi farqni tushunasiz
- pgAdmin'ni o'rnatib, unda yangi server ulanishini sozlay olasiz
- DBeaver'da ham xuddi shunday ulanish yaratishni bilasiz
- Qachon `psql`, qachon grafik vositadan foydalanish maqsadga muvofiqligini tushunasiz

## Nazariy qism

### Nega grafik interfeys kerak

0.2-darsda ko'rgan `psql` — kuchli, tez va har qanday serverda (hatto masofaviy SSH orqali) ishlaydigan vosita, lekin uning kamchiliklari ham bor: katta natijalarni ko'rish, jadval strukturasini vizual tekshirish, yoki bir nechta bazani parallel boshqarish terminalda noqulay bo'lishi mumkin. **Grafik interfeys** (GUI) vositalari bu muammoni hal qiladi — ular jadvallarni jadval ko'rinishida ko'rsatadi, sxemani vizual daraxt sifatida ko'rsatadi, va so'rov natijalarini eksport qilish, tahrirlash kabi qulayliklar beradi.

Ikkita eng mashhur PostgreSQL GUI vositasi:

- **pgAdmin** — PostgreSQL loyihasining rasmiy, PostgreSQL uchun **maxsus** yaratilgan grafik vositasi. Veb-brauzer orqali ishlaydigan interfeysga ega (hatto ish stoli versiyasi ham ichida veb-texnologiyalarni ishlatadi).
- **DBeaver** — universal ma'lumotlar bazasi vositasi, faqat PostgreSQL emas, balki MySQL, Oracle, SQL Server, SQLite va o'nlab boshqa DBMS bilan ham ishlaydi. Bir nechta turli ma'lumotlar bazasi bilan ishlaydigan dasturchilar uchun qulay.

| Xususiyat | pgAdmin | DBeaver |
|---|---|---|
| Maxsuslashuv | Faqat PostgreSQL (va hosilalari) | Universal — ko'plab DBMS |
| Interfeys | Veb-asosidagi (brauzerda yoki desktop app ichida) | Ish stoli dasturi (Java asosida) |
| PostgreSQL'ga xos funksiyalar | Juda chuqur (masalan, server konfiguratsiyasi, replikatsiya monitoring) | Yaxshi, lekin umumiyroq |
| Litsenziya | Bepul (PostgreSQL litsenziyasi) | Community Edition — bepul, Enterprise — pullik |
| Kimlarga mos | Faqat PostgreSQL bilan ishlaydiganlar | Turli DBMS bilan ishlaydiganlar |

## Amaliy misol

### pgAdmin o'rnatish (Ubuntu)

```bash
# Rasmiy pgAdmin repozitoriyasini qo'shish
curl -fsSL https://www.pgadmin.org/static/packages_pgadmin_org.pub | sudo gpg --dearmor -o /usr/share/keyrings/packages-pgadmin-org.gpg

sudo sh -c 'echo "deb [signed-by=/usr/share/keyrings/packages-pgadmin-org.gpg] https://ftp.postgresql.org/pub/pgadmin/pgadmin4/apt/$(lsb_release -cs) pgadmin4 main" > /etc/apt/sources.list.d/pgadmin4.list'

sudo apt update
sudo apt install -y pgadmin4-desktop     # ish stoli versiyasi
```

pgAdmin ishga tushirilgandan so'ng, birinchi marta master-parol so'raladi (bu — pgAdmin ilovasining o'zini himoya qiluvchi parol, PostgreSQL parolidan farqli).

### pgAdmin'da yangi server ulanishi yaratish

1. Chap tomondagi "Servers" daraxtida o'ng tugma bosing → **Register → Server...**
2. **General** yorlig'ida: `Name` maydoniga ixtiyoriy nom kiriting (masalan "Mening lokal serverim").
3. **Connection** yorlig'ida:
   - `Host name/address`: `localhost` (yoki `127.0.0.1`)
   - `Port`: `5432`
   - `Maintenance database`: `postgres`
   - `Username`: `postgres`
   - `Password`: o'rnatishda belgilagan parolingiz
4. **Save** tugmasini bosing.

Ulangandan so'ng, chap tomondagi daraxtda **Databases → dokon_bazasi → Schemas → public → Tables** yo'li orqali jadvallaringizga vizual kirish mumkin bo'ladi. So'rov yozish uchun yuqoridagi **Query Tool** (yashin belgisi) tugmasidan foydalaniladi — bu yerga oddiy SQL yozib, `F5` yoki "Bajarish" tugmasi orqali ishga tushirish mumkin.

### DBeaver o'rnatish (Ubuntu, Snap orqali)

```bash
sudo snap install dbeaver-ce
```

### DBeaver'da yangi ulanish yaratish

1. Yuqori chap burchakdagi **"New Database Connection"** tugmasini bosing (yoki `Database → New Database Connection`).
2. Ro'yxatdan **PostgreSQL**ni tanlang.
3. Ulanish parametrlarini kiriting: `Host: localhost`, `Port: 5432`, `Database: dokon_bazasi`, `Username: postgres`, `Password: ...`.
4. **Test Connection** tugmasi orqali ulanish to'g'riligini tekshiring, so'ng **Finish**.

DBeaver'da SQL yozish uchun jadval yoki bazaga o'ng tugma bosib **SQL Editor → New SQL Script** tanlanadi.

## Keng tarqalgan xatolar

**Xato 1:** pgAdmin/DBeaver'da ulanish yaratishda `Host name`ga `localhost` o'rniga bazaning nomini yozish.
❌ `Host name: dokon_bazasi` — bu xato, chunki `Host` — serverning **manzili** (kompyuter/server nomi), baza nomi esa alohida (`Maintenance database` yoki `Database` maydonida) ko'rsatiladi.
✅ To'g'ri: `Host` — har doim `localhost` (yoki server IP manzili/domeni), baza nomi — alohida maydonda.

**Xato 2:** Docker konteynerida ishlayotgan PostgreSQL'ga GUI orqali ulanishga urinishda, konteyner portini kompyuterga bog'lamaganlik sababli ulanish muvaffaqiyatsiz bo'lishi.
❌ `docker run` buyrug'ida `-p 5432:5432` ko'rsatilmagan bo'lsa, pgAdmin/DBeaver "Connection refused" xatosini beradi.
✅ To'g'ri: 0.2-darsda ko'rganimizdek, konteynerni portlarni tashqariga ochib ishga tushiring, yoki GUI vositasini ham Docker tarmog'ining ichiga ulang (murakkabroq usul).

**Xato 3:** Grafik vositada so'rovni bajarib, natija chiqmagach, "dastur ishlamayapti" deb o'ylash — aslida so'rov hali **saqlanmagan/bajarilmagan**.
❌ Query Tool'ga SQL yozib, lekin "Execute" (bajarish) tugmasini yoki `F5`ni bosishni unutish.
✅ To'g'ri: har doim so'rovni yozgandan keyin uni aniq bajarish buyrug'i (tugma yoki klaviatura yorlig'i) bilan ishga tushiring — bu barcha GUI vositalarida psql'dan farqli o'laroq **avtomatik** emas.

## Mashq/topshiriq

**(Oson)** pgAdmin yoki DBeaver'dan birini o'rnating (xohishingizga ko'ra) va 0.2-darsda yaratgan `dokon_bazasi`ga ulaning.

**(O'rtacha)** Grafik vosita orqali (Query Tool yoki SQL Editor yordamida) `SELECT * FROM sinov;` so'rovini bajarib, natijani jadval ko'rinishida ko'ring — uni `psql`dagi natija bilan solishtiring.

**(Qiyin)** Ikkalasini ham (pgAdmin va DBeaver) o'rnatib, bir xil bazaga ikkalasidan ham ulaning va ularning interfeysidagi kamida uchta amaliy farqni (masalan, jadval sxemasini ko'rish, so'rov natijasini eksport qilish, ER-diagramma yaratish) yozib chiqing.

## Qisqacha xulosa

pgAdmin — PostgreSQL uchun rasmiy, chuqur ixtisoslashgan grafik vosita, DBeaver esa turli ma'lumotlar bazalari bilan ishlashga mo'ljallangan universal vosita — ikkalasi ham jadvallarni vizual ko'rish, so'rov yozish va natijalarni qulay tahlil qilish imkonini beradi. Amaliyotda ko'p dasturchi kundalik, tez ishlarni `psql` orqali (tezligi va skriptlashtirish imkoniyati uchun), murakkabroq, vizual tahlil talab qiladigan ishlarni esa GUI vositasi orqali bajaradi — ikkalasini ham bilish foydali. Bu bilan 00-bob (Kirish) yakunlanadi — keyingi bobdan boshlab, SQL'ning o'zi bilan — `SELECT` buyrug'idan — chuqur tanishishni boshlaymiz.
