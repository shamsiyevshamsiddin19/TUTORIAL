# Papkalar orasida yurish

## Bu darsda nimalarni o'rganasiz

- `pwd` bilan, joriy qaysi papkada turganingizni aniqlaysiz
- `cd` bilan, papkalar orasida erkin harakatlanasiz
- Absolyut va nisbiy yo'l (path) tushunchalarini farqlaysiz
- `~`, `.`, `..` kabi maxsus belgilardan foydalanasiz

## Nazariy qism

### Fayl tizimi — daraxt tuzilmasi

Linux'da barcha fayl va papkalar, bitta umumiy "ildiz"dan (`/` — root) boshlanadigan **daraxt** shaklida joylashgan. Masalan, sizning uy papkangiz (`/home/shamsiddin`), aslida — `/` ildizining ichidagi `home` papkasi ichidagi `shamsiddin` papkasi. Har doim, siz shu daraxtning **bitta tugunida** (papkasida) turasiz — bu, "joriy papka" (current directory) deb ataladi.

### `pwd` — men qayerdaman

`pwd` (Print Working Directory) — joriy turgan papkangizning **to'liq yo'lini** ekranga chiqaradi. Bu, ayniqsa uzoq ishlaganda yoki bir nechta terminal oynasi ochiq bo'lganda, "hozir men qayerdaman" degan savolga tezda javob beradi.

### `cd` — joyni almashtirish

`cd <papka-nomi>` — sizni, ko'rsatilgan papkaga "olib boradi" (joriy papkani o'zgartiradi). Bu buyruq, papkani ochib ko'rmaydi, faylni ko'rsatmaydi — u faqat, siz **qayerda turganingizni** o'zgartiradi.

### Absolyut va nisbiy yo'l — muhim farq

Yo'l (path) ikki xil ko'rinishda yozilishi mumkin:

- **Absolyut yo'l** — `/` belgisidan boshlanadi, va fayl tizimining **ildizidan** boshlab, to'liq manzilni ko'rsatadi. Masalan: `/home/shamsiddin/Documents`. Bu yo'l, siz qayerda turishingizdan qat'i nazar, **doim bir xil joyga** olib boradi.
- **Nisbiy yo'l** — `/` bilan boshlanmaydi, va **joriy turgan joyingizga nisbatan** hisoblanadi. Masalan, agar siz `/home/shamsiddin`da tursangiz, `Documents` deb yozish — `/home/shamsiddin/Documents`ga borish bilan bir xil. Ammo, agar siz boshqa papkada tursangiz, xuddi shu `Documents` so'zi, butunlay boshqa joyga ishora qilishi mumkin (yoki umuman mavjud bo'lmasligi mumkin).

### Maxsus belgilar: `~`, `.`, `..`

| Belgi | Ma'nosi |
|---|---|
| `~` | Joriy foydalanuvchining **uy papkasi** (masalan, `/home/shamsiddin`) |
| `.` | **Joriy papkaning o'zi** |
| `..` | Joriy papkaning **bitta yuqori (ota) papkasi** |
| `-` | (faqat `cd` bilan) **Oldingi turgan papka** |

Bu belgilar, uzun absolyut yo'llarni har safar to'liq yozishdan qutqaradi. Masalan, qayerda tursangiz ham, `cd ~` — sizni doim uy papkangizga qaytaradi.

## Amaliy misol

```bash
pwd
```

Natija (misol):

```
/home/shamsiddin
```

Endi, `Documents` papkasiga (agar mavjud bo'lsa) nisbiy yo'l orqali kiramiz:

```bash
cd Documents
pwd
```

Natija:

```
/home/shamsiddin/Documents
```

Bir papka yuqoriga qaytamiz:

```bash
cd ..
pwd
```

Natija:

```
/home/shamsiddin
```

Endi, absolyut yo'l orqali, tizim jurnallari saqlanadigan `/var/log` papkasiga o'tamiz (bu — uy papkangizdan butunlay boshqa "shoxda" joylashgan):

```bash
cd /var/log
pwd
```

Natija:

```
/var/log
```

Uy papkasiga bir zumda qaytamiz:

```bash
cd ~
pwd
```

Natija:

```
/home/shamsiddin
```

Oldingi turgan joyга (`/var/log`ga) qaytish uchun:

```bash
cd -
```

Natija: `/var/log` (va yana `pwd` chaqirsangiz, shuni ko'rasiz).

## Keng tarqalgan xatolar

❌ **`cd` buyrug'idan keyin, mavjud bo'lmagan papka nomini yozish** (masalan, katta-kichik harfda xato: `cd documents` o'rniga `Documents` kerak bo'lganda).
✅ Xato chiqsa (`No such file or directory`), avval joriy papkadagi fayllarni ko'rib (keyingi darsda o'rganiladigan `ls` bilan), aniq nomni tekshiring.

**Nega xato:** Linux, katta-kichik harflarga sezgir — `documents` va `Documents` ikkita **butunlay boshqa** nom hisoblanadi, hatto ular bir xil ko'rinsa ham.

❌ **Nisbiy va absolyut yo'lni aralashtirib yuborish** — masalan, `/Documents` deb yozish (`/` bilan boshlab), aslida `~/Documents`ni nazarda tutgan holda.
✅ Agar uy papkangizdagi biror joyga o'tmoqchi bo'lsangiz, yo `~/Documents` deb (aniq), yoki hech qanday `/` qo'ymasdan `Documents` deb (agar allaqachon uy papkasida bo'lsangiz) yozing.

**Nega xato:** `/Documents` — bu, fayl tizimining **eng tepasidagi** (`/`) `Documents` papkasini anglatadi, bu esa odatda mavjud emas — shuning uchun "No such file or directory" xatosi chiqadi.

❌ **`cd`dan keyin papka nomida probel bo'lsa, tirnoqsiz yozish** (masalan, `cd My Documents`).
✅ Probelli nomlarni tirnoq ichiga oling: `cd "My Documents"`.

**Nega xato:** Shell, probelni, argumentlarni **ajratuvchi** belgi sifatida tushunadi — tirnoqsiz yozilsa, u `My` va `Documents`ni ikkita alohida argument deb qabul qiladi, va `cd` ikkinchi argumentni tushunmay xato beradi.

## Mashq/topshiriq

**(Oson)** `pwd` bilan joriy joyingizni aniqlang, so'ng `cd /tmp` bilan vaqtinchalik fayllar papkasiga o'ting va yana `pwd` bilan tekshiring.

**(O'rtacha)** `/tmp`dan turib, bitta buyruq bilan (ketma-ket ikkita `cd` ishlatmasdan) to'g'ridan-to'g'ri o'z uy papkangizning `Documents` ichidagi (agar mavjud bo'lmasa, `Desktop` ichidagi) joyiga o'ting.

**(Qiyin)** `/var/log`ga o'ting, so'ng, faqat `..` va bitta papka nomidan foydalanib (absolyut yo'l ishlatmasdan), `/var/spool`ga o'ting (ya'ni, avval yuqoriga, keyin `spool`ga tushish kerak). Amalni bajargach, `cd -` bilan `/var/log`ga qaytib, keyin yana `cd -` bilan `/var/spool`ga qaytib kelishni sinab ko'ring.

<details>
<summary>Javoblarni ko'rish</summary>

1. `cd /tmp` — `pwd` natijasi `/tmp` bo'ladi.
2. `cd ~/Documents` (yoki `cd ~/Desktop`) — `~` belgisi, qayerda turganingizdan qat'i nazar, to'g'ridan-to'g'ri uy papkasiga ishora qiladi.
3. `/var/log`da turib: `cd ../spool` — bu, avval bir papka yuqoriga (`/var`ga), so'ng `spool` ichiga tushadi, natijada `/var/spool`da bo'lasiz. `cd -` — har safar, oldingi turgan joyingiz bilan almashtiradi (bu, ikki joy orasida "tez-tez o'tib turish" uchun juda qulay).

</details>

## Qisqacha xulosa

Fayl tizimi — `/` ildizidan boshlanadigan daraxt bo'lib, `pwd` sizga "hozir qayerdaligingizni", `cd` esa "qayerga borishni" ko'rsatadi; yo'lni yozishda **absolyut** (`/`dan boshlanadigan, doim bir xil joyga olib boradigan) va **nisbiy** (joriy joyга bog'liq) yo'l orasidagi farqni, hamda `~`, `.`, `..`, `-` kabi qisqartmalarni yaxshi bilish — terminaldagi navigatsiyani sezilarli tezlashtiradi.
