# Terminalni moslashtirish

## Bu darsda nimalarni o'rganasiz

- Terminal promptini (`PS1`), o'zingizga qulay va informativ qilib o'zgartirasiz
- `zsh` va `oh-my-zsh` nima ekanini, va ular, `bash`ga nisbatan qanday qo'shimcha qulayliklar berishini tushunasiz
- O'z terminal muhitingizni, kelajakda ham, izchil ravishda rivojlantirish yo'nalishini bilib olasiz

## Nazariy qism

### `PS1` — promptni boshqaruvchi o'zgaruvchi

0.1-darsda ko'rgan **prompt** (`shamsiddin@laptop:~$`), aslida, `PS1` nomli, oddiy muhit o'zgaruvchisi orqali belgilanadi (6.1-darsda o'rgangan `export` mantig'iga to'liq mos keladi). Uni, o'zgartirish orqali, promptni, o'zingizga kerakli ma'lumot (masalan, joriy vaqt, git branch nomi) bilan boyitish mumkin.

`PS1` ichida, maxsus belgilar (`\u` — foydalanuvchi nomi, `\h` — kompyuter nomi, `\w` — joriy papka, `\t` — vaqt) ishlatiladi:

```bash
export PS1='\u@\h:\w\$ '
```

Bu — standart promptga juda o'xshash, ammo, uni, xohlagancha o'zgartirish mumkin, masalan, ranglar qo'shib yoki qisqartirib.

### `zsh` va `oh-my-zsh` — `bash`ning kuchliroq muqobili

**`zsh`** (Z Shell) — `bash`ga o'xshash, ammo, ba'zi qo'shimcha, qulay xususiyatlarga ega shell: ancha "aqlliroq" avtomatik to'ldirish, o'rnatilgan imlo tuzatish (masalan, `cd Documnets` yozilsa, `cd Documents`ni taklif qilishi), va boy moslashtirish imkoniyatlari.

**`oh-my-zsh`** — `zsh` uchun, tayyor sozlamalar, mavzular (theme) va plaginlar to'plamini, oson o'rnatish imkonini beruvchi loyiha. U, o'rnatilgandan so'ng, promptni, avtomatik ravishda, ancha informativ va chiroyli qilib beradi (masalan, joriy Git papkada bo'lsangiz, branch nomini, avtomatik ko'rsatadi).

`zsh` va `oh-my-zsh`ni sinash (ixtiyoriy, chuqurroq mavzu, bu yerda faqat yo'nalish sifatida ko'rsatiladi):

```bash
sudo apt install zsh
sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
```

**Muhim eslatma:** internetdan olingan o'rnatish skriptini (yuqoridagi kabi), ishga tushirishdan oldin, 8.3-darsda o'rganilganidek, uning manbasiga ishonch hosil qilish kerak — bu, `oh-my-zsh`ning, keng tanilgan, rasmiy manbasi.

### Terminal emulyatorni moslashtirish

`bash`/`zsh` sozlamalaridan tashqari, terminal **dasturining o'zi** (masalan, GNOME Terminal, Konsole) ham, odatda, o'z sozlamalar menyusiga ega — u yerda, shrift o'lchami, rang sxemasi (masalan, qorong'i mavzu) va oyna shaffofligini o'zgartirish mumkin. Bu sozlamalar, terminal dasturidan-dasturga farq qiladi, shuning uchun, aniq yo'l-yo'riq, ishlatilayotgan terminal dasturiga bog'liq — odatda, sozlamalar (Preferences/Settings) menyusidan topiladi.

## Amaliy misol

Joriy `PS1`ni ko'ramiz:

```bash
echo $PS1
```

Yangi, joriy vaqtni ham ko'rsatuvchi promptni, vaqtincha (faqat shu sessiya uchun) sinaymiz:

```bash
export PS1='[\t] \u@\h:\w\$ '
```

Endi, prompt, quyidagiga o'xshash ko'rinishga ega bo'ladi:

```
[15:42:07] shamsiddin@laptop:~$
```

Agar bu, sizga yoqsa, uni, **doimiy** qilish uchun, 6.2-darsda o'rgangan usulda, `.bashrc` fayliga qo'shamiz:

```bash
nano ~/.bashrc
```

Faylning oxiriga:

```bash
# Mening moslashtirilgan promptim
export PS1='[\t] \u@\h:\w\$ '
```

Saqlab (`Ctrl+O`, `Enter`), chiqamiz (`Ctrl+X`), va, o'zgarishni darhol qo'llaymiz:

```bash
source ~/.bashrc
```

Endi, promptingiz, terminal qayta ochilganda ham, doimiy ravishda, vaqtni ko'rsatib turadi.

## Keng tarqalgan xatolar

❌ **`PS1`ni, `.bashrc`ga qo'shishdan oldin, terminalda, to'g'ridan-to'g'ri sinamasdan, murakkab, uzun ifodani yozib qo'yish**, va natijada, prompt, buzilgan yoki tushunarsiz ko'rinishga ega bo'lib qolishi.
✅ Har doim, avval, yangi `PS1`ni, terminalda, `export PS1='...'` orqali, **vaqtincha** sinab ko'ring, va, faqat, natija sizga yoqqandan so'ng, uni `.bashrc`ga qo'shing.

**Nega xato:** `PS1` sintaksisi (masalan, maxsus belgilar, qochish ketma-ketliklari), ba'zan, nozik va xato qilish oson — agar, sinovsiz, to'g'ridan-to'g'ri `.bashrc`ga yozilsa, va xato bo'lsa, bu, **har safar** terminal ochilganda, muammoli promptga olib kelishi mumkin.

❌ **Internetdan topilgan, o'rnatish skriptini (masalan, `oh-my-zsh` o'rnatish buyrug'i), uning manbasini tekshirmasdan, to'g'ridan-to'g'ri ishga tushirish.**
✅ Bunday skriptlarni ishga tushirishdan oldin, ular, keng tanilgan, ishonchli, rasmiy manbadan (masalan, loyihaning rasmiy GitHub sahifasidan) ekanligiga ishonch hosil qiling.

**Nega xato:** `curl ... | sh` shaklidagi buyruqlar, internetdan olingan skriptni, **to'g'ridan-to'g'ri, ko'rmasdan** ishga tushiradi — bu, 8.3-darsda ko'rilgan, "ishonchsiz manbadan yuklab olingan faylni tekshirmasdan ishga tushirish" xatosining, alohida, keng tarqalgan ko'rinishi.

❌ **Terminalni, juda ko'p, ortiqcha ma'lumot (masalan, uzun yo'l, ko'p rang, ortiqcha belgilar) bilan "to'ldirib" moslashtirish**, natijada, prompt, o'qish qiyin bo'lib qolishi.
✅ Promptga, faqat, haqiqatan **kerakli** ma'lumotni qo'shing — maqsad, terminaldan foydalanishni **osonlashtirish**, murakkablashtirish emas.

**Nega xato:** Juda uzun yoki ranglarga to'la prompt, ekranda, ko'p joy egallaydi, va, ayniqsa, kichik terminal oynasida, haqiqiy buyruqlarni yozish uchun joyni kamaytiradi — moslashtirish, foydalilikka xizmat qilishi, shunchaki bezak bo'lib qolmasligi kerak.

## Mashq/topshiriq

**(Oson)** `echo $PS1` bilan, joriy promptingizning "xom" ko'rinishini ko'ring, va undagi, `\u`, `\h`, `\w` kabi, kamida ikkita belgini aniqlang.

**(O'rtacha)** `PS1`ni, faqat joriy papka nomini (to'liq yo'lsiz) va `$` belgisini ko'rsatadigan, juda qisqa ko'rinishga o'zgartiring (maslahat: `\W`, katta harf bilan — faqat, **oxirgi** papka nomini ko'rsatadi, `\w`dan farqli, u — to'liq yo'lni ko'rsatadi).

**(Qiyin)** `.bashrc`ga, o'zingiz tanlagan, informativ `PS1`ni (masalan, vaqt va foydalanuvchi nomi bilan) qo'shing, `source` bilan sinab ko'ring, va, agar tizimingizda imkon bo'lsa, `zsh` va `oh-my-zsh`ni (yuqoridagi rasmiy manba orqali) o'rnatib, standart `bash` prompti bilan, `oh-my-zsh` prompti orasidagi farqni solishtiring.

## Qisqacha xulosa

Terminal prompti, `PS1` nomli oddiy muhit o'zgaruvchisi orqali boshqariladi, va uni, maxsus belgilar (`\u`, `\h`, `\w`, `\t`) yordamida, o'zingizga kerakli ma'lumot bilan moslashtirish, va `.bashrc`ga qo'shib, doimiy qilish mumkin; `zsh` va `oh-my-zsh` esa, `bash`ga qaraganda, ancha boy, tayyor moslashtirish imkoniyatlarini beradi — ammo, har qanday moslashtirishda, avval sinab ko'rish, va ishonchsiz manbadagi skriptlarni ehtiyot bilan ishlatish, muhim odat bo'lib qoladi.
