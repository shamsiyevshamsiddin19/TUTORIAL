# Arxivlash va siqish

## Bu darsda nimalarni o'rganasiz

- `tar` bilan, bir nechta faylni, bitta arxiv fayliga birlashtirasiz va uni ochasiz
- `tar`ni, `gzip` siqishi bilan birga (`tar.gz`), hajmi kichikroq arxiv yaratish uchun ishlatasiz
- `zip`/`unzip` bilan, keng tarqalgan `.zip` formatida arxivlaysiz

## Nazariy qism

### `tar` — Linux dunyosining standart arxivchisi

**`tar`** (Tape Archive — nomi, eski, lentaga yozib saqlash davridan qolgan), bir nechta faylni, bitta faylga **birlashtiradi** ("tarball" deb ataladi). E'tibor bering: `tar`, standart holatda, hajmni **siqmaydi** — u, faqat, fayllarni bitta faylga "yig'adi". Siqish, alohida, qo'shimcha bayroq orqali qo'shiladi.

### `tar`ning eng muhim bayroqlari

| Bayroq | Vazifasi |
|---|---|
| `-c` | Yangi arxiv **yaratish** (create) |
| `-x` | Arxivni **ochish** (extract) |
| `-v` | Jarayonni, batafsil (verbose) ko'rsatish |
| `-f <nom>` | Arxiv **fayl nomini** ko'rsatish (deyarli har doim kerak) |
| `-z` | `gzip` bilan **siqish/ochish** (arxiv yaratishda yoki ochishda qo'shiladi) |

Bayroqlar, odatda, birlashtirilib yoziladi. Eng ko'p ishlatiladigan ikkita buyruq:

```bash
tar -czvf arxiv-nomi.tar.gz papka-nomi/    # yaratish (siqib)
tar -xzvf arxiv-nomi.tar.gz                # ochish
```

Bu yerda, harflarning ma'nosi: `c` (create/yarat) yoki `x` (extract/och), `z` (gzip siqish), `v` (batafsil ko'rsatish), `f` (fayl nomi — undan keyin, albatta, arxiv nomi yoziladi).

### `zip`/`unzip` — universal, boshqa tizimlar bilan ham mos format

`.tar.gz` — Linux dunyosida standart bo'lsa-da, `.zip` formati, **barcha operatsion tizimlarda** (Windows, macOS, Linux) tanish va qo'llab-quvvatlanadi. Agar arxivni, boshqa tizim foydalanuvchisiga yuborish kerak bo'lsa, `.zip` — ko'pincha, xavfsizroq tanlov.

```bash
zip -r arxiv-nomi.zip papka-nomi/    # yaratish
unzip arxiv-nomi.zip                 # ochish
```

`-r` bayrog'i, `zip` uchun ham, papka ichidagi barcha fayllarni, ichma-ich qo'shish uchun kerak (`cp -r` mantig'iga o'xshash).

## Amaliy misol

Avval, arxivlash uchun, kichik papka tayyorlaymiz:

```bash
mkdir -p ~/sinov-arxiv/hujjatlar
echo "Birinchi hujjat" > ~/sinov-arxiv/hujjatlar/birinchi.txt
echo "Ikkinchi hujjat" > ~/sinov-arxiv/hujjatlar/ikkinchi.txt
```

`tar.gz` arxivini yaratamiz:

```bash
cd ~/sinov-arxiv
tar -czvf hujjatlar.tar.gz hujjatlar/
```

Natija (batafsil rejimda):

```
hujjatlar/
hujjatlar/birinchi.txt
hujjatlar/ikkinchi.txt
```

Yaratilgan arxiv hajmini ko'ramiz:

```bash
ls -lh ~/sinov-arxiv
```

Sinov uchun, asl papkani o'chiramiz (arxivdan qayta tiklashni tekshirish uchun):

```bash
rm -r ~/sinov-arxiv/hujjatlar
ls ~/sinov-arxiv
```

Endi, `hujjatlar` papkasi yo'q, faqat `hujjatlar.tar.gz` bor. Arxivdan, qayta tiklaymiz:

```bash
tar -xzvf hujjatlar.tar.gz
ls ~/sinov-arxiv/hujjatlar
```

Natijada, `hujjatlar` papkasi va ichidagi fayllar, arxivdan, to'liq qayta tiklanadi.

Endi, `zip` bilan ham sinaymiz:

```bash
zip -r hujjatlar.zip hujjatlar/
ls -lh ~/sinov-arxiv
```

`.tar.gz` va `.zip` hajmlarini, `ls -lh` orqali solishtirib ko'rish mumkin.

`.zip` arxivini ochamiz (avval, sinov uchun, papkani yana o'chirib):

```bash
rm -r ~/sinov-arxiv/hujjatlar
unzip hujjatlar.zip
ls ~/sinov-arxiv/hujjatlar
```

## Keng tarqalgan xatolar

❌ **`tar`da, `-f` bayrog'idan keyin, arxiv nomini yozishni unutish yoki noto'g'ri tartibda yozish** (masalan, `tar -czv hujjatlar.tar.gz hujjatlar/` — `f` bayrog'isiz).
✅ `-f` bayrog'ini, doim, boshqa bayroqlar bilan birga, va undan **darhol keyin**, arxiv nomini yozing: `tar -czvf hujjatlar.tar.gz hujjatlar/`.

**Nega xato:** `-f` bayrog'isiz, `tar`, arxiv nomi o'rniga, standart kirish/chiqish oqimini (yoki, ba'zi tizimlarda, eski "lenta qurilmasi"ni) ishlatishga harakat qiladi — bu, kutilmagan xatolarga yoki natijalarga olib keladi.

❌ **`tar -czvf` va `tar -xzvf`dagi `c` (create) va `x` (extract) harflarini chalkashtirib, mavjud arxivni, "yaratish" rejimida ochib, uni bilmasdan **qayta yozib yuborish**.**
✅ Arxiv **yaratishda** — `c`, arxivni **ochishda** — `x`. Ularni, har safar, ongli ravishda tanlang.

**Nega xato:** `c` (create), agar shu nomli arxiv **allaqachon mavjud** bo'lsa, uning ustidan, **yangi, bo'sh** arxivni yozib yuboradi — bu, avvalgi arxiv mazmunini, butunlay yo'qotadi.

❌ **`zip -r`da, `-r` bayrog'ini unutib, faqat, papkaning bo'sh "nomini" arxivlashga urinish** (fayl mazmunisiz).
✅ Papkani, ichidagi hamma narsasi bilan arxivlashda, doim `-r` bayrog'ini qo'shing: `zip -r arxiv.zip papka/`.

**Nega xato:** `-r`siz, `zip`, papka ichiga "kirmaydi" — natijada, arxivda, faqat, bo'sh papka yozuvi qoladi, ichidagi fayllar, arxivga umuman kiritilmaydi.

## Mashq/topshiriq

**(Oson)** `~/skriptlar` papkasini (avvalgi darslardan qolgan, skriptlar bilan), `tar -czvf` yordamida, `skriptlar-zaxira.tar.gz` nomli arxivga joylang.

**(O'rtacha)** Yaratilgan `skriptlar-zaxira.tar.gz` arxivini, `~/sinov-arxiv/tiklangan` (avval `mkdir -p` bilan yarating) papkasiga, ochib chiqing (maslahat: `tar -xzvf` buyrug'iga, `-C <papka>` bayrog'ini qo'shish, arxivni, joriy papka o'rniga, ko'rsatilgan boshqa papkaga ochish imkonini beradi: `tar -xzvf skriptlar-zaxira.tar.gz -C ~/sinov-arxiv/tiklangan`).

**(Qiyin)** `~/sinov-arxiv/hujjatlar` papkasini, **ikkala** formatda (`.tar.gz` va `.zip`) arxivlang, `ls -lh` bilan, ikkala arxivning hajmini solishtiring, va, qaysi biri kichikroq ekanini aniqlang (odatda, `.tar.gz`, matn fayllar uchun, biroz samaraliroq siqish beradi — ammo, natija, fayl turiga qarab farq qilishi mumkin).

## Qisqacha xulosa

`tar` — bir nechta faylni, bitta arxivga birlashtiradi, va `-z` bayrog'i bilan, `gzip` siqishini ham qo'shadi (`tar -czvf` — yaratish, `tar -xzvf` — ochish); `zip`/`unzip` esa, kamroq Linux-ga xos, ammo barcha operatsion tizimlarda tanish bo'lgan, universal format — ikkalasida ham, papkani, ichidagi hamma narsasi bilan arxivlashda, tegishli `-r` (yoki `tar`da, mantiqan shunga mos, papka nomining o'zi) qo'llanilishiga e'tibor berish muhim.
