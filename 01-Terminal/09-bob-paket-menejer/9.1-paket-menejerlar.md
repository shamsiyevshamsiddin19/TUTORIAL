# Paket menejerlar

## Bu darsda nimalarni o'rganasiz

- Paket menejer (package manager) nima ekanini va u nega dasturni saytdan qo'lda yuklab olishdan afzal ekanini tushunasiz
- `apt` bilan, dastur qidirasiz, o'rnatasiz, yangilaysiz va o'chirasiz
- Tizimning **barcha** paketlarini, bitta buyruqda yangilashni o'rganasiz

## Nazariy qism

### Paket menejer nima va nega u kerak

**Paket menejer** — dasturlarni (va ularning ishlashi uchun zarur bo'lgan boshqa kichik dasturlarni — "bog'liqliklar"/dependencies) qidirish, o'rnatish, yangilash va o'chirishni, **markazlashgan va avtomatlashtirilgan** tarzda boshqaruvchi tizim.

Nega bu, dastur saytidan, qo'lda yuklab olishdan yaxshiroq? Sabablar: paket menejer, dastur uchun zarur bo'lgan, **barcha boshqa kichik dasturlarni ham, avtomatik** o'rnatadi (aks holda, ularni, birma-bir, qo'lda topib o'rnatish kerak bo'lardi); barcha o'rnatilgan dasturlarni, **bitta buyruq bilan**, yangilash mumkin; dasturlar, rasmiy tekshiruvdan o'tgan, ishonchli manbadan (repository — "ombор") olinadi.

### `apt` — Debian/Ubuntu oilasidagi paket menejer

Ubuntu, Debian va ularga asoslangan boshqa distributivlarda (bu — eng keng tarqalgan Linux oilalaridan biri), standart paket menejer — **`apt`** hisoblanadi.

### `apt`ning eng ko'p ishlatiladigan buyruqlari

| Buyruq | Vazifasi |
|---|---|
| `sudo apt update` | Mavjud paketlar **ro'yxatini** yangilaydi (dasturlarning o'zini emas — faqat, "qanday yangi versiyalar bor" degan ma'lumotni) |
| `sudo apt upgrade` | O'rnatilgan **barcha** paketlarni, eng so'nggi versiyaga yangilaydi |
| `sudo apt install <nom>` | Ko'rsatilgan dasturni o'rnatadi |
| `sudo apt remove <nom>` | Ko'rsatilgan dasturni o'chiradi (sozlama fayllari qoladi) |
| `sudo apt purge <nom>` | Dasturni, sozlama fayllari bilan birga, **to'liq** o'chiradi |
| `apt search <so'z>` | Berilgan so'z bo'yicha, mavjud paketlarni qidiradi |
| `apt show <nom>` | Paket haqida, batafsil ma'lumot (tavsif, versiya, hajm) ko'rsatadi |

### `update` va `upgrade` orasidagi farq — muhim tushuncha

Bu ikkisi, ko'pincha chalkashtiriladi:

- `apt update` — faqat, mavjud paketlar haqidagi **ro'yxatni/katalogni** yangilaydi (internetdan, "nima yangilangan" degan ma'lumotni oladi) — bu, hech qanday dasturni, haqiqatan o'zgartirmaydi
- `apt upgrade` — `update` orqali olingan ma'lumotga asoslanib, **haqiqatan**, o'rnatilgan dasturlarning o'zini, yangi versiyaga yangilaydi

Shuning uchun, ular, deyarli har doim, ketma-ket, birga ishlatiladi: avval `update`, so'ng `upgrade`.

## Amaliy misol

Avval, paketlar ro'yxatini yangilaymiz:

```bash
sudo apt update
```

Natija (misol, qisqartirilgan):

```
Hit:1 http://archive.ubuntu.com/ubuntu jammy InRelease
Get:2 http://archive.ubuntu.com/ubuntu jammy-updates InRelease [119 kB]
...
Reading package lists... Done
```

Sinov uchun, `tree` nomli, papka tuzilmasini vizual ko'rsatuvchi kichik dasturni qidiramiz:

```bash
apt search tree
```

Natijada, `tree` va unga bog'liq boshqa paketlar ro'yxati chiqadi. Uni, batafsil ko'ramiz:

```bash
apt show tree
```

Endi, uni o'rnatamiz:

```bash
sudo apt install tree
```

Tizim, o'rnatish uchun kerakli hajmni ko'rsatadi, va tasdiqlashni so'raydi (`Do you want to continue? [Y/n]`) — `Y` yoki `Enter` bosing.

O'rnatilganini tekshiramiz:

```bash
tree ~/skriptlar
```

Bu, `~/skriptlar` papkasining, ichma-ich tuzilmasini, vizual (daraxt shaklida) ko'rsatadi.

Barcha o'rnatilgan dasturlarni yangilaymiz:

```bash
sudo apt upgrade
```

Agar, biror yangilanish mavjud bo'lsa, tizim, ularning ro'yxatini ko'rsatib, tasdiqlashni so'raydi.

Endi, `tree` dasturini, endi kerak bo'lmagani uchun, o'chiramiz:

```bash
sudo apt remove tree
```

## Keng tarqalgan xatolar

❌ **`apt update`ni, `apt upgrade` bilan bir xil narsa deb hisoblab, faqat `update`ni ishga tushirib, "dasturlarim yangilandi" deb o'ylash.**
✅ Dasturlarning o'zini haqiqatan yangilash uchun, **ikkalasini ham**, ketma-ket ishlating: `sudo apt update && sudo apt upgrade` (bu yerda, `&&` — 7.4-darsda o'rgangan, birinchi buyruq muvaffaqiyatli bo'lsagina, ikkinchisini bajarish belgisi).

**Nega xato:** `update` — faqat, "nima yangi bor" degan **ma'lumotni** yangilaydi, hech qanday dasturni o'zgartirmaydi; `upgrade` esa — aynan **haqiqiy o'zgarishni** amalga oshiradi. Faqat `update` bilan cheklanish — dasturlarni eski holatda qoldiradi.

❌ **`sudo`ni unutib, `apt install`ni, oddiy foydalanuvchi huquqida ishga tushirishga urinish.**
✅ Dastur o'rnatish, o'chirish yoki yangilash — tizim darajasidagi amal, shuning uchun, doim `sudo` bilan ishlating.

**Nega xato:** Dastur o'rnatish, tizimning umumiy papkalariga (masalan, `/usr/bin`) yozishni talab qiladi — bu papkalar, 3.1-darsda o'rganilganidek, faqat, `root` (yoki `sudo` orqali) ruxsatga ega.

❌ **`apt remove` bilan `apt purge`ni farqlamaslik**, va dastur "to'liq o'chirilgan" deb o'ylab, aslida, sozlama fayllari, tizimda qolib ketishi.
✅ Agar dasturni, sozlama fayllari bilan birga, **to'liq** o'chirmoqchi bo'lsangiz, `remove` o'rniga, `purge` ishlating: `sudo apt purge <nom>`.

**Nega xato:** `apt remove`, ataylab, dasturning **sozlama fayllarini** o'chirmaydi — bu, agar siz, kelajakda, o'sha dasturni qayta o'rnatsangiz, avvalgi sozlamalaringiz saqlanib qolishi uchun qilingan, foydali xususiyat, ammo, "to'liq tozalash" kerak bo'lgan holatlarda, buni bilish muhim.

## Mashq/topshiriq

**(Oson)** `sudo apt update` buyrug'ini ishga tushiring, va natijada, nechta paket manbai (repository) tekshirilganini kuzating.

**(O'rtacha)** `apt search` yordamida, "editor" (matn muharriri) so'zi bo'yicha qidiruv qiling, va natijada chiqqan paketlar ro'yxatidan, kamida uchtasining nomini yozib qo'ying.

**(Qiyin)** `htop` dasturini (5-bobda tilga olingan, jarayonlarni real vaqtli kuzatish vositasi), `apt` orqali o'rnating, uni ishga tushirib sinab ko'ring (`q` bilan chiqing), so'ng, uni, `purge` orqali, sozlamalari bilan birga, to'liq o'chiring.

## Qisqacha xulosa

Paket menejer (`apt`, Ubuntu/Debian oilasida), dasturlarni, ularning barcha bog'liqliklari bilan birga, markazlashgan, ishonchli manbadan, avtomatik o'rnatish, yangilash va o'chirish imkonini beradi; `sudo apt update` — paketlar ro'yxatini yangilaydi (hech narsani o'zgartirmaydi), `sudo apt upgrade` — haqiqiy yangilanishni amalga oshiradi, `install`/`remove`/`purge` esa — dasturni mos ravishda o'rnatadi, o'chiradi (sozlamalarsiz) yoki to'liq tozalab o'chiradi.
