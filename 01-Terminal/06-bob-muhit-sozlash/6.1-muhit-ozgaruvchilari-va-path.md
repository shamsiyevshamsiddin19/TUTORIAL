# Muhit o'zgaruvchilari va PATH

## Bu darsda nimalarni o'rganasiz

- Muhit o'zgaruvchisi (environment variable) nima ekanini tushunasiz
- `echo $VAR` bilan, mavjud o'zgaruvchining qiymatini ko'rasiz
- `export` bilan, yangi muhit o'zgaruvchisi yaratasiz
- `PATH` o'zgaruvchisi nima ekanini va "buyruq topilmadi" xatosi bilan qanday bog'liqligini tushunasiz

## Nazariy qism

### Muhit o'zgaruvchisi nima

**Muhit o'zgaruvchisi (environment variable)** — bu, nomi va qiymatidan iborat, terminal sessiyasi davomida "xotirada" saqlanadigan ma'lumot bo'lib, uni, ishga tushirilgan **har qanday dastur** o'qiy oladi. Masalan, `HOME` o'zgaruvchisi — sizning uy papkangiz yo'lini saqlaydi; `USER` — foydalanuvchi nomingizni; `LANG` — tizim tili sozlamasini.

O'zgaruvchining qiymatini ko'rish uchun, uning nomi oldiga `$` belgisi qo'yiladi, va `echo` bilan chiqariladi:

```bash
echo $HOME
```

### `export` — yangi o'zgaruvchi yaratish

O'z muhit o'zgaruvchingizni yaratish uchun, `export` buyrug'i ishlatiladi:

```bash
export MENING_OZGARUVCHIM="qiymat"
```

Shundan so'ng, `echo $MENING_OZGARUVCHIM` — `qiymat`ni chiqaradi, va bu o'zgaruvchi, shu terminal sessiyasidan ishga tushirilgan **boshqa dasturlar** uchun ham ko'rinadi.

**Muhim eslatma:** `export` orqali yaratilgan o'zgaruvchi, faqat **joriy terminal sessiyasi** davomida amal qiladi — terminal oynasini yopsangiz, u yo'qoladi. Doimiy saqlash uchun, uni, profil faylga (`.bashrc` — keyingi darsda ko'riladi) yozish kerak.

### `PATH` — buyruqlar qayerda izlanadi

`PATH` — eng muhim muhit o'zgaruvchilardan biri. U, ikki nuqta (`:`) bilan ajratilgan, papkalar ro'yxatini saqlaydi:

```bash
echo $PATH
```

Natija (misol):

```
/usr/local/bin:/usr/bin:/bin:/usr/local/sbin
```

Siz terminalga, masalan, `ls` deb yozganingizda, tizim, `ls` nomli ijro etiladigan faylni, aynan shu **`PATH`da ko'rsatilgan papkalarning har birida, tartib bilan** qidiradi. Birinchi topilgan joyda to'xtaydi, va o'sha faylni ishga tushiradi. Agar biror buyruq, `PATH`dagi **hech qaysi papkada** topilmasa — mashhur "command not found" (buyruq topilmadi) xatosi chiqadi.

### O'z dasturingizni PATH'ga qo'shish

Agar siz, o'zingiz yozgan skriptni, uning to'liq yo'lini yozmasdan (masalan, `~/skriptlarim/mening-skriptim.sh` o'rniga, faqat `mening-skriptim.sh` deb) ishga tushirmoqchi bo'lsangiz, o'sha skript joylashgan papkani, `PATH`ga qo'shishingiz kerak:

```bash
export PATH="$PATH:/uy/papkam/skriptlarim"
```

E'tibor bering: `$PATH` — **mavjud** qiymatni saqlab qoladi, va unga, yangi papka, `:` orqali qo'shiladi — agar `$PATH` yozilmasa, **eski barcha papkalar yo'qolib**, faqat yangisi qoladi, va bu, `ls` kabi asosiy buyruqlarning ham ishlamay qolishiga olib kelishi mumkin.

## Amaliy misol

Mavjud o'zgaruvchilarni ko'ramiz:

```bash
echo $HOME
echo $USER
echo $PATH
```

Yangi, o'zimizning o'zgaruvchimizni yaratamiz:

```bash
export MEVA="olma"
echo $MEVA
```

Natija: `olma`

`PATH`ga, sinov uchun, mavjud bo'lmagan (yoki mavjud) yangi papka qo'shamiz:

```bash
mkdir -p ~/mening-skriptlarim
echo $PATH
export PATH="$PATH:$HOME/mening-skriptlarim"
echo $PATH
```

Endi, `$PATH` natijasida, oxirida, `mening-skriptlarim` papkasi ham qo'shilganini ko'rasiz.

Endi, o'sha papkada, sodda skript yaratamiz:

```bash
echo 'echo "Bu, PATHga qoshilgan skriptdan salom!"' > ~/mening-skriptlarim/salom-skript.sh
chmod u+x ~/mening-skriptlarim/salom-skript.sh
```

Uni, to'liq yo'lni yozmasdan, faqat nomi bilan ishga tushiramiz:

```bash
salom-skript.sh
```

Natija: `Bu, PATHga qoshilgan skriptdan salom!` — chunki tizim, endi, `salom-skript.sh` nomli faylni, `PATH`dagi papkalarning birida (aynan siz qo'shgan papkada) topdi.

## Keng tarqalgan xatolar

❌ **`PATH`ni o'zgartirganda, `$PATH`ni (eski qiymatni) unutib qoldirish** (masalan, `export PATH="/uy/papkam"` — to'liq almashtirib yuborish).
✅ Har doim, yangi papka qo'shayotganda, eski qiymatni saqlab qoling: `export PATH="$PATH:/uy/papkam"`.

**Nega xato:** Bu xato, `PATH`dagi **barcha** avvalgi papkalarni (jumladan, `ls`, `cd`, `grep` kabi asosiy buyruqlar joylashgan `/usr/bin`, `/bin`) yo'qotib yuboradi — natijada, o'sha terminal sessiyasida, deyarli **hech qanday** oddiy buyruq ishlamay qoladi.

❌ **O'zgaruvchi qiymatini o'qishda, `$` belgisini yozishni unutish** (masalan, `echo HOME` — `$HOME` o'rniga).
✅ O'zgaruvchining **qiymatini** o'qish uchun, doim `$` belgisini oldiga qo'ying: `echo $HOME`.

**Nega xato:** `$`siz, `HOME` — shell uchun, oddiy, **so'zma-so'z matn** hisoblanadi (o'zgaruvchi emas), shuning uchun `echo HOME`, "HOME" so'zining o'zini chiqaradi, uning qiymatini emas.

❌ **`export`ni, faylga yozmasdan, terminalning **shu sessiyasida** ishlatib, keyingi safar terminalni ochganda, o'zgaruvchi yo'qolganiga hayron bo'lish.**
✅ Agar o'zgaruvchi **doimiy** (har safar terminal ochilganda) mavjud bo'lishi kerak bo'lsa, uni, `.bashrc` fayliga (keyingi darsda batafsil o'rganiladi) yozib qo'ying.

**Nega xato:** `export`, faqat **joriy sessiya** uchun amal qiladi — terminalning yangi oynasi, xotirasiz, "toza holatda" boshlanadi, va unda, avvalgi sessiyada `export` qilingan o'zgaruvchilar mavjud bo'lmaydi.

## Mashq/topshiriq

**(Oson)** `echo $SHELL` buyrug'ini ishga tushiring va natijada nima chiqishini ko'ring — bu, sizning joriy shell dasturingiz (masalan, `/bin/bash`) yo'lini ko'rsatadi.

**(O'rtacha)** `KURS` nomli, qiymati "Terminal darsligi" bo'lgan yangi muhit o'zgaruvchisini `export` bilan yarating, va uni `echo` bilan tekshiring.

**(Qiyin)** `which ls` buyrug'i orqali, `ls` buyrug'ining, `PATH`dagi qaysi papkada joylashganini toping. So'ng, `echo $PATH` natijasida, o'sha papka nomi haqiqatan mavjudligini, ko'z bilan tekshiring (`:` bilan ajratilgan ro'yxat ichidan qidiring).

<details>
<summary>Javoblarni ko'rish</summary>

1. `echo $SHELL` — odatda `/bin/bash` yoki `/usr/bin/bash` natijasini beradi.
2. `export KURS="Terminal darsligi"`, so'ng `echo $KURS` — natija: `Terminal darsligi`.
3. `which ls` — odatda `/usr/bin/ls` yoki `/bin/ls` natijasini beradi. `echo $PATH` natijasida, `:` bilan ajratilgan ro'yxatda, `/usr/bin` (yoki `/bin`) papkasi mavjudligini ko'rish mumkin — bu, tizimning, `ls` buyrug'ini, aynan shu ro'yxatdagi papkalarni tekshirib topganini tasdiqlaydi.

</details>

## Qisqacha xulosa

Muhit o'zgaruvchilari — dastur ishlashi davomida foydalaniladigan, nom-qiymat juftliklari bo'lib, `$NOM` orqali o'qiladi va `export NOM=qiymat` orqali yaratiladi (faqat joriy sessiya uchun); `PATH` — eng muhim o'zgaruvchilardan biri bo'lib, tizim, buyruq yozilganda, aynan shu ro'yxatdagi papkalarni, tartib bilan qidiradi — va bu ro'yxatni o'zgartirishda, doimo `$PATH`ning eski qiymatini saqlab qolish (`export PATH="$PATH:yangi-papka"`), tizimning ishlashda davom etishi uchun hal qiluvchi ahamiyatga ega.
