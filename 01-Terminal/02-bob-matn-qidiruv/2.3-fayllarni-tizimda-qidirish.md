# Fayllarni tizimda qidirish

## Bu darsda nimalarni o'rganasiz

- `find` bilan, fayl tizimida, nomi bo'yicha faylni qidirasiz
- `find`ni tur (fayl/papka), hajm va o'zgartirilgan sana bo'yicha filtrlaysiz
- `which` bilan, ishlatilayotgan buyruqning aynan qayerda joylashganini topasiz

## Nazariy qism

### `find` — nomi bo'yicha qidiruv

`grep` (avvalgi darsda ko'rilgan) — fayl **ichidagi matnni** qidiradi. `find` esa — butunlay boshqa vazifani bajaradi: u, fayl tizimida, **fayl yoki papkaning o'zini**, uning nomi, turi, hajmi yoki sanasiga qarab qidiradi.

Eng oddiy shakli:

```bash
find <qidiriladigan-papka> -name "<nom-shabloni>"
```

Masalan, `find ~ -name "*.pdf"` — uy papkasi ichida (va uning barcha ichki papkalarida), nomi `.pdf` bilan tugaydigan barcha fayllarni topadi. `*` belgisi — "istalgan belgilar" degan ma'noni bildiradi (bu, "wildcard" deb ataladi).

### `find`ning foydali filtrlari

| Filtr | Vazifasi |
|---|---|
| `-name "shablon"` | Nomi bo'yicha qidiradi (katta-kichik harfga sezgir) |
| `-iname "shablon"` | Nomi bo'yicha, katta-kichik harfga **sezgir bo'lmagan** holda qidiradi |
| `-type f` | Faqat **fayllarni** qidiradi (papkalarni emas) |
| `-type d` | Faqat **papkalarni** qidiradi |
| `-size +10M` | 10 megabaytdan **katta** fayllarni qidiradi |
| `-mtime -7` | Oxirgi **7 kun** ichida o'zgartirilgan fayllarni qidiradi |

Filtrlarni birlashtirish mumkin: `find ~ -type f -iname "*.jpg" -size +5M` — uy papkasidagi, 5 MB dan katta, barcha JPG fayllarni (katta-kichik harfga qaramay) topadi.

### `which` — buyruq qayerda joylashgan

Har bir terminal buyrug'i (masalan, `ls`, `grep`, `python3`) — aslida, tizimning biror joyida joylashgan, **ijro etiladigan fayl**. `which <buyruq>` — o'sha buyruq, chaqirilganda, aynan **qaysi fayl** ishga tushishini ko'rsatadi. Bu, ayniqsa bitta dasturning bir nechta versiyasi o'rnatilgan bo'lsa ("nega mening `python3`im eski versiyani ishga tushiryapti"), yoki buyruq umuman o'rnatilganmi-yo'qmi ekanini tekshirishda foydali.

## Amaliy misol

Avval, qidirish uchun bir nechta fayl tayyorlaymiz:

```bash
mkdir -p ~/sinov-qidiruv/papka1 ~/sinov-qidiruv/papka2
touch ~/sinov-qidiruv/hisobot.txt
touch ~/sinov-qidiruv/papka1/rasm.jpg
touch ~/sinov-qidiruv/papka2/RASM.JPG
touch ~/sinov-qidiruv/papka2/hujjat.pdf
```

Barcha `.jpg` fayllarni qidiramiz:

```bash
find ~/sinov-qidiruv -name "*.jpg"
```

Natija:

```
/home/shamsiddin/sinov-qidiruv/papka1/rasm.jpg
```

E'tibor bering — `RASM.JPG` (katta harfda) natijaga kirmadi, chunki `-name` katta-kichik harfga sezgir. Buni tuzatamiz:

```bash
find ~/sinov-qidiruv -iname "*.jpg"
```

Natija — endi ikkalasi ham chiqadi.

Faqat papkalarni qidiramiz:

```bash
find ~/sinov-qidiruv -type d
```

Natija:

```
/home/shamsiddin/sinov-qidiruv
/home/shamsiddin/sinov-qidiruv/papka1
/home/shamsiddin/sinov-qidiruv/papka2
```

Faqat oddiy fayllarni, `.pdf` bilan tugaydiganlarini qidiramiz:

```bash
find ~/sinov-qidiruv -type f -name "*.pdf"
```

Endi, `python3` buyrug'ining qayerda joylashganini bilamiz:

```bash
which python3
```

Natija (misol):

```
/usr/bin/python3
```

## Keng tarqalgan xatolar

❌ **`find`da `-name` shablonini tirnoqsiz yozish** (masalan, `find ~ -name *.jpg`).
✅ Shablonni doim tirnoq ichiga oling: `find ~ -name "*.jpg"`.

**Nega xato:** Tirnoqsiz yozilgan `*.jpg`ni, shell (bash), `find` ishga tushishidan **oldin**, joriy papkadagi mos keluvchi fayl nomlariga "kengaytirishga" harakat qiladi. Agar joriy papkada mos fayl bo'lmasa, ba'zi holatlarda kutilmagan xatolik yoki natija chiqishi mumkin — tirnoq, shablonni "xom holida", to'g'ridan-to'g'ri `find`ga yetkazadi.

❌ **`find`ni, `grep` bilan adashtirib, fayl **ichidagi** matnni qidirmoqchi bo'lish** (masalan, `find ~ -name "xato"` — "xato" so'zi bor fayllarni emas, nomi aynan "xato" bo'lgan faylni qidiradi).
✅ Fayl **ichidagi matn** kerak bo'lsa — `grep -r`, fayl yoki papkaning **o'zini, nomi bo'yicha** topish kerak bo'lsa — `find` ishlatiladi.

**Nega xato:** Ikki buyruq, ikki butunlay boshqa narsani qidiradi: `find` — fayl **nomlari** bo'yicha, `grep` — fayl **mazmuni** bo'yicha. Ularni chalkashtirish, hech qanday natija bermaydigan qidiruvga olib keladi.

❌ **`which` natijasini, buyruq mavjud emasligi bilan adashtirish** — agar `which` hech narsa qaytarmasa (bo'sh natija), bu, buyruq umuman o'rnatilmaganini bildiradi, lekin ba'zilar buni tushunmay, xato deb chalkashib qoladi.
✅ `which <buyruq>` bo'sh natija bersa — bu, o'sha buyruq, tizimning `PATH`ida (6-bobda batafsil o'rganiladi) topilmagani, ya'ni odatda o'rnatilmagani haqida to'g'ri signal.

**Nega xato:** Bo'sh natija — xatolik emas, balki "bu buyruq hozircha topilmadi" degan **aniq va foydali** ma'lumot.

## Mashq/topshiriq

**(Oson)** `~/sinov-qidiruv` papkasida, nomi `hisobot` so'zidan boshlanadigan barcha fayllarni `find` bilan toping (maslahat: `-name "hisobot*"`).

**(O'rtacha)** `~/sinov-qidiruv` ichida, faqat **fayllarni** (papkalarni emas), kengaytmasidan qat'i nazar (`.txt`, `.jpg`, `.pdf` — hammasi), sanang (maslahat: `-type f` bilan `find`ni ishlating, natijani `wc -l` bilan sanang — bu, avvalgi darsda o'rgangan bilim bilan bog'lanadi).

**(Qiyin)** `bash` buyrug'ining qayerda joylashganini `which` bilan toping. So'ng, `find /usr/bin -iname "*python*"` buyrug'i orqali, `/usr/bin` papkasida, nomida "python" so'zi bor barcha fayllarni (katta-kichik harfga qaramay) qidiring va natijada nechta versiya (masalan, `python3`, `python3.12`) borligini kuzating.

<details>
<summary>Javoblarni ko'rish</summary>

1. `find ~/sinov-qidiruv -name "hisobot*"`.
2. `find ~/sinov-qidiruv -type f | wc -l` — `find`, barcha fayllarning to'liq yo'lini, har birini alohida qatorda chiqaradi, `wc -l` esa shu qatorlarni sanaydi.
3. `which bash` — odatda `/usr/bin/bash` yoki `/bin/bash` natijasini beradi. `find /usr/bin -iname "*python*"` — tizimda o'rnatilgan turli Python versiyalari va bog'liq vositalarni (masalan, `python3`, `python3.12`, `pip3`) ko'rsatishi mumkin — bu, bitta tizimda bir nechta versiya yonma-yon turishi mumkinligini ko'rsatadi.

</details>

## Qisqacha xulosa

`find` — fayl tizimida, faylning **o'zini**, nomi (`-name`/`-iname`), turi (`-type f`/`-type d`), hajmi yoki sanasi bo'yicha qidirish uchun ishlatiladi (fayl **mazmunini** emas — bu, `grep`ning vazifasi), `which` esa — terminalda chaqirilgan buyruqning, tizimda aynan qaysi faylga tegishli ekanini ko'rsatadi, bu ikkalasi birgalikda, "kerakli narsa qayerda ekanini" tezda topish imkonini beradi.
