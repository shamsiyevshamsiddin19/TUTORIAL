# Fayl uzatish (scp va rsync)

## Bu darsda nimalarni o'rganasiz

- `scp` bilan, fayl va papkalarni, mahalliy va masofaviy kompyuter orasida ko'chirasiz
- `rsync` bilan, faqat **o'zgargan** qismlarni ko'chirib, vaqtni tejaysiz
- `scp` va `rsync` orasidagi asosiy farqni tushunasiz

## Nazariy qism

### `scp` — SSH orqali, oddiy fayl nusxalash

**`scp`** (Secure Copy) — avvalgi darsda o'rgangan SSH ulanishidan foydalanib, faylni, mahalliy kompyuter va masofaviy server orasida, xavfsiz ko'chiradi. Uning sintaksisi, oddiy `cp`ga o'xshaydi, faqat, masofaviy manzil, `foydalanuvchi@server:yo'l` formatida yoziladi:

**Mahalliy kompyuterdan, serverga yuborish:**

```bash
scp mahalliy-fayl.txt foydalanuvchi@server:/masofadagi/papka/
```

**Serverdan, mahalliy kompyuterga olish:**

```bash
scp foydalanuvchi@server:/masofadagi/fayl.txt ~/mahalliy-papka/
```

Papkani, ichidagi hamma narsasi bilan ko'chirish uchun, `cp`dagi kabi, `-r` bayrog'i kerak:

```bash
scp -r mahalliy-papka/ foydalanuvchi@server:/masofadagi/joy/
```

### `rsync` — aqlliroq, samaraliroq nusxalash

**`rsync`** — `scp`ga o'xshash vazifani bajaradi, ammo ancha "aqlli": u, manba va manzildagi fayllarni **solishtiradi**, va faqat, **o'zgargan qismlarni** ko'chiradi — butun faylni qaytadan emas. Bu, ayniqsa, katta hajmli fayllarni, tez-tez, kichik o'zgarishlar bilan, qayta-qayta uzatishда, sezilarli vaqt tejaydi.

Asosiy sintaksis, `scp`ga o'xshash:

```bash
rsync -avz manba/ foydalanuvchi@server:/manzil/
```

Eng ko'p ishlatiladigan bayroqlar:

- `-a` (archive) — papka tuzilmasini, ruxsatlarni va sanalarni, **to'liq saqlagan holda** nusxalaydi
- `-v` (verbose) — jarayon davomida, nima ko'chirilayotganini, batafsil ko'rsatadi
- `-z` (compress) — uzatish paytida, ma'lumotni siqadi (tarmoq orqali tezroq o'tishi uchun)

### Muhim farq: manba nomining oxiridagi `/`

`rsync`da, manba papka nomining oxiriga `/` qo'yish yoki qo'ymaslik — **natijaga sezilarli ta'sir qiladi**:

- `rsync -avz papka/ manzil/` — `papka`ning **ichidagi mazmuni**, `manzil`ning ichiga ko'chiriladi (`papka`ning o'zi emas)
- `rsync -avz papka manzil/` (oxirida `/` yo'q) — `papka`ning **o'zi**, butunligicha, `manzil` ichiga ko'chiriladi (natijada, `manzil/papka/...` hosil bo'ladi)

## Amaliy misol

Sinov uchun, kichik fayl va papka tayyorlaymiz:

```bash
mkdir -p ~/sinov-uzatish/hujjatlar
echo "Bu — sinov fayli" > ~/sinov-uzatish/hisobot.txt
echo "Ichki fayl" > ~/sinov-uzatish/hujjatlar/ichki.txt
```

**`scp` misoli** (faraz qilingan server bilan — o'zingizga tegishli, haqiqiy manzil bilan almashtiring):

```bash
scp ~/sinov-uzatish/hisobot.txt shamsiddin@mening-serverim.uz:/home/shamsiddin/
```

Natija (misol):

```
hisobot.txt    100%   23     1.2KB/s   00:00
```

Papkani, ichidagi hamma narsasi bilan yuborish:

```bash
scp -r ~/sinov-uzatish/hujjatlar shamsiddin@mening-serverim.uz:/home/shamsiddin/
```

**`rsync` misoli** — xuddi shu papkani, `rsync` bilan uzatish (natijasi, `scp -r`ga o'xshash, ammo, agar keyinroq, xuddi shu buyruqni, papka ichidagi bitta faylni o'zgartirib, qayta ishga tushirsangiz, `rsync`, faqat o'sha o'zgargan faylni qayta uzatadi):

```bash
rsync -avz ~/sinov-uzatish/hujjatlar/ shamsiddin@mening-serverim.uz:/home/shamsiddin/hujjatlar/
```

Natija (misol):

```
sending incremental file list
./
ichki.txt

sent 145 bytes  received 35 bytes  120.00 bytes/sec
```

Endi, papka ichidagi faylni, ozgina o'zgartiramiz, va **xuddi shu** buyruqni qayta ishga tushiramiz:

```bash
echo "Yangi qator qo'shildi" >> ~/sinov-uzatish/hujjatlar/ichki.txt
rsync -avz ~/sinov-uzatish/hujjatlar/ shamsiddin@mening-serverim.uz:/home/shamsiddin/hujjatlar/
```

Bu safar, `rsync`, faqat, **o'zgargan** `ichki.txt` faylini qayta uzatadi — boshqa fayllar (agar mavjud bo'lganida), qayta tekshirilib, o'zgarmagan bo'lsa, o'tkazib yuboriladi.

## Keng tarqalgan xatolar

❌ **`rsync`da, manba papka oxiridagi `/` borligi yoki yo'qligiga e'tibor bermaslik**, natijada, fayllar, kutilmagan joyga (bir daraja chuqurroq yoki sayozroq) tushib qolishi.
✅ `rsync`ni ishlatishdan oldin, avval, kichik, sinov papkasida, natijani tekshirib ko'ring, va, "papka mazmunini" yoki "papkaning o'zini" ko'chirmoqchi ekaningizga qarab, `/` ni ongli ravishda qo'shing yoki qoldiring.

**Nega xato:** `rsync`, manba yo'lining oxiridagi `/`ni, "shu papkaning ichiga kirib, mazmunini ko'chir" degan ma'noda talqin qiladi; `/` bo'lmasa esa, "shu papkaning o'zini, butunligicha, manzil ichiga ko'chir" deb tushunadi — bu ikki xatti-harakat, natijada hosil bo'ladigan papka tuzilmasini, sezilarli darajada farqlantiradi.

❌ **Katta hajmli fayllarni, tez-tez, kichik o'zgarishlar bilan qayta uzatishda, `scp`dan foydalanish**, va har safar, butun faylni, boshidan oxirigacha qayta yuklab, vaqt sarflash.
✅ Agar fayl (yoki papka), tez-tez, kichik o'zgarishlar bilan, qayta-qayta uzatiladigan bo'lsa, `rsync`ni tanlang — u, faqat farqlarni uzatib, sezilarli vaqt tejaydi.

**Nega xato:** `scp`, har safar, faylni, **to'liq, boshidan oxirigacha** ko'chiradi — u, avvalgi uzatilgan nusxa bilan solishtirish imkoniyatiga ega emas; `rsync` esa, aynan shu solishtirish uchun mo'ljallangan.

❌ **`scp -r` yoki `rsync`ni, manzil papka mavjudligiga ishonch hosil qilmasdan ishlatish.**
✅ Agar manzil papka, serverda hali mavjud emasligiga shubha qilsangiz, avval, `ssh` orqali serverga ulanib, `mkdir -p` bilan uni oldindan yarating (yoki `rsync`ning ayrim konfiguratsiyalari, ba'zan avtomatik yaratadi — ammo bunga ishonib qolmaslik tavsiya etiladi).

**Nega xato:** Ba'zi holatlarda, mavjud bo'lmagan manzil papka, `scp`da xatoga olib kelishi, yoki, `rsync`da, kutilganidan boshqacha (masalan, "papka" o'rniga, xuddi shu nomli "fayl" sifatida) natija berishi mumkin.

## Mashq/topshiriq

**(Oson)** `~/sinov-uzatish/hisobot.txt` faylini, `scp` yordamida, faraziy `shamsiddin@server:/tmp/` manziliga yuborish uchun to'g'ri buyruqni yozing (haqiqiy serverga ulanmasdan, faqat sintaksisni mashq qiling).

**(O'rtacha)** `~/sinov-uzatish` papkasini, `rsync -avz` yordamida, xuddi shu faraziy serverga, `hujjatlar` papkasining **ichidagi mazmuni**, serverdagi `/tmp/hujjatlar-nusxa/` ichiga tushadigan qilib (ya'ni, manba oxirida `/` bilan) yozing.

**(Qiyin)** Ikkita `rsync` buyrug'ini yozib solishtiring: birinchisida, manba oxirida `/` **bor** (`~/sinov-uzatish/hujjatlar/`), ikkinchisida — **yo'q** (`~/sinov-uzatish/hujjatlar`), ikkalasi ham, manzil sifatida `/tmp/natija/`ni ishlatadi. Ikkala holatda ham, natijada, `/tmp/natija/` ichida, aniq qanday papka tuzilmasi hosil bo'lishini (masalan, `/tmp/natija/ichki.txt` yoki `/tmp/natija/hujjatlar/ichki.txt`), o'z so'zlaringiz bilan tushuntiring.

## Qisqacha xulosa

`scp` — SSH orqali, fayl yoki papkani (`-r` bilan), mahalliy va masofaviy kompyuter orasida, oddiy, to'liq nusxalash uchun ishlatiladi; `rsync` esa — manba va manzilni solishtirib, faqat **o'zgargan qismlarni** uzatadigan, ancha samaraliroq alternativa bo'lib, ayniqsa, katta yoki tez-tez yangilanadigan fayllar uchun tavsiya etiladi — ikkalasida ham, manba yo'lining oxiridagi `/` belgisiga (ayniqsa `rsync`da) e'tibor berish, kutilmagan papka tuzilmalarining oldini oladi.
