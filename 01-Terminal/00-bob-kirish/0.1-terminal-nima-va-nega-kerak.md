# Terminal nima va nega kerak

## Bu darsda nimalarni o'rganasiz

- Terminal, buyruqlar qatori (CLI) va grafik interfeys (GUI) o'rtasidagi farqni tushunasiz
- Terminal nima uchun, ba'zi ishlarda, sichqoncha bilan ishlashdan tezroq va kuchliroq ekanini bilib olasiz
- Linux tizimida terminal dasturini (terminal emulyator) ochasiz
- Birinchi buyruqni ishga tushirasiz va natijani o'qiysiz

## Nazariy qism

### GUI va CLI — ikki xil "til"

Kompyuter bilan ikki xil usulda gaplashish mumkin. **GUI** (Graphical User Interface) — bu, tugmalarni bosib, oynalarni sudrab ishlaydigan, tanish grafik muhit. **CLI** (Command Line Interface) — bu, kompyuterga **matn ko'rinishidagi buyruqlar** yozib buyruq berish usuli. Terminal — aynan shu CLI bilan ishlash uchun ochiladigan dastur (oyna).

Nega GUI turganda, yana CLI kerak? Sababi oddiy: GUI'da "500 ta faylning nomini o'zgartirish" kerak bo'lsa, siz 500 marta sichqoncha bosishingiz kerak bo'ladi. Terminalda esa, bitta buyruq — bir necha soniyada, 500 ta faylni ham o'zgartiradi. Terminal — **takrorlanuvchi, aniq va katta hajmdagi ishlarni** tez bajarish uchun yaratilgan. Shuningdek, serverlar (masalan, veb-sayt joylashgan uzoqdagi kompyuter) odatda GUI'ga ega bo'lmaydi — ular bilan ishlashning yagona yo'li — terminal.

### Terminal, shell va buyruqlar qatori — atamalar farqi

Uch atama ko'pincha aralashtiriladi, lekin ularning ma'nosi boshqacha:

- **Terminal (yoki terminal emulyator)** — bu, matn kiritish va natijani ko'rish uchun ochiladigan **dastur/oyna** (masalan, Ubuntu'dagi "Terminal" ilovasi).
- **Shell** — bu, terminal ichida ishlaydigan, siz yozgan buyruqni **tushunadigan va bajaradigan dastur**. Eng ko'p tarqalgani — `bash` (Bourne Again SHell). `zsh` — bash'ga o'xshash, ba'zi qo'shimcha qulayliklarga ega yana bir shell.
- **Buyruqlar qatori (command line)** — bu, siz buyruqni yozadigan qator, odatda `$` yoki `#` belgisi bilan boshlanadi.

Ushbu darslikda, biz asosan **bash**ga qaratilgan holda o'rgatamiz — chunki u eng keng tarqalgan va deyarli barcha Linux tizimlarida standart hisoblanadi.

### Prompt (kutish belgisi) nimani bildiradi

Terminalni ochganingizda, quyidagiga o'xshash yozuv ko'rasiz:

```
shamsiddin@laptop:~$
```

Bu — **prompt** deb ataladi, va sizga uchta narsani aytadi: `shamsiddin` — joriy foydalanuvchi nomi, `laptop` — kompyuter nomi, `~` — joriy joylashgan papka (`~` — "uy papkasi" degani). Oxiridagi `$` belgisi — oddiy foydalanuvchi ekanligingizni bildiradi (agar `#` bo'lsa, bu — administrator/root sifatida ishlayotganingizni anglatadi, va bunday holatda ayniqsa ehtiyot bo'lish kerak).

## Amaliy misol

Ubuntu yoki boshqa Linux distributivida terminalni ochish uchun, klaviaturada quyidagi tugmalar birikmasini bosing:

```bash
Ctrl + Alt + T
```

Yoki, ilovalar ro'yxatidan "Terminal" (yoki "Konsole", distributivga qarab) dasturini toping va oching.

Terminal ochilgach, birinchi buyruqni kiriting va `Enter` bosing:

```bash
echo "Salom, terminal!"
```

Natija:

```
Salom, terminal!
```

`echo` buyrug'i — o'ziga berilgan matnni, terminalda ekranga chiqaradi. Bu — terminalning eng sodda, ammo skriptlarda juda ko'p ishlatiladigan buyruqlaridan biri (masalan, skript ichida foydalanuvchiga xabar ko'rsatish uchun).

Endi, joriy sanani ko'rsatuvchi buyruqni sinab ko'ring:

```bash
date
```

Natija (sizning joriy sanangiz va vaqtingiz chiqadi):

```
Se 19-avg 2026 14:32:07 +05
```

## Keng tarqalgan xatolar

❌ **Buyruqni katta harf bilan yozish** (masalan, `Echo` yoki `DATE`). Terminal, katta va kichik harflarni **farqlaydi** (case-sensitive). `echo` ishlaydi, `Echo` esa "buyruq topilmadi" xatosini beradi.
✅ Buyruqlarni doim, hujjatda ko'rsatilganidek, aniq harflar bilan yozing.

**Nega xato:** Linux (va bash) — Windows'dan farqli, harflarga juda sezgir. `Desktop` va `desktop` — ikkita butunlay boshqa nom sifatida qabul qilinadi.

❌ **Buyruq va uning argumenti orasiga probel qo'ymaslik yoki ortiqcha probel qo'yish** (masalan, `echo"Salom"` — tirnoq bilan yopishib ketgan).
✅ `echo "Salom"` — buyruq va argument orasida, kamida bitta probel bo'lishi shart.

**Nega xato:** Shell, buyruqni va uning argumentlarini, probel orqali ajratadi. Probel bo'lmasa, shell butun matnni **bitta so'z** deb, mavjud bo'lmagan buyruq nomi sifatida izlaydi.

❌ **`Enter` bosishni unutish va keyin qo'shimcha buyruq yozishga urinish.** Yozilgan buyruq, `Enter` bosilmaguncha, hech qachon bajarilmaydi — u shunchaki ekranda "kutib" turadi.
✅ Har bir buyruqdan so'ng, albatta `Enter` tugmasini bosing.

## Mashq/topshiriq

**(Oson)** Terminalni oching va `whoami` buyrug'ini kiriting. Natijada nima chiqishini va bu nimani anglatishini tushunishga harakat qiling.

**(O'rtacha)** `echo` buyrug'idan foydalanib, ekranga o'z ismingiz va yoshingizni ko'rsatuvchi bitta xabar chiqaring (masalan: "Mening ismim ... va men ... yoshdaman").

**(Qiyin)** `date` buyrug'ini ishga tushiring, so'ng `man date` deb yozib (bu — keyingi darsda batafsil o'rganiladigan "qo'llanma" buyrug'i), chiqqan matnda sananinг formatini o'zgartirish uchun ishlatiladigan kamida bitta bayroqni (flag) toping. Topgan bayrog'ingiz bilan `date` buyrug'ini qayta ishga tushirib ko'ring. (Maslahat: `q` tugmasi — qo'llanmadan chiqish uchun.)

## Qisqacha xulosa

Terminal — matn orqali kompyuterga buyruq berish uchun ochiladigan dastur bo'lib, ichida ishlaydigan **shell** (masalan, bash) — yozilgan buyruqni tushunib bajaradi; prompt — joriy foydalanuvchi, kompyuter va papka haqida ma'lumot beradi, buyruqlar esa katta-kichik harflarga sezgir va probel orqali argumentlardan ajratiladi — bu ikki qoida, terminal bilan ishlashning eng boshlang'ich, ammo eng ko'p xato qilinadigan joyi hisoblanadi.
