# 4.2. `csv` va `enum` — CSV eksport, `TextChoices` qanday ishlaydi

## Bu darsda nimalarni o'rganasiz

- `csv.writer` bilan CSV fayl yaratishni va uni `HttpResponse` orqali to'g'ridan-to'g'ri yuklab olish sifatida yuborishni o'rganasiz
- `csv.DictWriter`ning oddiy `writer`dan qulayligini bilib olasiz
- `enum.Enum` asoslarini va Django'ning `TextChoices`/`IntegerChoices` aynan shu klass ustiga qanday qurilganini tushunasiz
- O'z holat (status) maydoningizni `enum` bilan tartibli va xatoga chidamli qilishni o'rganasiz

## Nazariy qism

### `csv` moduli — qatorlarni to'g'ri formatlash

CSV (Comma-Separated Values) — jadval ma'lumotini oddiy matn faylida saqlash formati. Uni qo'lda, `",".join(...)` bilan yaratish xavfli tuyuladi: agar qiymat ichida vergul yoki tirnoq belgisi bo'lsa (masalan mahsulot nomi `"Krossovka, o'lcham 42"`), fayl buziladi. `csv` moduli bu holatlarni avtomatik, to'g'ri hal qiladi:

```python
import csv
import sys

writer = csv.writer(sys.stdout)
writer.writerow(["Nomi", "Narxi"])
writer.writerow(["Krossovka, qora", 450000])
```

```
Nomi,Narxi
"Krossovka, qora",450000
```

E'tibor bering: `"Krossovka, qora"` avtomatik tirnoq ichiga olindi, chunki tarkibida vergul bor — bu qatorni keyin qayta o'qiganda (`csv.reader`), vergul "yangi ustun" deb emas, qiymatning bir qismi deb to'g'ri tushuniladi.

### `csv.DictWriter` — ustun nomlari bilan ishlash

Agar ma'lumot allaqachon `dict` ro'yxati shaklida bo'lsa (masalan Django QuerySet'dan `.values()`), `DictWriter` qulayroq — ustunlar tartibini alohida boshqarish shart emas:

```python
import csv
import sys

malumotlar = [
    {"nomi": "Krossovka", "narxi": 450000},
    {"nomi": "Ko'ylak", "narxi": 120000},
]

writer = csv.DictWriter(sys.stdout, fieldnames=["nomi", "narxi"])
writer.writeheader()
writer.writerows(malumotlar)
```

### `enum.Enum` — nomlangan doimiy qiymatlar to'plami

Ko'p loyihada "holat" kabi maydonlar oddiy string bilan ifodalanadi: `"kutilmoqda"`, `"tolandi"`, `"bekor_qilindi"`. Muammo — bu qiymatlar hech qayerda **ro'yxat** qilinmagan, xato yozish (`"tolandi"` o'rniga `"to'landi"`) osongina sodir bo'ladi va Python buni sezmaydi. `enum.Enum` — ruxsat etilgan qiymatlarni aniq, cheklangan ro'yxat sifatida belgilaydi:

```python
from enum import Enum


class BuyurtmaHolati(Enum):
    KUTILMOQDA = "kutilmoqda"
    TOLANDI = "tolandi"
    BEKOR_QILINDI = "bekor_qilindi"


print(BuyurtmaHolati.TOLANDI)         # BuyurtmaHolati.TOLANDI
print(BuyurtmaHolati.TOLANDI.value)   # "tolandi"
print(BuyurtmaHolati.TOLANDI.name)    # "TOLANDI"

for holat in BuyurtmaHolati:
    print(holat.name, "->", holat.value)
```

`BuyurtmaHolati.TOLANDI` — bu shunchaki string emas, alohida, aniq **nom**; agar kimdir `BuyurtmaHolati.TOLANID` (xato yozilgan) deb yozsa, Python darhol `AttributeError` beradi — string bilan bo'lganda esa xato yozilgan `"tolanid"` hech qanday xatosiz "jimgina" noto'g'ri ishlab ketardi.

### Django'ning `TextChoices` — `enum` ustiga qurilgan qatlam

0.1-darsda `TextChoices.__mro__`da `enum.Enum` borligini ko'rgan edik. Django buni modelda ishlatish uchun qulayroq qildi:

```python
from django.db import models


class Buyurtma(models.Model):
    class Holat(models.TextChoices):
        KUTILMOQDA = "kutilmoqda", "Kutilmoqda"
        TOLANDI = "tolandi", "To'landi"
        BEKOR_QILINDI = "bekor_qilindi", "Bekor qilindi"

    holat = models.CharField(max_length=20, choices=Holat.choices, default=Holat.KUTILMOQDA)
```

Har bir qatorda ikki qiymat: birinchisi — bazada saqlanadigan (`value`, oddiy `enum`dagi kabi), ikkinchisi — admin panelda va formada ko'rsatiladigan **odam o'qiydigan nom** (label). `Holat.choices` — Django admin/forma kutadigan `[(qiymat, nom), ...]` formatidagi ro'yxatni avtomatik hosil qiladi. `models.TextChoices` — oddiy `enum.Enum`ning Django uchun moslashtirilgan, `str`dan ham meros oluvchi versiyasi (shuning uchun `Buyurtma.objects.filter(holat=Buyurtma.Holat.TOLANDI)` — to'g'ridan-to'g'ri, `.value` yozmasdan ham ishlaydi).

## Amaliy misol

`onlayn_dokon` admin panelida, "to'langan buyurtmalarni CSV formatida yuklab olish" tugmasini qo'shamiz:

```python
# apps/buyurtmalar/views.py
import csv

from django.contrib.auth.decorators import staff_member_required
from django.http import HttpResponse

from .models import Buyurtma


@staff_member_required
def buyurtmalarni_csv_eksport(request):
    response = HttpResponse(content_type="text/csv")
    response["Content-Disposition"] = 'attachment; filename="buyurtmalar.csv"'

    writer = csv.writer(response)
    writer.writerow(["ID", "Mijoz", "Holat", "Summa", "Sana"])

    buyurtmalar = (
        Buyurtma.objects.filter(holat=Buyurtma.Holat.TOLANDI)
        .select_related("mijoz")
        .order_by("-yaratilgan_sana")
    )
    for b in buyurtmalar:
        writer.writerow([
            b.id,
            b.mijoz.toliq_ism,
            b.get_holat_display(),   # "TOLANDI" emas, "To'landi" — odam o'qiydigan nom
            b.umumiy_summa,
            b.yaratilgan_sana.strftime("%Y-%m-%d %H:%M"),
        ])

    return response
```

Muhim detal: `HttpResponse`ning o'zi — fayl kabi `.write()` metodini qo'llab-quvvatlaydi, shuning uchun `csv.writer(response)` to'g'ridan-to'g'ri ishlaydi — CSV avval xotirada yig'ilib, keyin yuborilmaydi, balki bevosita `response`ga yoziladi. `get_holat_display()` — Django'ning `choices` bilan modelga avtomatik qo'shadigan metodi (har qanday `choices=`li maydon uchun `get_<maydon_nomi>_display()` shaklida mavjud bo'ladi): u saqlangan qiymat (`"tolandi"`) o'rniga, unga mos label (`"To'landi"`)ni qaytaradi.

## Keng tarqalgan xatolar

**Xato 1:** CSV faylni qo'lda, `",".join()` bilan yaratish.

❌ `f"{mahsulot.nomi},{mahsulot.narxi}\n"` — agar `mahsulot.nomi` ichida vergul bo'lsa (masalan `"Krossovka, qora"`), CSV fayl noto'g'ri (ustunlar siljigan) bo'lib chiqadi, va bu xato faqat faylni Excel'da ochganda payqaladi.

✅ Har doim `csv.writer`/`csv.DictWriter`dan foydalaning — u tirnoq va vergul kabi maxsus belgilarni avtomatik, to'g'ri qochiradi (escape qiladi).

**Xato 2:** Model maydonida `choices` o'rniga qo'lda tekshirish yozish.

❌ `if buyurtma.holat not in ["kutilmoqda", "tolandi", "bekor_qilindi"]: raise ValueError(...)` — har bir joyda bu ro'yxatni qayta yozish, va ro'yxat o'zgarganda (yangi holat qo'shilganda) barcha joylarni yangilashni unutish xavfi.

✅ `models.TextChoices` bilan ro'yxatni **bitta joyda** aniqlang (`Buyurtma.Holat`), va uni har doim shu yerdan import qilib ishlating: `Buyurtma.Holat.TOLANDI`. Django o'zi `choices=` orqali validatsiyani ta'minlaydi.

**Xato 3:** `enum` a'zosining `.value`si va nomini (`.name`) aralashtirib ishlatish.

❌ `if buyurtma.holat == BuyurtmaHolati.TOLANDI:` — agar `buyurtma.holat` bazadan olingan oddiy string (`"tolandi"`) bo'lsa va `BuyurtmaHolati.TOLANDI` esa `enum` a'zosi (`TextChoices` bo'lmasa), bu solishtiruv har doim `False` bo'ladi, chunki `enum.Enum` a'zosi va oddiy string — teng emas turlar.

✅ Django'ning `TextChoices`i ayni shu muammoni hal qiladi — u `str`dan ham meros oladi, shuning uchun `buyurtma.holat == Buyurtma.Holat.TOLANDI` **to'g'ri** ishlaydi (chunki `Holat.TOLANDI` aslida `"tolandi"` stringining o'zi, faqat qo'shimcha nom bilan). Oddiy `enum.Enum`da (Django tashqarisida) esa har doim `.value` bilan solishtiring: `buyurtma.holat == BuyurtmaHolati.TOLANDI.value`.

## Mashq/topshiriq

**(Oson)** `python manage.py shell`da `from apps.buyurtmalar.models import Buyurtma; list(Buyurtma.Holat)` bajarib, barcha holatlar ro'yxatini ko'ring, so'ng `Buyurtma.Holat.TOLANDI.label`ni chiqaring (`.value` bilan solishtiring).

**(O'rtacha)** `buyurtmalarni_csv_eksport` view'iga sana filtri qo'shing: URL parametri sifatida `?boshlanish=2026-01-01&tugash=2026-12-31` qabul qilib, faqat shu oraliqdagi buyurtmalarni eksport qilsin (`request.GET.get(...)` va `datetime.strptime` dan foydalaning).

**(Qiyin)** `Buyurtma.Holat`ga yangi holat qo'shing: `KUTIB_TURIBDI_TOLOV = "kutib_turibdi_tolov", "To'lov kutilmoqda"`. Shundan so'ng, mavjud migratsiyalar bilan nima sodir bo'lishini (yangi migratsiya kerakmi yoki yo'qmi) `python manage.py makemigrations --dry-run` orqali tekshiring va natijani bir jumlada izohlang (eslatma: `choices=` — bazaning o'zida cheklov emas, faqat Django darajasidagi validatsiya).

## Qisqacha xulosa

`csv` moduli — jadval ma'lumotini to'g'ri (vergul, tirnoq kabi maxsus belgilarni hisobga olib) CSV formatga yozadi, va `HttpResponse` fayl kabi ishlagani uchun `csv.writer(response)` to'g'ridan-to'g'ri, xotirada oraliq nusxa yaratmasdan eksport qilish imkonini beradi. `enum.Enum` — ruxsat etilgan qiymatlarni aniq, xato yozishga chidamli ro'yxat sifatida belgilaydi; Django'ning `TextChoices`/`IntegerChoices` aynan shu klass ustiga qurilgan, `str`dan meros olib, bazadagi qiymat bilan to'g'ridan-to'g'ri solishtirishga imkon beradi va `choices=` orqali admin/formalarda avtomatik tanlov ro'yxati hosil qiladi. Keyingi bobda — xavfsiz tokenlar (`secrets`) va fayl/parol checksumlari (`hashlib`) bilan tanishamiz.
