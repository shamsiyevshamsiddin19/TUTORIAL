# 7.2. `functools` va `collections` — keshlash va ma'lumotlarni guruhlash

## Bu darsda nimalarni o'rganasiz

- `functools.lru_cache` bilan qimmat hisoblarni avtomatik keshlashni o'rganasiz
- `functools.wraps` nega maxsus dekorator yozganda **shart** ekanini tushunasiz
- `collections.defaultdict` va `collections.Counter` bilan ma'lumotlarni tez guruhlash va sanashni o'rganasiz
- `lru_cache`ning Django'ning `cached_property`sidan farqini bilib olasiz

## Nazariy qism

### `functools.lru_cache` — funksiya natijasini keshlash

Agar funksiya bir xil argumentlar bilan qayta-qayta chaqirilsa va har safar qimmat hisoblash (yoki tashqi so'rov) bajarsa, natijani **keshlash** — birinchi chaqiruvda hisoblab, keyingilarida saqlangan natijani qaytarish — mantiqiy:

```python
from functools import lru_cache
import time


@lru_cache(maxsize=128)
def qimmat_hisoblash(n):
    time.sleep(2)   # og'ir hisoblashni simulyatsiya qilamiz
    return n * n


qimmat_hisoblash(5)   # 2 soniya kutadi, natija: 25
qimmat_hisoblash(5)   # DARHOL qaytadi (keshdan) — 25
qimmat_hisoblash(6)   # yana 2 soniya (yangi argument)
```

`maxsize=128` — keshda saqlanadigan **noyob argument kombinatsiyalari** sonini cheklaydi; eng uzoq ishlatilmagan natija chiqarib tashlanadi (LRU — Least Recently Used). `maxsize=None` — cheksiz kesh (ehtiyot bo'ling, xotira cheksiz o'sishi mumkin).

**Muhim cheklov:** `lru_cache` faqat **hashable** (o'zgarmas, masalan son, string, tuple) argumentlar bilan ishlaydi — `list` yoki `dict` argument sifatida uzatilsa, `TypeError: unhashable type` beradi.

### `functools.wraps` — dekorator yozganda

Django'da ko'p custom dekorator yoziladi (masalan `@staff_member_required` kabi). Dekorator yozishda `functools.wraps` ishlatilmasa, muammo chiqadi:

```python
from functools import wraps


def logga_yoz(funksiya):
    @wraps(funksiya)   # bu qatorsiz, funksiya "nomini yo'qotadi"
    def ichki(*args, **kwargs):
        print(f"{funksiya.__name__} chaqirildi")
        return funksiya(*args, **kwargs)
    return ichki


@logga_yoz
def mahsulot_royxati(request):
    """Barcha mahsulotlarni ko'rsatadi."""
    ...


print(mahsulot_royxati.__name__)   # 'mahsulot_royxati' ('ichki' EMAS — @wraps tufayli)
print(mahsulot_royxati.__doc__)    # 'Barcha mahsulotlarni ko'rsatadi.'
```

`@wraps(funksiya)`siz, `mahsulot_royxati.__name__` — `'ichki'` bo'lib qolar edi (chunki texnik jihatdan `mahsulot_royxati` endi `ichki` funksiyaga "ishora qiladi"). Bu Django'da jiddiy oqibatlarga olib kelishi mumkin: Django'ning ba'zi ichki mexanizmlari (masalan admin, yoki xato xabarlarida) funksiya nomiga tayanadi — nom yo'qolsa, diagnostika qiyinlashadi.

### `collections.defaultdict` — "kalit yo'q bo'lsa" muammosini yechish

Oddiy `dict`da mavjud bo'lmagan kalitga murojaat `KeyError` beradi. Ma'lumotlarni guruhlashda bu doim ortiqcha `if kalit not in dict` tekshiruviga olib keladi:

```python
# Oddiy dict bilan — noqulay
guruhlar = {}
for mahsulot in mahsulotlar:
    if mahsulot.bolim not in guruhlar:
        guruhlar[mahsulot.bolim] = []
    guruhlar[mahsulot.bolim].append(mahsulot)

# defaultdict bilan — qisqa
from collections import defaultdict

guruhlar = defaultdict(list)
for mahsulot in mahsulotlar:
    guruhlar[mahsulot.bolim].append(mahsulot)   # kalit yo'q bo'lsa, AVTOMATIK bo'sh list yaratiladi
```

`defaultdict(list)` — har bir yangi kalitga birinchi murojaatda, avtomatik ravishda `list()` (bo'sh ro'yxat) yaratadi, shuning uchun "kalit bormi-yo'qmi" tekshiruvi kerak emas.

### `collections.Counter` — sanash uchun maxsus dict

```python
from collections import Counter

bolim_nomlari = ["Poyabzal", "Kiyim", "Poyabzal", "Aksessuar", "Kiyim", "Poyabzal"]
sanoq = Counter(bolim_nomlari)
print(sanoq)                    # Counter({'Poyabzal': 3, 'Kiyim': 2, 'Aksessuar': 1})
print(sanoq.most_common(2))     # [('Poyabzal', 3), ('Kiyim', 2)] — eng ko'p uchraydigan 2 tasi
```

## Amaliy misol

`onlayn_dokon`da valyuta konvertatsiya kursini (tashqi API'dan olinadigan, soatlab o'zgarmaydigan qiymat) keshlaymiz, va sotuv statistikasini `defaultdict`/`Counter` bilan tez hisoblaymiz:

```python
# apps/mahsulotlar/utils.py
import time
from functools import lru_cache


@lru_cache(maxsize=8)
def valyuta_kursini_olish(valyuta_kodi: str) -> float:
    """Tashqi API'dan valyuta kursini oladi (qimmat, tarmoq so'rovi)."""
    # Haqiqiy loyihada bu yerda requests.get(...) bo'lardi
    time.sleep(1)   # tarmoq kechikishini simulyatsiya qilamiz
    kurslar = {"USD": 12650.0, "EUR": 13720.0, "RUB": 135.0}
    return kurslar.get(valyuta_kodi, 1.0)
```

Statistika uchun management command:

```python
# apps/mahsulotlar/management/commands/bolim_statistikasi.py
from collections import Counter, defaultdict
from decimal import Decimal

from django.core.management.base import BaseCommand

from apps.buyurtmalar.models import BuyurtmaElementi


class Command(BaseCommand):
    help = "Bo'limlar bo'yicha sotuv statistikasini ko'rsatadi"

    def handle(self, *args, **options):
        bolim_soni = Counter()
        bolim_summasi = defaultdict(lambda: Decimal("0.00"))

        for element in BuyurtmaElementi.objects.select_related("mahsulot__bolim"):
            bolim_nomi = element.mahsulot.bolim.nomi
            bolim_soni[bolim_nomi] += element.miqdor
            bolim_summasi[bolim_nomi] += element.narx * element.miqdor

        self.stdout.write("=== Eng ko'p sotilgan 3 bo'lim ===")
        for nomi, soni in bolim_soni.most_common(3):
            self.stdout.write(f"{nomi}: {soni} dona, {bolim_summasi[nomi]} so'm")
```

`defaultdict(lambda: Decimal("0.00"))` — 3.2-darsda ko'rgan `Decimal`ni standart qiymat sifatida ishlatadi, `lambda` kerak, chunki `defaultdict` argumenti **chaqiriladigan** (callable) narsa bo'lishi kerak, `Decimal("0.00")`ning o'zi emas (aks holda barcha kalitlar bitta **xuddi shu** obyektga "ishora" qilib qolishi mumkin edi — garchi `Decimal` o'zgarmas bo'lgani uchun bu holatda muammo tug'dirmasa ham, umumiy qoida sifatida `lambda`/funksiya ishlatish to'g'ri).

## Keng tarqalgan xatolar

**Xato 1:** `lru_cache`ni tez-tez o'zgaradigan (masalan bazadan olinadigan) ma'lumot uchun ishlatish.

❌ `@lru_cache` bilan `mahsulot_narxini_olish(mahsulot_id)` funksiyasini keshlash — agar narx admin panelda o'zgartirilsa, funksiya **eski** (keshlangan) narxni qaytarishda davom etadi, chunki `lru_cache` bazadagi o'zgarishdan bexabar.

✅ `lru_cache`ni faqat **haqiqatan barqaror** (deyarli o'zgarmaydigan, yoki vaqt bo'yicha o'zi yangilanadigan) ma'lumot uchun ishlating — masalan tashqi API'dan olinadigan, kamdan-kam o'zgaradigan valyuta kursi. Tez-tez o'zgaradigan ma'lumot uchun Django'ning `django-redis` kabi kesh tizimidan (4-qismda ko'rilgan), muddat (`timeout`) bilan foydalaning.

**Xato 2:** Custom dekoratorda `@wraps`ni unutish.

❌ Yuqoridagi `logga_yoz` misolida `@wraps(funksiya)` qatori olib tashlansa — bir nechta dekorator ustma-ust qo'llanilganda yoki Django admin/introspeksiya funksiya nomiga tayanganda, tushunarsiz xatolar yoki noto'g'ri nomlar chiqishi mumkin.

✅ Har bir yozadigan dekoratoringizda ichki funksiya ustiga har doim `@wraps(asl_funksiya)` qo'ying — bu bir qatorlik, lekin muhim odat.

**Xato 3:** `defaultdict`ning standart qiymatini **chaqiriladigan** emas, tayyor obyekt sifatida berish.

❌ `defaultdict([])` — `TypeError: first argument must be callable or None` beradi, chunki `defaultdict` argument sifatida **funksiya** (masalan `list`, `dict`, yoki `lambda: ...`) kutadi, tayyor `[]` obyektini emas.

✅ `defaultdict(list)` (funksiyaning o'zi, qavssiz) yoki murakkabroq standart qiymat uchun `defaultdict(lambda: Decimal("0.00"))` yozing.

## Mashq/topshiriq

**(Oson)** Shell'da `valyuta_kursini_olish("USD")`ni ikki marta ketma-ket chaqirib, `time`ni o'lchang (`import time; t0 = time.time(); ...; print(time.time() - t0)`) — birinchisi ~1 soniya, ikkinchisi deyarli 0 soniya bo'lishini kuzating.

**(O'rtacha)** `bolim_statistikasi` buyrug'iga, `Counter.most_common()`dan foydalanib, **eng kam** sotilgan bo'limni ham (ro'yxatning oxiridan) ko'rsatadigan qator qo'shing (`bolim_soni.most_common()[-1]` — argumentsiz `most_common()` barchasini, kamayish tartibida qaytaradi).

**(Qiyin)** `valyuta_kursini_olish` funksiyasiga, keshni **qo'lda tozalash** imkonini bering — masalan admin "kursni yangilash" tugmasini bossa, eski keshlangan qiymat o'chirilishi kerak. `lru_cache` bilan bezalgan funksiyaning `.cache_clear()` metodidan (funksiyaning o'zida avtomatik mavjud bo'ladi) foydalanib, buni bajaruvchi alohida funksiya yozing.

## Qisqacha xulosa

`functools.lru_cache` — funksiya natijasini avtomatik keshlab, qimmat hisoblarni tezlashtiradi, lekin faqat barqaror (tez o'zgarmaydigan) ma'lumot uchun mos; `functools.wraps` esa custom dekorator yozganda funksiya nomi va hujjatini saqlab qolish uchun **shart**. `collections.defaultdict` — guruhlash kodini "kalit bormi" tekshiruvidan xalos qiladi, `collections.Counter` esa elementlarni sanash va eng ko'p/kam uchraganlarini topishni bir qatorda bajaradi. Bu ikki modul birga — Django loyihasida statistika, hisobot va keshlash kodini ancha qisqa va o'qish oson qiladi. Keyingi bobda — management command'larga argument qo'shish (`argparse`) va ulardan tashqi buyruq chaqirish (`subprocess`) bilan tanishamiz.
