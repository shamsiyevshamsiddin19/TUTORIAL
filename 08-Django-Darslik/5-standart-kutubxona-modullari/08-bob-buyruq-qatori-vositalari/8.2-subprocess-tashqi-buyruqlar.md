# 8.2. `subprocess` — management command ichidan tashqi buyruq chaqirish

## Bu darsda nimalarni o'rganasiz

- `subprocess.run()` bilan tashqi buyruqni (masalan `pg_dump`, `ffmpeg`) Python'dan ishga tushirishni o'rganasiz
- `shell=True`ning nega xavfli ekanini va undan qanday qochishni tushunasiz
- Buyruq natijasini (`stdout`, `stderr`, `returncode`) qanday to'g'ri tekshirishni bilib olasiz
- Foydalanuvchi kiritgan ma'lumot bilan tashqi buyruq chaqirishda xavfsizlikni ta'minlashni o'rganasiz
- Buyruq chaqiruvi oqimini diagramma orqali ko'rasiz

## Nazariy qism

### `subprocess.run()` — asosiy usul

`subprocess` moduli — Python'dan operatsion tizimning boshqa dasturini (buyruq qatori vositasini) ishga tushirish, uning natijasini olish uchun ishlatiladi:

```python
import subprocess

natija = subprocess.run(
    ["ls", "-la", "/tmp"],
    capture_output=True,
    text=True,
)

print(natija.returncode)   # 0 — muvaffaqiyatli, 0dan boshqa — xato
print(natija.stdout)       # buyruq chiqargan matn
print(natija.stderr)       # xato xabarlari (agar bo'lsa)
```

Buyruq va uning argumentlari — **ro'yxat** (`list`) shaklida uzatiladi: `["ls", "-la", "/tmp"]`, bitta uzun string emas (`"ls -la /tmp"`). Bu — muhim xavfsizlik va ishonchlilik qoidasi, quyida batafsil ko'ramiz.

`capture_output=True` — buyruqning chiqishini (`stdout`/`stderr`) qaytarilgan obyektga yig'adi; `text=True` — natijani bayt (`bytes`) emas, matn (`str`) sifatida qaytaradi.

### `shell=True` — nega xavfli

```python
# XAVFLI — hech qachon foydalanuvchi kiritgan ma'lumot bilan bunday qilmang!
fayl_nomi = request.GET.get("fayl")
subprocess.run(f"cat {fayl_nomi}", shell=True)
```

`shell=True` — buyruqni operatsion tizim qobig'i (masalan `bash`) orqali bajaradi, bu esa qobiq maxsus belgilarini (`;`, `&&`, `|`, ``` ` ``` ) **ishga tushiradigan** qiladi. Agar `fayl_nomi` foydalanuvchidan kelgan bo'lsa va u `"malumot.txt; rm -rf /"` kabi qiymat kiritsa — bu **buyruqlar zanjiri** sifatida bajariladi! Bu — **command injection** deb ataluvchi, eng xavfli veb-zaifliklardan biri.


### Xavfsiz yo'l — ro'yxat + `shell=True` YO'Q

```python
# XAVFSIZ
fayl_nomi = request.GET.get("fayl")
subprocess.run(["cat", fayl_nomi], capture_output=True, text=True)
```

Bu holda `fayl_nomi` — nima bo'lishidan qat'iy nazar (hatto `"; rm -rf /"` bo'lsa ham) — **faqat bitta argument** sifatida `cat`ga uzatiladi, qobiq uni maxsus belgi sifatida talqin qilmaydi. `subprocess.run()`ni **har doim** ro'yxat bilan, `shell=True`siz chaqirish — standart, xavfsiz amaliyot.

### Natijani tekshirish — `check=True` yoki qo'lda

```python
# Variant 1: xato bo'lsa avtomatik CalledProcessError chiqaradi
try:
    natija = subprocess.run(["pg_dump", "onlayn_dokon"], check=True, capture_output=True, text=True)
except subprocess.CalledProcessError as xato:
    print("Xato:", xato.stderr)

# Variant 2: qo'lda tekshirish
natija = subprocess.run(["pg_dump", "onlayn_dokon"], capture_output=True, text=True)
if natija.returncode != 0:
    print("Xato:", natija.stderr)
```

## Amaliy misol

`onlayn_dokon` uchun, ma'lumotlar bazasini zaxira nusxalash (backup) va uni siqib arxivlash management command yozamiz:

```python
# apps/core/management/commands/baza_zaxirasi.py
import subprocess
from datetime import datetime
from pathlib import Path

from django.conf import settings
from django.core.management.base import BaseCommand, CommandError


class Command(BaseCommand):
    help = "PostgreSQL ma'lumotlar bazasidan zaxira nusxa oladi"

    def add_arguments(self, parser):
        parser.add_argument(
            "--papka",
            type=str,
            default=str(settings.BASE_DIR / "backups"),
            help="Zaxira fayllar saqlanadigan papka",
        )

    def handle(self, *args, **options):
        papka = Path(options["papka"])
        papka.mkdir(parents=True, exist_ok=True)   # 1.1-darsdagi pathlib

        vaqt_belgisi = datetime.now().strftime("%Y%m%d_%H%M%S")
        fayl_nomi = papka / f"onlayn_dokon_{vaqt_belgisi}.sql"

        db_nomi = settings.DATABASES["default"]["NAME"]

        self.stdout.write(f"Zaxira olinmoqda: {fayl_nomi}")

        try:
            natija = subprocess.run(
                ["pg_dump", "-d", db_nomi, "-f", str(fayl_nomi)],
                capture_output=True,
                text=True,
                timeout=300,          # 5 daqiqadan ortiq ketsa, to'xtatiladi
                check=True,
            )
        except FileNotFoundError:
            raise CommandError(
                "pg_dump topilmadi — PostgreSQL client vositalari o'rnatilganini tekshiring"
            )
        except subprocess.TimeoutExpired:
            raise CommandError("Zaxira olish 5 daqiqadan ortiq davom etdi, to'xtatildi")
        except subprocess.CalledProcessError as xato:
            raise CommandError(f"pg_dump xato bilan tugadi:\n{xato.stderr}")

        hajm_mb = fayl_nomi.stat().st_size / (1024 * 1024)
        self.stdout.write(self.style.SUCCESS(
            f"Zaxira muvaffaqiyatli yaratildi: {fayl_nomi} ({hajm_mb:.1f} MB)"
        ))
```

Bu misolda uchta muhim himoya qatlami bir vaqtda ishlatilgan: `timeout=300` (osilib qolgan jarayonni cheklash), `check=True` + `except CalledProcessError` (buyruq xato bilan tugasa aniq xabar), va `except FileNotFoundError` (`pg_dump` umuman o'rnatilmagan bo'lsa).

## Keng tarqalgan xatolar

**Xato 1:** Foydalanuvchi kiritgan (yoki tashqi manbadan kelgan) ma'lumotni `shell=True` bilan ishlatish.

❌ `subprocess.run(f"convert {fayl_yoli} chiqish.png", shell=True)` — agar `fayl_yoli` biror tashqi manbadan (fayl nomi, URL parametri) kelgan bo'lsa, bu **command injection**ga ochiq eshik.

✅ Har doim ro'yxat shaklida, `shell=True`siz: `subprocess.run(["convert", str(fayl_yoli), "chiqish.png"])`. Agar chindan ham qobiq xususiyatlari (masalan `|`, `&&`) kerak bo'lsa — bu juda kam uchraydigan holat — kirish ma'lumotini `shlex.quote()` bilan qat'iy tozalang.

**Xato 2:** `timeout` qo'ymaslik.

❌ `subprocess.run(["ffmpeg", "-i", video_yoli, ...])` — agar tashqi vosita biror sababga ko'ra "osilib qolsa" (masalan buzilgan fayl tufayli), Django worker jarayoni **cheksiz** kutib turadi, bu butun serverni sekinlashtirishi yoki band qilib qo'yishi mumkin.

✅ Har doim mos `timeout=` (sekundlarda) qo'shing va `subprocess.TimeoutExpired`ni ushlang — amaliy misoldagi kabi.

**Xato 3:** `returncode`ni tekshirmasdan, natijani "muvaffaqiyatli" deb hisoblash.

❌ `subprocess.run([...], capture_output=True, text=True)` — `check=True` yo'q, va natijadan keyin `returncode`ni tekshirmasdan to'g'ridan-to'g'ri natijani ishlatishga o'tish — agar buyruq ichki xato bilan tugagan bo'lsa (masalan `pg_dump` ma'lumotlar bazasiga ulana olmagan bo'lsa), dastur bu haqda **bilmaydi** va yo'q yoki bo'sh faylni "muvaffaqiyatli" deb hisoblashi mumkin.

✅ Yoki `check=True` qo'yib, `CalledProcessError`ni ushlang, yoki qo'lda `if natija.returncode != 0:` tekshiring — ikkalasidan birini har doim qiling, hech qachon natijani tekshirmasdan qoldirmang.

## Mashq/topshiriq

**(Oson)** Shell'da `subprocess.run(["echo", "Salom, onlayn_dokon"], capture_output=True, text=True).stdout`ni chiqarib, natijani ko'ring.

**(O'rtacha)** `baza_zaxirasi` buyrug'iga, zaxira faylini `subprocess.run(["gzip", str(fayl_nomi)])` orqali siqadigan qo'shimcha qadam qo'shing (`gzip` buyrug'i faylni siqib, `.gz` kengaytmasi bilan qayta nomlaydi) — bu qadam ham `try/except` bilan himoyalangan bo'lsin.

**(Qiyin)** `onlayn_dokon` uchun, `media/mahsulotlar/` papkasidagi rasmlarni tekshiruvchi (1.1-darsdagi `rasmlarni_tekshir` buyrug'ini eslang) va `identify` (ImageMagick'ning bir qismi, rasm o'lchamini ko'rsatadi) buyrug'i orqali har bir rasmning piksel o'lchamini (masalan `1200x800`) chiqaruvchi kengaytirilgan versiyasini yozing — `subprocess.run(["identify", "-format", "%wx%h", str(rasm_yoli)], capture_output=True, text=True)` dan foydalaning, va agar `identify` topilmasa (`FileNotFoundError`), foydalanuvchiga ImageMagick o'rnatish kerakligini aytadigan aniq xabar bering.

## Qisqacha xulosa

`subprocess.run()` — tashqi buyruq qatori vositalarini Python'dan ishga tushirish uchun standart usul; buyruq va argumentlari **har doim ro'yxat shaklida**, `shell=True`siz uzatilishi kerak — bu command injection zaifligining oldini oladi, ayniqsa foydalanuvchi kiritgan ma'lumot ishtirok etganda. `timeout=` osilib qolgan jarayonlardan himoya qiladi, `check=True` (yoki qo'lda `returncode` tekshiruvi) esa xatoni sukut saqlamasdan aniqlashni ta'minlaydi. Django management command'lar — bunday tashqi vositalarni (backup, media konvertatsiya, tashqi skript) chaqirishning tabiiy joyi, chunki ular serverda, nazorat ostida, muntazam ishga tushiriladi. Bu bilan kurs davomida ko'rilgan barcha standart kutubxona modullari tanish bo'ldi — 9-bobda ularning barchasini bitta yakuniy funksiyada birlashtiramiz.
