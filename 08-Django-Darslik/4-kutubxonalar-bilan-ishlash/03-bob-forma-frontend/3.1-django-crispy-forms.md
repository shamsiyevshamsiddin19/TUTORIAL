# 3.1. django-crispy-forms + crispy-bootstrap5 — formalarni chiroyli chizish

## Bu darsda nimalarni o'rganasiz

- Django formalarini qo'lda HTML yozmasdan, avtomatik va chiroyli (Bootstrap uslubida) chizishni o'rganasiz
- `django-crispy-forms` va `crispy-bootstrap5`ni o'rnatib, loyihaga ulashni bilib olasiz
- `{% crispy %}` shablon tegi va `|crispy` filtridan foydalanishni o'rganasiz
- `FormHelper` orqali forma maydonlari tartibini (layout) moslashtirishni o'rganasiz

## Nazariy qism

### Muammo: standart Django forma render qilish

10-darsda (1-qism) ko'rgan oddiy `{{ form.as_p }}` — ishlaydi, lekin **hech qanday** CSS klassi qo'shmaydi:

```html
{{ form.as_p }}
```

```html
<p><label for="id_nomi">Nomi:</label> <input type="text" name="nomi" id="id_nomi"></p>
```

Agar loyihangiz Bootstrap ishlatsa, `<input>` elementiga qo'lda `class="form-control"` qo'shish kerak bo'ladi — har bir maydon uchun, har bir formada, qo'lda. Katta loyihada bu — o'nlab formalarda takrorlanadigan, zerikarli va xatoga moyil ish.

### django-crispy-forms yechimi

```bash
pip install django-crispy-forms crispy-bootstrap5
```

```python
# settings.py
INSTALLED_APPS += [
    "crispy_forms",
    "crispy_bootstrap5",
]

CRISPY_ALLOWED_TEMPLATE_PACKS = "bootstrap5"
CRISPY_TEMPLATE_PACK = "bootstrap5"
```

Shablonda, ikki usuldan biri bilan ishlatiladi:

```html
{% load crispy_forms_tags %}

<form method="post">
    {% csrf_token %}
    {{ form|crispy }}
    <button type="submit" class="btn btn-primary">Saqlash</button>
</form>
```

yoki, `<form>` tegini ham o'zi generatsiya qiladigan to'liq versiya:

```html
{% load crispy_forms_tags %}
{% crispy form %}
```

Ikkalasi ham, endi har bir maydonni to'g'ri Bootstrap 5 klasslari (`form-control`, `mb-3`, va h.k.) bilan, label bilan birga chiqaradi — qo'lda hech narsa yozmasdan.

### FormHelper — layout'ni moslashtirish

Standart chiqish (barcha maydonlar tepadan-pastga, bitta ustunda) ko'p holatda yetarli. Lekin maydonlarni ikki ustunga joylashtirish yoki tugma matnini o'zgartirish kerak bo'lsa, `FormHelper` ishlatiladi:

```python
# apps/dokon/forms.py
from django import forms
from crispy_forms.helper import FormHelper
from crispy_forms.layout import Layout, Row, Column, Submit
from .models import Mahsulot


class MahsulotForm(forms.ModelForm):
    class Meta:
        model = Mahsulot
        fields = ["nomi", "narxi", "tavsif", "bolim"]

    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        self.helper = FormHelper()
        self.helper.layout = Layout(
            Row(
                Column("nomi", css_class="col-md-6"),
                Column("narxi", css_class="col-md-6"),
            ),
            "tavsif",
            "bolim",
            Submit("submit", "Saqlash", css_class="btn btn-primary"),
        )
```

Shablonda endi shunchaki:

```html
{% load crispy_forms_tags %}
{% crispy form form.helper %}
```

`self.helper` formaning o'zida saqlangani uchun, `{% crispy form %}` (ikkinchi argumentsiz) ham avtomatik uni topib ishlatadi.

## Amaliy misol

`onlayn_dokon`da yangi mahsulot qo'shish sahifasi, to'liq `crispy-forms` bilan:

```python
# apps/dokon/forms.py
from django import forms
from crispy_forms.helper import FormHelper
from crispy_forms.layout import Layout, Row, Column, Submit, Fieldset
from .models import Mahsulot


class MahsulotForm(forms.ModelForm):
    class Meta:
        model = Mahsulot
        fields = ["nomi", "narxi", "tavsif", "bolim", "mavjud"]

    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        self.helper = FormHelper()
        self.helper.layout = Layout(
            Fieldset(
                "Asosiy ma'lumot",
                Row(
                    Column("nomi", css_class="col-md-8"),
                    Column("narxi", css_class="col-md-4"),
                ),
                "bolim",
                "tavsif",
                "mavjud",
            ),
            Submit("submit", "Mahsulotni saqlash", css_class="btn btn-success mt-3"),
        )
```

```python
# apps/dokon/views.py
from django.shortcuts import render, redirect
from .forms import MahsulotForm


def mahsulot_qoshish(request):
    if request.method == "POST":
        form = MahsulotForm(request.POST)
        if form.is_valid():
            form.save()
            return redirect("mahsulotlar_royxati")
    else:
        form = MahsulotForm()
    return render(request, "dokon/mahsulot_qoshish.html", {"form": form})
```

```html
<!-- templates/dokon/mahsulot_qoshish.html -->
{% extends "base.html" %}
{% load crispy_forms_tags %}

{% block content %}
<div class="container mt-4">
    <h2>Yangi mahsulot qo'shish</h2>
    {% crispy form %}
</div>
{% endblock %}
```

Natijada, `nomi` va `narxi` maydonlari **bir qatorda, yonma-yon** (Bootstrap grid orqali), qolgan maydonlar esa alohida qatorlarda, hammasi tayyor Bootstrap 5 uslubida chiqadi — bironta ham qo'lda yozilgan CSS klassisiz.

## Keng tarqalgan xatolar

**Xato 1:** `CRISPY_TEMPLATE_PACK` sozlanmasdan `{% crispy %}` ishlatish.

❌ `settings.py`da `CRISPY_TEMPLATE_PACK = "bootstrap5"` qo'shilmagan — `{% crispy form %}` `TemplateDoesNotExist` yoki noto'g'ri (stilsiz) chiqish beradi, chunki `django-crispy-forms` qaysi CSS freymvork (Bootstrap 4, 5, Tailwind) uchun shablon ishlatishni bilmaydi.

✅ `crispy_bootstrap5`ni o'rnatgach, **darhol** `CRISPY_ALLOWED_TEMPLATE_PACKS` va `CRISPY_TEMPLATE_PACK`ni `settings.py`da sozlang — ikkalasi ham kerak.

**Xato 2:** `{% crispy form %}` ichida `<form>` tegini yana qo'lda qo'shib yuborish.

❌ Shablonda `<form method="post">{% crispy form %}</form>` yozilgan — `{% crispy %}` o'zi ham `<form>` tegini generatsiya qiladi, natijada ikkita ichma-ich `<form>` HTML'da noto'g'ri (brauzer buni buzib ko'rsatishi mumkin).

✅ `{% crispy form %}` ishlatilganda, `<form>` tegini **o'zingiz qo'shmang** — u avtomatik keladi. Agar `<form>` tegini o'zingiz nazorat qilmoqchi bo'lsangiz, buning o'rniga `{{ form|crispy }}` filtridan (u faqat ichki maydonlarni chizadi, `<form>`siz) foydalaning.

**Xato 3:** Bootstrap versiyasi bilan `crispy` paketining mos kelmasligi.

❌ Loyihada Bootstrap 5 ishlatilyapti, lekin `crispy-bootstrap4` o'rnatilgan (yoki aksincha) — CSS klasslar noto'g'ri chiqadi (masalan Bootstrap 5'da `form-group` klassi olib tashlangan, lekin eski paket hali ham uni generatsiya qiladi).

✅ Loyihangizdagi **aynan** Bootstrap versiyasiga mos `crispy-bootstrapN` paketini tanlang (`crispy-bootstrap5` — Bootstrap 5 uchun, `crispy-bootstrap4` — Bootstrap 4 uchun) — ikkalasi alohida PyPI paketlari.

## Mashq/topshiriq

**(Oson)** `django-crispy-forms` va `crispy-bootstrap5`ni o'rnating, `settings.py`ni sozlang. Mavjud biror formani `{{ form.as_p }}`dan `{{ form|crispy }}`ga o'zgartiring va natijadagi HTML'da qanday CSS klasslari paydo bo'lganini brauzer developer tools orqali tekshiring.

**(O'rtacha)** `Mijoz` modeli uchun forma yarating (`ism`, `telefon`, `manzil` maydonlari bilan) va `FormHelper` orqali `ism` va `telefon`ni bitta qatorga (`Row`/`Column`), `manzil`ni alohida qatorga joylashtiring.

**(Qiyin)** `MahsulotForm`ga `Fieldset("Narx ma'lumoti", "narxi", "chegirma_foizi")` kabi ikkinchi `Fieldset` qo'shing, va `Submit` tugmasidan tashqari, `HTML`/`Button` orqali "Bekor qilish" tugmasini (formani yubormasdan, orqaga qaytaradigan) qo'shing.

## Qisqacha xulosa

`django-crispy-forms` (+ tanlangan CSS freymvorkka mos `crispy-bootstrapN` paketi) — Django formalarini qo'lda HTML/CSS yozmasdan, `{% crispy form %}` yoki `{{ form|crispy }}` orqali avtomatik, tayyor CSS klasslari bilan chizib beradi; `FormHelper` va `Layout` esa maydonlar tartibini (ustunlarga bo'lish, guruhlash, qo'shimcha tugmalar) moslashtirish imkonini beradi. Bu — o'nlab formaga ega loyihada, dizayn izchilligini saqlash va zerikarli takrorlanuvchi HTML yozishdan qutulishning standart yo'li. Keyingi darsda — statik fayllarni (CSS, JS, rasm) production serverda to'g'ri va tez xizmat qilish uchun `whitenoise` kutubxonasini ko'ramiz.
