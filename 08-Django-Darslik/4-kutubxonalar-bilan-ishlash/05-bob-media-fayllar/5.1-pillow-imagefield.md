# 5.1. Pillow — ImageField, rasm validatsiyasi va o'lchamini o'zgartirish

## Bu darsda nimalarni o'rganasiz

- `ImageField` nega ichida `Pillow` kutubxonasiga tayanishini tushunasiz
- `Pillow` yuklangan faylning **haqiqatan** rasm ekanini qanday tekshirishini bilib olasiz
- Yuklangan rasmdan avtomatik, kichraytirilgan nusxa (thumbnail) yaratishni o'rganasiz
- Fayl hajmiga chegara qo'yib, haddan tashqari katta rasmlarni rad etishni o'rganasiz

## Nazariy qism

### Nega Pillow kerak

Django'da `models.ImageField` — `models.FileField`ning maxsus turi, lekin bir muhim farq bilan: u, yuklangan faylning **kengishi** (`.jpg`) emas, balki faylning **haqiqiy tarkibi** rasm ekanini tekshiradi. Buni qanday bilasiz? — Django buning uchun ichida `Pillow` kutubxonasidan foydalanadi. Agar `Pillow` o'rnatilmagan bo'lsa, `ImageField` ishlatilgan modelda `makemigrations` bajarilganda xato chiqadi:

```
SystemCheckError: System check identified some issues:
ERRORS:
apps.dokon.Mahsulot.rasm: (fields.E210) Cannot use ImageField because Pillow is not installed.
```

```bash
pip install Pillow
```

E'tibor bering: PyPI'dagi o'rnatish nomi `Pillow` (katta P bilan), lekin Python ichida `import PIL` (Python Imaging Library'ning tarixiy nomidan) — 0.1-darsda ko'rgan "o'rnatish nomi ≠ import nomi" holatining яна bir aniq misoli.

### ImageField asosiy foydalanish

```python
# apps/dokon/models.py
from django.db import models


class Mahsulot(models.Model):
    nomi = models.CharField(max_length=200)
    rasm = models.ImageField(upload_to="mahsulotlar/", blank=True, null=True)
    rasm_kengligi = models.PositiveIntegerField(editable=False, null=True)
    rasm_balandligi = models.PositiveIntegerField(editable=False, null=True)
```

`upload_to="mahsulotlar/"` — yuklangan fayllar `MEDIA_ROOT/mahsulotlar/` papkasiga saqlanishini bildiradi. `width_field`/`height_field` parametrlarini (`ImageField(..., width_field="rasm_kengligi", height_field="rasm_balandligi")`) qo'shsangiz, Django rasm o'lchamini **avtomatik**, har safar saqlashda, shu maydonlarga yozib qo'yadi — bu, shablonda `<img>` teglariga `width`/`height` atributlarini oldindan bilib qo'yish (va sahifa "sakramasligi" — layout shift'ning oldini olish) uchun foydali.

### Rasmni avtomatik kichraytirish (thumbnail)

Foydalanuvchi 8000×6000 piksellik, 15 MB'lik rasm yuklashi mumkin — buni saytda to'g'ridan-to'g'ri ko'rsatish sahifani sekinlashtiradi. `save()` metodini qayta aniqlab (override), yuklangandan keyin avtomatik kichraytirish mumkin:

```python
from PIL import Image
from django.db import models


class Mahsulot(models.Model):
    nomi = models.CharField(max_length=200)
    rasm = models.ImageField(upload_to="mahsulotlar/", blank=True, null=True)

    def save(self, *args, **kwargs):
        super().save(*args, **kwargs)   # avval — faylni diskka yozib bo'lish kerak

        if self.rasm:
            img = Image.open(self.rasm.path)
            if img.height > 800 or img.width > 800:
                img.thumbnail((800, 800))   # nisbatni saqlagan holda kichraytiradi
                img.save(self.rasm.path)    # xuddi shu joyga qayta yozadi
```

**Muhim:** `super().save()` — **birinchi** chaqirilishi shart, chunki faqat shundan keyin `self.rasm.path` (faylning diskdagi haqiqiy yo'li) mavjud bo'ladi. `img.thumbnail((800, 800))` — nisbatni (aspect ratio) buzmasdan, eng katta tomonini 800 pikselgacha kichraytiradi.

## Amaliy misol

`onlayn_dokon`da `Mahsulot` modeli — to'liq, hajm chegarasi va thumbnail bilan:

```python
# apps/dokon/models.py
from PIL import Image
from django.core.exceptions import ValidationError
from django.db import models


def rasm_hajmini_tekshir(fayl):
    chegara_mb = 5
    if fayl.size > chegara_mb * 1024 * 1024:
        raise ValidationError(f"Rasm hajmi {chegara_mb} MB dan oshmasligi kerak.")


class Mahsulot(models.Model):
    nomi = models.CharField(max_length=200)
    rasm = models.ImageField(
        upload_to="mahsulotlar/",
        blank=True,
        null=True,
        validators=[rasm_hajmini_tekshir],
    )

    def save(self, *args, **kwargs):
        super().save(*args, **kwargs)
        if self.rasm:
            img = Image.open(self.rasm.path)
            if img.height > 800 or img.width > 800:
                img.thumbnail((800, 800))
                img.save(self.rasm.path)
```

`admin.py`da rasm oldindan ko'rish (preview):

```python
# apps/dokon/admin.py
from django.contrib import admin
from django.utils.html import format_html
from .models import Mahsulot


@admin.register(Mahsulot)
class MahsulotAdmin(admin.ModelAdmin):
    list_display = ["nomi", "rasm_preview"]
    readonly_fields = ["rasm_preview"]

    def rasm_preview(self, obj):
        if obj.rasm:
            return format_html('<img src="{}" style="max-height: 100px;">', obj.rasm.url)
        return "Rasm yo'q"

    rasm_preview.short_description = "Ko'rinishi"
```

Endi 3000×2400 piksellik rasm yuklansa, saqlanganidan keyin avtomatik 800×640ga (nisbatni saqlagan holda) kichrayadi, va agar fayl 5 MB'dan katta bo'lsa, forma validatsiyada aniq xato bilan rad etiladi.

## Keng tarqalgan xatolar

**Xato 1:** `Pillow`ni o'rnatmasdan `ImageField` ishlatishga urinish.

❌ Model'da `ImageField` yozilgan, lekin `pip install Pillow` bajarilmagan — `makemigrations` `fields.E210` xatosi bilan to'xtaydi.

✅ `ImageField` ishlatilgan **har qanday** loyihada, `Pillow`ni `requirements.txt`ga (1.1-darsdagi uslubda) qo'shishni birinchi qadam sifatida bajaring.

**Xato 2:** `save()`ni qayta aniqlaganda, `super().save()`ni chaqirishdan **oldin** faylga murojaat qilish.

❌ `img = Image.open(self.rasm.path)` qatori `super().save(*args, **kwargs)`dan **oldin** yozilgan — bu payt fayl hali diskka yozilmagan, `self.rasm.path` mavjud emas yoki eski qiymatga ishora qiladi, `FileNotFoundError` chiqadi.

✅ `save()`ni qayta aniqlaganda, tartib har doim: (1) `super().save()` — asl saqlash, (2) shundan keyingina fayl bilan qo'shimcha ishlov (`Image.open`, kichraytirish, qayta saqlash).

**Xato 3:** Fayl hajmiga hech qanday chegara qo'ymaslik.

❌ `rasm = models.ImageField(upload_to="mahsulotlar/")` — validator yo'q, foydalanuvchi 50 MB'lik rasm yuklashi mumkin, bu serverning disk maydonini tez to'ldirishi va sahifa yuklanishini sekinlashtirishi mumkin.

✅ Har doim `validators=[...]` orqali maksimal fayl hajmiga (masalan 5 MB) chegara qo'ying — bu, oddiy funksiya (`rasm_hajmini_tekshir` kabi) yoki tayyor uchinchi-tomon validatorlari orqali amalga oshiriladi.

## Mashq/topshiriq

**(Oson)** `Pillow`ni o'rnating, `Mahsulot` modeliga `rasm = models.ImageField(upload_to="mahsulotlar/", blank=True, null=True)` qo'shing, migratsiya yarating va bajaring.

**(O'rtacha)** `save()` metodini qayta aniqlab, 600×600 piksel chegarasida avtomatik kichraytirish qo'shing. Admin panel orqali katta (masalan 2000×2000) rasm yuklab, saqlangandan keyin fayl o'lchami kichraytirilganini (Pillow yoki fayl menejeri orqali) tasdiqlang.

**(Qiyin)** `rasm_hajmini_tekshir` validatorini yozing (3 MB chegara bilan) va uni `ImageField`ga bog'lang. Admin panel orqali 3 MB'dan katta fayl yuklashga urinib, aniq xato xabari ko'rsatilishini tasdiqlang; keyin 3 MB'dan kichik fayl bilan muvaffaqiyatli saqlanishini tekshiring.

## Qisqacha xulosa

`Pillow` — Django `ImageField`ning ishlashi uchun **majburiy** bog'liqlik: u, yuklangan faylning haqiqatan rasm ekanini tekshiradi va rasm bilan (o'lchamini o'zgartirish, kichraytirish) dasturiy ishlov berish imkonini beradi. `save()` metodini `super().save()`dan **keyin** fayl bilan ishlaydigan qilib qayta aniqlash — avtomatik thumbnail yaratishning standart usuli; fayl hajmiga validator orqali chegara qo'yish esa serverni haddan tashqari katta yuklamalardan himoya qiladi. Keyingi darsda — bu rasmlarni serverning o'z diskida emas, bulutli saqlash xizmatida (S3-mos) saqlashni ko'ramiz.
