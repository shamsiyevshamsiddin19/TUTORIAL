# Disk tasviri va virtual mashina fayllari

## ISO — to'liq disk nusxasi

`.iso` — fizik diskning (CD, DVD) **to'liq, bайt-baytiga aniq** nusxasini, bitta faylda saqlaydigan format.

**Nima qila oladi:** operatsion tizim tarqatuvchilari (Windows, Linux distributivlari), ISO faylini yuklab olish va uni USB flesh-diskka yoki virtual diskka "yozish" orqali, o'rnatish diskisiz, tizimni o'rnatish imkonini beradi; disk mazmunini, jismoniy diskka yozmasdan turib, virtual ravishda "ulash" (mount) mumkin.

## IMG — umumiy disk tasviri

`.img` — ISO'ga o'xshash, disk yoki xotira kartasining xom (raw) nusxasini saqlaydigan, kengroq formatlar oilasi. Ko'pincha, Raspberry Pi kabi qurilmalar uchun tayyor tizim tasvirlarini tarqatishda ishlatiladi.

## VDI, VMDK va VHD — virtual mashina disklari

Bu formatlar — **virtual mashina** (kompyuter ichida ishlaydigan "kompyuter")ning butun qattiq diskini, bitta faylda tasvirlaydi:

| Format | Virtual mashina dasturi |
|---|---|
| `.vdi` | VirtualBox |
| `.vmdk` | VMware |
| `.vhd`/`.vhdx` | Microsoft Hyper-V |

**Nima qila oladi:** virtual mashinaning butun operatsion tizimi, o'rnatilgan dasturlari va fayllarini, bitta (yoki bir nechta bo'lakka bo'lingan) faylda saqlaydi; bu faylni boshqa kompyuterga ko'chirish orqali, butun virtual muhitni, qayta sozlashsiz, boshqa joyda ishga tushirish mumkin.

## OVA — virtual mashinani eksport qilish formati

`.ova` (Open Virtualization Appliance) — virtual mashinaning diskini (VMDK/VDI) **va** uning sozlamalarini (protsessor, xotira hajmi va h.k.) birgalikda, bitta faylga "qadoqlab" saqlaydigan format. Bu, tayyor virtual mashinani, turli virtualizatsiya dasturlari orasida almashish uchun ishlatiladi.

## Solishtirma jadval

| Format | Nima saqlaydi | Asosiy qo'llanilishi |
|---|---|---|
| ISO | To'liq disk nusxasi | OS o'rnatish, dastur tarqatish |
| VDI/VMDK/VHD | Virtual mashina diski | Virtual kompyuterlar |
| OVA | Virtual mashina + sozlamalar | Virtual mashinani almashish |
