# Fayl formatlarini tanlash qo'llanmasi

Ushbu darslikda ko'rilgan barcha kategoriyalar bo'yicha, qaysi vaziyatda qaysi formatni tanlash kerakligi haqida yakuniy, amaliy qo'llanma.

## Matn va hujjatlar

| Vaziyat | Tavsiya etilgan format |
|---|---|
| Oddiy, sof matn yozish | TXT yoki Markdown (.md) |
| Formatlangan hujjat tayyorlash va tahrirlash | DOCX |
| Hujjatni o'zgarmas ko'rinishda tarqatish | PDF |
| Kitob nashr qilish | EPUB (asosiy), AZW3 (Amazon uchun) |

## Jadval va ma'lumot

| Vaziyat | Tavsiya etilgan format |
|---|---|
| Hisob-kitob va vizual tahlil | XLSX |
| Dasturlar orasida ma'lumot almashish | CSV |
| Katta hajmli ma'lumotlar tahlili | Parquet |
| Konfiguratsiya fayli yozish | YAML yoki TOML |
| API orqali ma'lumot almashish | JSON |

## Rasm va dizayn

| Vaziyat | Tavsiya etilgan format |
|---|---|
| Fotosurat saqlash | JPEG (umumiy) yoki HEIC (Apple) |
| Logotip, ikonka, shaffof fon | PNG yoki SVG |
| Veb-sayt tezligini oshirish | WEBP yoki AVIF |
| Professional dizayn loyihasi | AI, PSD yoki Figma (.fig) |

## Audio va video

| Vaziyat | Tavsiya etilgan format |
|---|---|
| Kundalik musiqa tinglash | MP3 yoki AAC |
| Sifatni yo'qotmasdan arxivlash | FLAC (audio), MKV (video) |
| Video striming/almashish | MP4 |
| Veb-saytga video joylashtirish | WEBM |

## Arxivlash va ma'lumotlar bazasi

| Vaziyat | Tavsiya etilgan format |
|---|---|
| Fayllarni siqib yuborish | ZIP (universal) yoki 7Z (maksimal siqish) |
| Kichik, mahalliy ma'lumotlar bazasi | SQLite |
| Jamoaviy, "no-code" ma'lumot boshqaruvi | .base (Notion/Airtable turi) |

## Umumiy tanlov mezonlari

Format tanlashda, quyidagi savollarga javob berish foydali:

**Kim ochadi?** Agar fayl, turli odamlarga, turli qurilmalarda ochilishi kerak bo'lsa — keng tarqalgan, ochiq standart formatlar (PDF, PNG, MP4, CSV) afzal. Agar fayl faqat bitta maxsus dastur ichida ishlatilsa — o'sha dasturning ona (native) formati (PSD, AI, .blend) to'g'ri tanlov.

**Qayta tahrirlanadimi?** Agar hujjat kelajakda qayta ochilib, o'zgartirilishi kerak bo'lsa — tahrirlash imkoniyatini saqlovchi format (DOCX, PSD, XLSX) kerak. Agar u faqat ko'rish/chop etish uchun bo'lsa — o'zgarmas format (PDF) yetarli.

**Sifat muhimmi yoki hajm?** Agar eng yuqori sifat kerak bo'lsa (professional fotografiya, audio arxiv) — yo'qotishsiz formatlar (PNG, FLAC, TIFF) tanlanadi. Agar fayl hajmini kichraytirish muhimroq bo'lsa (veb-sayt, striming) — yo'qotishli, siqilgan formatlar (JPEG, MP3, MP4) afzal.

**Qancha ma'lumot bor?** Kichik, oddiy ma'lumot uchun — sodda formatlar (CSV, INI, TXT) yetarli. Katta hajmli, murakkab, ko'p qatlamli ma'lumot uchun — kuchliroq formatlar (XLSX, JSON, Parquet, ma'lumotlar bazasi fayllari) kerak bo'ladi.

Fayl formati — vosita, xolos. To'g'ri tanlangan format, ishni osonlashtiradi; noto'g'ri tanlangani esa, keyinchalik moslik va sifat muammolarini keltirib chiqarishi mumkin. Shu sababli, har doim, "bu faylni kim, qanday maqsadda ochadi va ishlatadi" degan savolni birinchi o'ringa qo'yish tavsiya etiladi.
