# Ijro etiladigan va o'rnatish fayllari

Bu fayllar — matn yoki media emas, balki kompyuterga **bevosita bajarish uchun buyruqlar** beradigan fayllardir.

## EXE va MSI — Windows dasturlari

`.exe` — Windows'da dasturni to'g'ridan-to'g'ri ishga tushiradigan, ijro etiladigan fayl. `.msi` — dasturni **o'rnatish** (install) jarayonini boshqaradigan maxsus format bo'lib, o'rnatish, yangilash va olib tashlashni tartibli, standartlashtirilgan tarzda amalga oshiradi.

## APP va DMG — macOS dasturlari

`.app` — aslida, ichida ko'plab fayllarni saqlovchi papka bo'lib, macOS uni bitta dastur sifatida ko'rsatadi. `.dmg` (Disk Image) — dasturni tarqatish uchun ishlatiladigan, virtual diskka o'xshab ochiladigan o'rnatish fayli — foydalanuvchi, ichidagi dastur belgisini "Applications" papkasiga sudrab olib borib, o'rnatadi.

## APK va IPA — mobil ilovalar

`.apk` — Android ilovalarining o'rnatish fayli, `.ipa` — iOS ilovalarining fayli. Ikkalasi ham, aslida, ilova kodini, rasmlarni va boshqa resurslarni birlashtirgan **siqilgan arxiv** (ZIP asosida qurilgan).

## DEB va RPM — Linux paketlari

`.deb` — Debian/Ubuntu asosidagi Linux distributivlarida dastur o'rnatish uchun ishlatiladigan format. `.rpm` — Red Hat/Fedora/CentOS asosidagi tizimlarda xuddi shu vazifani bajaradi. Ikkalasi ham, dasturning o'zi bilan bir qatorda, unga kerakli boshqa dasturlarni (bog'liqliklar/dependencies) ham belgilaydi.

## APPIMAGE — universal Linux formati

`.appimage` — Linux'ning turli distributivlarida, **o'rnatishsiz**, to'g'ridan-to'g'ri ishga tushiriladigan dastur formati. Barcha kerakli fayllarni o'zida saqlagani uchun, tizimga hech narsa o'rnatmasdan ishlaydi.

## BAT, SH va PS1 — skript fayllari

Bular — to'g'ridan-to'g'ri protsessor kodi emas, balki terminalga ketma-ket beriladigan **buyruqlar ro'yxati**ni saqlaydi:

| Format | Tizim | Vazifasi |
|---|---|---|
| `.bat` | Windows (Command Prompt) | Buyruqlar ketma-ketligini avtomatlashtirish |
| `.ps1` | Windows (PowerShell) | Ancha kuchliroq, zamonaviy skript tili |
| `.sh` | Linux/macOS (terminal) | Buyruqlar ketma-ketligini avtomatlashtirish |

## Solishtirma jadval

| Format | Operatsion tizim | Turi |
|---|---|---|
| EXE/MSI | Windows | Dastur/o'rnatuvchi |
| APP/DMG | macOS | Dastur/o'rnatuvchi |
| APK/IPA | Android/iOS | Mobil ilova |
| DEB/RPM/AppImage | Linux | Dastur paketi |
