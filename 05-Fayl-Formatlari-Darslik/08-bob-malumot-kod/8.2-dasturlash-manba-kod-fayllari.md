# Dasturlash manba kod fayllari

Manba kod fayllari — sof matn fayllari bo'lib, ularning kengaytmasi, kompyuterga (yoki dasturchiga) qaysi dasturlash tilida yozilganini bildiradi.

## Umumiy tuzilma

Har bir kengaytma, muayyan tilning sintaksis qoidalariga mos yozilgan matnni bildiradi, va tegishli **kompilyator** yoki **interpretator** tomonidan ishga tushiriladi (bevosita) yoki avval ijro etiladigan formatga aylantiriladi (kompilyatsiya qilinadi).

| Kengaytma | Til | Ishga tushirish usuli |
|---|---|---|
| `.py` | Python | Interpretatsiya (to'g'ridan-to'g'ri ishga tushadi) |
| `.js` | JavaScript | Interpretatsiya (brauzer yoki Node.js orqali) |
| `.ts` | TypeScript | Avval `.js`ga aylantiriladi (transpilyatsiya), keyin ishga tushadi |
| `.java` | Java | Kompilyatsiya qilinadi (`.class` baytkodga), Java Virtual Machine orqali ishlaydi |
| `.c` | C | To'g'ridan-to'g'ri protsessor kodiga kompilyatsiya qilinadi |
| `.cpp`/`.cc` | C++ | To'g'ridan-to'g'ri protsessor kodiga kompilyatsiya qilinadi |
| `.go` | Go | To'g'ridan-to'g'ri, tezkor kompilyatsiya qilinadi |
| `.rs` | Rust | To'g'ridan-to'g'ri kompilyatsiya qilinadi, xotira xavfsizligini tekshiradi |
| `.php` | PHP | Server tomonida interpretatsiya qilinadi |
| `.rb` | Ruby | Interpretatsiya qilinadi |
| `.sh` | Shell/Bash | Terminal orqali, buyruqlar ketma-ketligi sifatida ishga tushadi |

## IPYNB — interaktiv hisoblash daftari

`.ipynb` (Jupyter Notebook) — oddiy manba kod faylidan farqli, kodni, uning natijasini (grafik, jadval, matn chiqishi) va tushuntirish matnini (Markdown) **bitta hujjatda, ketma-ket bo'laklar** (cell) ko'rinishida birlashtiradi.

**Nima qila oladi:** kodni bo'lak-bo'lak ishga tushirish va natijani darhol shu yerning o'zida ko'rish imkonini beradi; ma'lumotlar tahlili, mashina o'rganish va ta'limiy materiallar tayyorlashda keng qo'llaniladi.

## HTML va CSS — kod sifatida

`.html` (1.1-darsda ko'rilgan) va `.css` — veb-sahifaning tuzilishi (HTML) va tashqi ko'rinishini (CSS) belgilaydigan fayllar. Ular, brauzer tomonidan to'g'ridan-to'g'ri o'qiladi va vizual sahifaga aylantiriladi.

## Umumiy xususiyat

Barcha manba kod fayllari — sof matn bo'lgani uchun, **istalgan matn muharriri**da ochilishi va tahrirlanishi mumkin, lekin ularni to'liq ishlatish (ishga tushirish, xatolarni tekshirish, avtomatik to'ldirish) uchun, odatda maxsus dasturlash muhiti (IDE) ishlatiladi.
