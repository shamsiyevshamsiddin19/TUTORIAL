# Ma'lumot almashish fayllari

Bu formatlar — insonlar emas, balki **dasturlar orasida** ma'lumot almashish uchun mo'ljallangan (garchi ular matn ko'rinishida bo'lib, inson tomonidan ham o'qilishi mumkin).

## JSON — zamonaviy veb standarti

`.json` (JavaScript Object Notation) — kalit-qiymat juftliklari va ro'yxatlar orqali, tuzilgan ma'lumotni saqlaydigan, sodda va yengil format.

**Nima qila oladi:** deyarli barcha zamonaviy dasturlash tili tomonidan, qo'shimcha kutubxonasiz o'qiladi va yoziladi; veb-ilovalar va API'lar orasida ma'lumot almashishning **de-fakto standarti**; sozlamalar fayllari (config) uchun ham keng qo'llaniladi.

## XML — eski, ammo kuchli standart

`.xml` (eXtensible Markup Language) — HTML'ga o'xshash teglar orqali, ma'lumotni ierarxik tarzda tasvirlaydigan format.

**Nima qila oladi:** JSON'ga qaraganda ko'proq imkoniyat beradi — sxema (schema) orqali ma'lumot tuzilishini qattiq belgilash, izohlar (comments) qo'shish va atributlar bilan ishlashni qo'llab-quvvatlaydi. Korporativ tizimlar, Microsoft Office fayllari (ichki tuzilishi) va ba'zi eski API'larda hali ham keng ishlatiladi.

## YAML — o'qish uchun eng qulay format

`.yaml`/`.yml` — qavs va tirnoqlarsiz, faqat bo'sh joy (indentation) orqali tuzilishni ifodalaydigan, inson uchun **eng o'qish qulay** ma'lumot formati.

**Nima qila oladi:** Docker Compose, Kubernetes va ko'plab CI/CD (masalan, GitHub Actions) tizimlarining konfiguratsiya fayllari uchun standart format; JSON'dagi barcha ma'lumot turlarini, ancha sodda sintaksis bilan ifodalay oladi.

## TOML — sozlamalar uchun zamonaviy format

`.toml` — YAML'dan soddaroq, aniqroq sintaksisga ega, maxsus konfiguratsiya fayllari uchun yaratilgan format. Python (`pyproject.toml`), Rust (`Cargo.toml`) kabi zamonaviy dasturlash vositalarida loyiha sozlamalarini saqlash uchun ishlatiladi.

## INI — eng sodda sozlamalar formati

`.ini` — `[bo'lim]` va `kalit=qiymat` ko'rinishidagi, eng oddiy konfiguratsiya format. Murakkab, ichma-ich (nested) tuzilmalarni ifodalay olmaydi, lekin sodda sozlamalar uchun hali ham ko'plab dasturlarda ishlatiladi.

## Solishtirma jadval

| Format | O'qish qulayligi | Izoh qo'llab-quvvatlashi | Asosiy qo'llanilishi |
|---|---|---|---|
| JSON | Yaxshi | Yo'q | API, veb-ma'lumot almashish |
| XML | O'rtacha | Ha | Korporativ tizimlar, sxemali hujjatlar |
| YAML | Eng yaxshi | Ha | Konfiguratsiya (Docker, CI/CD) |
| TOML | Yaxshi | Ha | Loyiha sozlamalari |
| INI | Yaxshi (sodda) | Ha (cheklangan) | Oddiy dastur sozlamalari |

Jadval ma'lumotlari uchun ishlatiladigan **CSV** va **Parquet** formatlari haqida 2-bobda batafsil ma'lumot berilgan edi.
